# machv_emit

Reusable MachV machine-code emitter.

`machv_emit` turns allocated legacy AMD64 MachV functions into machine-code
objects and relocation/fixup metadata. Final target VCode pipelines use their
target package's emitter and may use `MachineCode` as an integration container.

## When to use it

Use `machv_emit` after a MachV function has been lowered and allocated. The
emitter produces bytes plus symbolic metadata; it does not decide how runtime
helper names become process addresses or how executable memory is allocated.

## Example: build a small code object

`MachineCode` can also be used directly by embedders that need small stubs or
tests. Pass the ISA explicitly so the generated bytes are independent of the
machine running the test.

```moonbit check
///|
test "build a tiny AMD64 return object" {
  let code = MachineCode::MachineCode(isa=AMD64, record_disasm=false)
  code.emit_byte(0xc3)
  let bytes = code.get_bytes()
  inspect(bytes.length(), content="1")
  inspect(code.current_pos(), content="1")
}
```

## Example: collect relocation metadata

Runtime and function-address fixups stay symbolic so callers can resolve them
after emission.

```moonbit check
///|
test "record an unresolved external call fixup" {
  let code = MachineCode::MachineCode(isa=AMD64, record_disasm=false)
  code.emit_byte(0xe8)
  code.add_external_call_fixup(1, ExternalName("env.print_i32"))
  for _ in 0..<4 {
    code.emit_byte(0)
  }
  inspect(code.get_bytes().length(), content="5")
  inspect(code.get_call_fixups().length(), content="1")
}
```

## Emitter output

The emitter returns machine-code bytes together with relocation, call-fixup,
trap, and stack-frame metadata. A caller can then resolve symbols, allocate
executable memory, and install the generated code according to its runtime
policy.
