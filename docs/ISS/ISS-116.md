# ISS-116: Retire the duplicate linear Wasm frontend interface

## Description
The top-level `wasm_milkir/frontend` package exposes both the canonical production translator (`translate_function`, translation contexts, and function-body translation) and a separate linear frontend (`lower_function` and `try_lower_native_function`). The linear implementation is approximately 2,700 lines and has a different supported-instruction surface and different failure behavior.

Product code now uses the production translator, but external callers still see two plausible semantic entry points. Keeping both public allows WebAssembly semantics, diagnostics, and optimization behavior to drift.

## Design
Keep one public Wasm-to-MilkIR interface. Delete the linear implementation if it no longer provides measurable value, or retain it only as a private fast path selected behind the canonical translator. If retained, run both implementations against the same semantic contract and use differential tests to prove equivalent MilkIR behavior for the fast path's accepted subset.

The public interface should hide the `wasm_milkir/frontend/ir` implementation package and should not require callers to choose which translator is semantically authoritative.

## Acceptance Criteria
- [ ] The top-level frontend exposes one authoritative Wasm-to-MilkIR semantic entry point.
- [ ] `lower_function` and `try_lower_native_function` are removed from the public interface or become private implementation details.
- [ ] Product and external examples no longer choose between linear and production translators.
- [ ] If the linear path remains, differential tests cover every instruction class it accepts and compare observable MilkIR semantics with the canonical path.
- [ ] Structured control flow, memory, tables, references, GC, SIMD, exceptions, and multi-memory continue through the canonical translator.
- [ ] Generated `.mbti` files and frontend documentation describe only the supported public seam.
- [ ] Frontend, preflight, explore, JIT, and WAST validation gates pass.
