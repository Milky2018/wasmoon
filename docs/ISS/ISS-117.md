# ISS-117: Enforce the JIT ABI contract across MoonBit and C

## Description
The fixed VMContext prefix and nested memory/table layout facts are duplicated between `wasmoon_jit/vmcontext_abi.mbt` and C declarations in `wasmoon_jit/jit_ffi`. Generated machine code consumes the MoonBit offsets, while native runtime code consumes the C structs. Existing MoonBit tests assert only the hard-coded MoonBit numbers; there are no C `offsetof`/`sizeof` static assertions or cross-language layout probes.

Any field insertion, C type change, atomic alignment change, or platform ABI difference can therefore compile successfully while generated code reads or writes the wrong memory. The result can be silent miscompilation, memory corruption, or process crashes.

## Design
Establish a mechanically checked ABI source of truth. At minimum, add C `_Static_assert` checks for every fixed-prefix field and nested descriptor/table fact consumed by generated code, and expose a small C layout probe whose values are compared with `vmcontext_layout()` and `memory_descriptor_layout()` in MoonBit tests. Prefer generation from one declarative layout description if it can remain simple and auditable.

Remove stale hand-written ownership references such as the header comment that still points to the retired `vcode/abi/abi.mbt` location.

## Acceptance Criteria
- [ ] C compilation statically verifies every VMContext fixed-prefix `offsetof` used by generated code.
- [ ] C compilation verifies relevant `sizeof`, alignment, memory-descriptor offsets, and table-entry layout facts.
- [ ] A MoonBit test compares `vmcontext_layout()` and `memory_descriptor_layout()` with values obtained from compiled C definitions.
- [ ] ABI checks run for supported AArch64 and AMD64 native CI environments.
- [ ] ABI ownership comments identify `wasmoon_jit/vmcontext_abi.mbt` or the new canonical source correctly.
- [ ] Changing a checked C field without updating the canonical ABI causes a deterministic build or test failure.
- [ ] Native check, full MoonBit tests, and core WAST interpreter/JIT suites pass.
