# ISS-118: Define process-global JIT signal and debug ownership

## Metadata
- Type: task
- Status: open

- Assignee: unassigned

## Description
JIT call-local trap state and the current JIT context are thread-local, but Wasmoon still installs process-wide SIGTRAP, SIGSEGV, and SIGBUS handlers once and does not retain an explicit host-visible ownership or restoration lifecycle. DWARF lookup also uses one process-global active builder pointer.

This is dangerous for library embedding: Wasmoon can overwrite a host runtime's existing signal policy, unrelated faults are no longer dispatched through the host's previous handlers, and multiple simultaneously active JIT contexts can overwrite debug lookup state.

## Design
Create a Wasmoon-owned native-runtime lifecycle module that explicitly manages process-global resources. Signal installation must save and either chain or restore previous handlers, use race-safe reference counting, and document which signals Wasmoon owns while JIT code is active. Debug metadata lookup must be per JIT context or use a synchronized address-range registry rather than one active global pointer.

Keep per-thread trap state in TLS. Do not move context-local state back into process-global variables.

## Acceptance Criteria
- [ ] Signal-handler installation records previous SIGTRAP, SIGSEGV, and SIGBUS dispositions.
- [ ] Unrelated signals are chained to the previous host handler or default disposition without permanently discarding host policy.
- [ ] The final Wasmoon user can uninstall or restore process-global handlers safely.
- [ ] Concurrent installation and removal are race-safe and reference-counted.
- [ ] DWARF address lookup supports multiple live JIT contexts without a single `g_active_dwarf` pointer.
- [ ] Tests cover a host-installed signal handler, multiple JIT contexts, multiple threads, and teardown ordering.
- [ ] Public embedding documentation states the lifecycle and signal ownership contract.
- [ ] Native MoonBit tests and JIT WAST suites pass on supported macOS and Linux targets.
