## Description

`benchmark_algorithms_parity.py` builds every Wasmtime sample before running
Wasmoon samples. Order, thermal state, and stale Wasmoon JIT artifacts can move
the reported AEGIS ratio from about 1.26x to about 1.60x.

## Design

Measure paired samples per workload, alternate engine order, and give Wasmoon an
isolated cache rooted in the benchmark output area. Report paired value and wall
ratios rather than ratios of two independently collected medians. Keep the tool
manual and do not restore Wasmtime as a blocking CI dependency.

## Acceptance Criteria

- [ ] Each measured pair runs both engines under an alternating deterministic
      order.
- [ ] Wasmoon uses an isolated cache and records whether the measured artifact
      was freshly compiled.
- [ ] Summary JSON records raw pairs plus paired median and geometric-mean ratios.
- [ ] Unit tests cover order, ratio aggregation, and cache isolation without
      requiring Wasmtime.
