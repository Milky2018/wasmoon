# ISS-236: Cut over Cwasm and remove legacy artifact surfaces

## Metadata

## Description

After the final artifact loader and installer exist, production and tooling must stop constructing v8 `PrecompiledModule`, negative runtime fixup indices, resolved-before-serialization `CwasmArtifact`, and public patch/FFI helpers.

## Design

Migrate eager JIT, run-cache, CLI Cwasm loading, tests, and tooling to the artifact and installer facades. Delete `/cwasm`, the linked-code artifact adapters, v8 target fixup helpers, and unsupported public `/jit_ffi` surface. Keep native primitives package-private behind the root installer.

## Acceptance Criteria
- [ ] Every live JIT, cache, explicit Cwasm, WAST, component, and CLI path uses the final artifact/installer seam.
- [ ] No v8 model, negative runtime fixup identity, resolved-before-serialization adapter, forwarding encoder, or public patch helper remains.
- [ ] Runtime and CLI packages enter compilation and installation only through the `wasmoon_jit` facade allowed by the boundary audit.
- [ ] Live/loaded parity, artifact corruption, GC/trap/stack-map/unwind, rollback, full native/default tests, and recursive WAST gates pass.
