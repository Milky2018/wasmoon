## Description
Resume performance engineering after 0.18.0, across the complete 70-workload
algorithm corpus, the pinned parse_double property, and explicit allocation,
lifetime, mutation and memory-pressure controls. The user superseded the old
1.05x execution / 1.5x compilation requirements: optimize measured costs while
preserving maintainability, correctness and the MoonBit architecture.

## Design
Start from main 21c702b5. Preserve the deferred experiment commit 586bc5b0 and
untracked V128 notes. Compare independent compiler, invocation, whole-process,
CPU and peak-RSS boundaries. Use serial cold-cache Wasmtime and optimized V8 controls with serial
compilation. A single cold sweep identifies candidates, not a stable
performance conclusion. Profile and repeat selected workloads before changing
implementation; change one causal variable at a time. Compare collector policies
only with explicit lifetime/survival data and complete root/rollback contracts.
Keep raw profiles, sources, caches and builds in auto-cleaned OS temporary
workspaces; retain small explanations and reproducible runners in the repo.
