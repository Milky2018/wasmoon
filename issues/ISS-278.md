## Description
Expose a real component command execution path and gate the host against pinned
Preview 2 and Preview 3 component workloads.

## Design
Extend the existing component CLI without conflating validation with
execution. The run path configures arguments, environment, preopens, standard
I/O, clocks, random providers, and network policy, instantiates the command
world, invokes `run`, and converts structured exit status to the CLI status.

## Acceptance Criteria
- [ ] The CLI runs binary components and preserves the existing parse/validate
      commands.
- [ ] Preview 2 stable and Preview 3 async suites are separate versioned lanes.
- [ ] Tests cover arguments, environment, exit, stdio, clocks, random,
      filesystem, polling, and loopback sockets.
- [ ] CI cannot pass with an empty or skipped WASI component corpus.
- [ ] User-facing documentation states supported snapshots and capability
      defaults.
