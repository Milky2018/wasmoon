# ISS-479: Reject malformed UTF-16 and overflowing canonical string lengths

## Description
The canonical UTF-16 reader currently falls through to unsafe character creation for isolated or mismatched surrogates. Its byte-length multiplication also uses signed Int arithmetic before bounds validation. Establish public guest regressions and repair both validation boundaries.

## Acceptance Criteria
- [ ] Wasmtime-verified invalid surrogate sequences trap in both engines.
- [ ] Oversized tagged and untagged lengths trap before host decoding/allocation.
- [ ] Valid surrogate pairs and existing string conformance tests still pass.
