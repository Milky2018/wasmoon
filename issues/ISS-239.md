# ISS-239: Migrate JIT cache and public compile APIs to v9 artifacts

## Description

The CLI run cache, WAST/test helpers, and public compile APIs still exchange and serialize v8 `PrecompiledModule` values.

## Design

Replace those seams with v9 artifact bytes plus explicit compatibility validation. Cache lookup must decode with limits, check source/policy/target identity, and delete incompatible or malformed entries without falling back to a compatibility decoder.

## Acceptance Criteria
- [ ] CLI, WAST, WASI, testsuite, and public compile APIs exchange v9 artifacts only.
- [ ] Run-cache reads use bounded decode and exact compatibility validation before installation.
- [ ] Cache keys and manifests distinguish all codegen-affecting policy and module identity.
- [ ] Corrupt, old, incompatible, and oversized cache entries are rejected and removed.
- [ ] Native, run-cache, WAST, component, and WASIp1 regression paths pass.
