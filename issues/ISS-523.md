## Description
Native Linux AMD64 misc execution returns 0xdeadbeef00000000 instead of zero from a successful i64.atomic.rmw32.cmpxchg_u. Narrow compare-exchange and RMW instructions must explicitly normalize the old memory value to the Wasm result width; successful CMPXCHG need not write the accumulator.

## Acceptance Criteria
- [x] Cover successful and failed narrow compare-exchange and RMW with nonzero high input bits.
- [ ] Native Linux AMD64 passes the original rmw32_cmpxchg_u_wrap.wast assertion.
- [ ] Existing native and external atomic regressions pass.
