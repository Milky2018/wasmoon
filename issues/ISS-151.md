# ISS-151: Reconnect MilkIR pass metrics through an embedding-neutral sink

## Description
MilkIR pass instrumentation was disconnected when the optimizer moved behind the reusable compiler-module boundary. `modules/milkir/perf_stub.mbt` permanently reports metrics as disabled and discards every pass record, so the Wasmoon-owned collector cannot observe per-pass timings, e-graph statistics, GVN work, or budget exhaustion even when detailed metrics are requested.

## Design
Replace the permanent stub with a generic optional optimization-metrics sink owned by MilkIR. The sink must contain no Wasmoon names or imports. The Wasmoon JIT performance package will install an adapter only while detailed metrics are enabled, own the platform clock, and translate generic pass events into the product JSON report. Keep the disabled fast path to one optional-sink check and preserve the current compact metrics behavior.

## Acceptance Criteria
- [x] An embedder can install and clear a generic MilkIR optimization-metrics sink.
- [x] Every existing instrumented pass reports its name, instruction counts, changed state, and duration through the sink.
- [x] E-graph statistics plus GVN work and budget-exhaustion state reach the JSON schema.
- [x] No sink is installed unless detailed metrics are explicitly enabled.
- [x] Reusable MilkIR does not import Wasmoon-owned packages.
- [x] Unit tests cover sink delivery and clearing; a real CLI probe confirms detailed pass metrics in JSON.

## Close Notes
Closed on 2026-07-13. The permanent no-op stub was replaced with an abstract MilkIR metrics sink carrying generic pass events. The Wasmoon-owned performance package supplies the monotonic clock and JSON adapter only in detailed metrics mode. Schema v2 includes e-graph statistics plus `work_done` and `budget_exhausted`. The sink unit test verifies event fields, duration, and clearing; a real detailed CLI report contained 56 pass records across four functions, including four GVN work/budget records. Verified with `moon check --target native --deny-warn`, MilkIR and commands package tests, `MACHV_REGALLOC_VALIDATION=1 moon test --target native` (1811/1811), `python3 scripts/audit_module_boundaries.py`, `./install.sh`, a cold/second-run cache probe, and `scripts/run_perf_benchmarks.py`.
