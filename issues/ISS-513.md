## Description
Integrate real atomic wait/notify into the interpreter and provide cooperative execution without placing MoonBit frames on native fiber stacks. Distinguish host suspension tokens, guest scheduling yields, and atomic waits in the continuation outcome. Cancellation must remove a parked wait registration before releasing its execution state.

## Acceptance Criteria
- [x] Guest wait/notify uses the checked shared native queue, including ordinary synchronous calls.
- [x] A long guest loop yields and resumes without restarting completed instructions.
- [x] Two independently owned interpreter contexts can wait and notify through shared memory.
- [x] Cancellation removes a parked wait and all existing component continuation regressions remain valid.
- [x] Native checks and focused ASan tests pass.
