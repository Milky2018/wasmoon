## Description
On accepted 00c44af6, execution-only samples of the unchanged ten-call control
place 62% of main-thread top-of-stack samples in array/struct metadata helpers.
A separate counter run observes 395,997,591 array projections; 96.3% repeat the
previous object. Existing struct metadata already has a 95.6% cache hit rate.
These are workload-specific samples/counters, not an additive speedup budget.

## Design
Reuse one heap-owned array metadata hint, independent of the existing struct
hint. It is never a GC root. Store only the reference, encoded view and compact
width; writes still read live payloads. Reuse existing lifetime invalidation for
growth, collection, compaction, identity retirement, rollback and runtime-type
updates. Preserve opaque/reference/legacy arrays, positive-width compatibility,
verification-mode refusal, bounds/null traps, barriers, quotas and fault controls.
Do not change generated code, safepoints or cooperative quantum.
