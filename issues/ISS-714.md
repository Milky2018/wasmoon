## Description
Current large-module phase measurements attribute about2.58 of6.27 seconds to
register allocation, including0.93 seconds in bundle allocation. The queue
pops1.49 million entries while moving four parallel arrays on every heap swap.

## Design
Store each numeric priority snapshot, bundle ID and hint in one private value
record. Retain the scalar buffer in the existing allocation session. Hold one
entry while moving parents or children through the hole, then write it once.
Preserve priority/weight/ID ordering, duplicate membership, hint snapshots,
second-chance reset, split requeues and session reuse. No allocator strategy,
public interface, runtime policy or artifact revision change.
