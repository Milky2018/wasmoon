## Description
Existing CLI smoke tests exercised real TCP and both engines, but did not establish broad HTTP conformance. Independent raw-socket probes reproduced incorrect rejection of case-insensitive Expect values and absolute-form targets, plus incomplete chunk-extension parsing. Strengthen behavior coverage and state what the evidence does not establish.

## Acceptance Criteria
- [x] Preserve Expect token case-insensitivity and accept HTTP absolute-form request targets using their URI authority.
- [x] Accept valid chunk extensions and reject malformed ones without falsely completing a streamed response.
- [x] Prove response data arrives before upload EOF, and service continues after more abandoned uploads than its connection limit.
- [x] Verify observable middleware transformations and guest-visible request metadata.
- [x] Run strict warning checks, native tests and real CLI tests on both engines; record fresh CI evidence without claiming exhaustive verification.
