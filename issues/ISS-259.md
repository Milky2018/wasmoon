# ISS-259: Reuse stable environment fields with pressure awareness

## Description

The current block-local reuse distance of eight reduces AEGIS `func_30`
memory-base loads from 60 to 40 without changing spills, but Wasmtime retains one
base load. Whole-function pinning is unacceptable because it can turn the value
into a long-lived allocation constraint and increase spills.

## Design

After reducing target temporary pressure, extend stable environment-field reuse
only across profitable block/loop regions. Treat calls and mutable fields as
barriers, include live-pressure or use-distance limits, and retain rematerialized
loads when that is cheaper than extending a live range.

## Acceptance Criteria

- [x] Stable and mutable environment fields retain distinct legality rules.
- [x] Reuse across demonstrated safe block/loop regions has focused tests.
- [x] AEGIS `func_30` emits fewer than 40 memory-base loads.
- [x] Spill/reload counts and paired runtime do not regress relative to ISS-258.
- [x] No allocatable physical register is reserved for the environment base.

## Notes

- 2026-07-23: The current bounded reuse deliberately trades load elimination for
  shorter live ranges; this issue must preserve that tradeoff rather than apply a
  global pin.
- 2026-07-23: Claimed after ISS-258 removed avoidable address-constant pressure.
  Work starts by measuring stable-field definitions and CFG use regions before
  changing the reuse boundary.
- 2026-07-23: A 32-instruction / three-reuse experiment cut memory-base loads to
  16 but increased spills/reloads from `8/10` to `12/14`, so it was rejected.
  The accepted 16-instruction / one-reuse budget cuts loads to 30 while keeping
  allocation edits unchanged.

## Close Notes

Stable environment fields now reuse one prior value within a 16-instruction
block-local pressure region. Calls clear the region; mutable fields are never
eligible. Tests cover reuse beyond the old eight-instruction window, the
one-reuse budget, mutable fields, and call barriers. Reuse remains virtual-value
coalescing and does not reserve an allocatable physical register.

AEGIS `func_30` memory-base loads fell from `40` to `30`; spill/reload counts
remain `8/10`, and code size fell from `1340` to `1296` bytes. A five-pair
cache-isolated run improved the median value ratio from `1.202732` to `1.158528`
and wall ratio from `1.197873` to `1.153689`. The full native suite passed
`2307/2307`.
