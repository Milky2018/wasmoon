## Description

An indirect call through a registered Store function can search the
identity index and executable index separately, including when the
signature already matches exactly.

## Design

Pack the exact type identity and the existing one-based executable
ordinal into the current dense slot for bounded registries. Refresh the
view on type and executable publication, and resolve the executable
pointer from its owning array. Keep the existing checked lookup for
subtypes, sparse registries, misses, and legacy references.

## Notes

- Original table64 invocation changes from 4.989 to 3.289 ms, a 34.04%
  paired median reduction. Serial Wasmtime and eager V8 medians are
  0.887 and 1.367 ms. Bulk-table invocation falls 11.65%. The reference
  control is 2.42% higher, within its 3% limit.
- The SDK controls pass all 24 cold four-arm comparisons with the
  original assertions. Paired compile changes are +0.23% to +1.11%
  and invocation changes are -0.98% to +1.72%.
- The earlier inline-lowering experiment exceeded its compile budget.
  The selected runtime change leaves guest artifacts unchanged and
  adds no allocation for the packed index.
