# ISS-256: Index register clobber queries for large CFGs

## Description

For every bundle segment and candidate physical register,
`first_clobber_point` linearly scans every clobber point recorded for that
register. AEGIS `func_56` has 882 optimized blocks and spends most target
compilation time in this repeated scan.

## Design

Build one block-order-sorted clobber index per physical register and answer
range queries by binary search. Preserve the exact earliest-conflict semantics,
including non-physical block numbering and fixed-register operand points. Avoid
public API changes.

## Acceptance Criteria

- [ ] First-clobber lookup uses a bounded logarithmic search over sorted points.
- [ ] Tests cover no match, boundary exclusion, multiple blocks, custom block
      order, and fixed-register clobbers.
- [ ] A deterministic scaling test locks the query-work bound.
- [ ] Regalloc snapshots and full allocation verification remain unchanged.
- [ ] Fresh AEGIS compile metrics demonstrate the large-function improvement.
