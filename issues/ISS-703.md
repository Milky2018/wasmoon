## Description
Shared-reservation bounds create longer straight-line native allocation blocks.
They still repeatedly publish identical parts of a complete precise function
mask. The old mask-cache experiment had no stable gain while allocation diamonds
forced unknown entries; the new CFG shape changes that prerequisite.

## Design
An explicit function-frame ABI capability promises immutable compiler-owned
mask bytes across helper calls, collectors, reentry and parking. Default false
retains complete writes for unknown providers. Wasmoon's const mask pointers,
header-only linking and whole-function stack-object ownership satisfy it.
Remember only the previous mask in the current block, omit equal words, retain
all root-slot writes and initial zeroing. Clear knowledge at unknown block entries
and returns-twice calls. No safepoint observes partial updates. Advance codegen25
and reject24 caches; preserve format12/ABI8 and all runtime/storage contracts.
