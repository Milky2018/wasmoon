## Description
Implement the upstream nan_canonicalization configuration for scalar and SIMD arithmetic, rounding and float-width conversions. Canonicalize before any consumer can reinterpret or store the result; preserve constants, loads and sign-only operations. Use a generic MilkIR pass and equivalent interpreter behavior, with an explicit artifact compilation policy that separates cached variants.

## Close Notes

Implemented a generic pre-optimization MilkIR canonicalization pass, preserving SSA result identities and checking every scalar/SIMD arithmetic NaN before consumers observe it. The interpreter applies the same operation boundary. Constants, loads, abs/neg/copysign and pseudo-min/max retain their source semantics. Core Store and compiler APIs accept the immutable configuration; WAST CLI exposes --canonicalize-nans and misc forwards the upstream option. Both exclusions are removed.

Cwasm format 10 records nan_canonicalization in CompilationPolicy. Serialization, compatibility and cache filenames distinguish variants, and the cache rejects artifacts compiled with the wrong policy. Existing v9 cache entries are incompatible. JIT ABI remains version 6.

All four upstream executions failed before configuration, and now pass. The independent internal-observation fixture and both upstream files pass pinned Wasmtime with -C cranelift-enable-nan-canonicalization=true. Native tests: 2,402 passed, including SSA verification, memory/reinterpret/SIMD observations and cache policy controls. info/fmt/check passed. All official core, runtime, component lanes and P1 gates passed. Full misc: 580 pass, 70 script-only, 112 thread/continuation failures, two unsupported capacity executions, no deferred cases (tmp/iss510-all-misc/summary.json).
