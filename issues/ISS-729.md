# ISS-729: Reject overflowing constant memory64 access ranges

## Description

The JIT's constant-range proof interpreted a WebAssembly unsigned memory
offset as a signed Int64 in a wrapping sum. An address of 1 and a maximum
unsigned offset reached byte zero. An out-of-bounds store changed the
sentinel from 65 to 99, while the interpreter trapped.

## Design

Use the existing checked offset-and-width bound, followed by subtraction
from the known minimum before comparing the address. Values outside the
signed proof domain use the existing unsigned dynamic overflow and bounds
checks. Increment the code generation revision so old compiled artifacts
cannot retain the defective proof.

## Acceptance Criteria

- [ ] Verify the platform run for the final revision.
