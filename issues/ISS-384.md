## Description
`get_simplified_opcode` (`modules/milkir/egraph_builder.mbt:331`) runs a
full recursive `EGraph::extract` for **every instruction result** during
block rewriting, allocating a fresh memo `Map` and `in_progress` set per
call and traversing the reachable subgraph each time. Under the current
constant-only harvest this answers a question the e-class already caches:
`EClass.const_value` exists precisely for O(1) constant lookup via
`get_const`, and extraction can only return a `Const` best node when the
class contains one (constants cost 0 and win every comparison), so the two
are semantically equivalent today.

On top of the per-value traversal, the equal-cost tie-break
`extract_node_tiebreak_less` (`modules/milkir/egraph/egraph.mbt:1688`)
builds `"\{Repr(op)}:\{Repr(children)}"` strings for every comparison —
allocation and formatting in the hottest extraction loop.

Net effect: each optimized function pays O(values × reachable subgraph)
plus string formatting for what `get_const` answers in O(values).

## Design
The fix depends on ISS-377's direction:

- If ISS-377 chooses pruning (constant-plus-aliasing stays the harvest),
  replace the `extract` call in `get_simplified_opcode` with
  `get_const`/`get_fconst` and drop the now-unused extraction entry point
  from the production path.
- If ISS-377 builds elaboration, extraction becomes genuinely needed —
  then compute best costs once per e-graph with a shared bottom-up pass
  (egg-style relaxation) instead of per-value fresh-memo DFS, and replace
  the string tie-break with a cheap deterministic ordering (opcode tag
  ordinal, then child class ids).

Either way the string-formatting tie-break goes away.

## Acceptance Criteria
- [ ] Block rewriting no longer performs per-value full extraction with a
      fresh memo; the chosen replacement (`get_const` or a shared
      bottom-up cost pass) is in place.
- [ ] Equal-cost tie-breaking no longer formats strings; determinism of
      chosen nodes is preserved (existing extraction/optimizer snapshots
      stay green).
- [ ] E-graph, optimizer, and JIT/interp comparison suites stay green.
