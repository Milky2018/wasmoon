## Description
Establish repeated serial measurements against Wasmtime 49.0.1 before selecting startup/compiler optimizations. Distinguish process wall time, actual CLI phases, guest-reported metrics and process peak RSS.

## Design
Use real workloads selected from the 70-module baseline: short startup-heavy cases, longer compute-heavy cases, and near-parity controls. Retain all samples with binary/input hashes and alternating engine order. Keep detailed compiler attribution separate from ordinary timings. Do not infer compiler time by subtracting unrelated compile-only fixtures from CLI wall time. Only retain optimizations supported by independent before/after measurements and correctness checks.
