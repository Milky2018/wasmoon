## Description
`modules/regalloc/planning` is 16 files and 2129 lines. Every reference to it
in the repository comes from a `_test.mbt` or `_wbtest.mbt` file. There are
zero production references.

The build file states it outright:

```
import {
  "Milky2018/regalloc/planning",
} for "wbtest"
```

Of its 28 `pub fn`, 26 have no caller outside tests, and `resolve_threaded_jump`
has no caller at all. The remaining two are called only from within the
package.

The duplication is the substantive part. `resolve_parallel_moves` exists
twice:

| | `regalloc/planning/move_resolver.mbt` | `machv/vcode/move_resolver.mbt` |
| --- | --- | --- |
| production callers | 0 | 12 |
| exhausted scratch | `abort` | `raise MoveResolveError` |
| cycle with no free scratch | `abort` | `raise MoveResolveError` |

The version in use raises and is caught by both targets
(`catch { error => raise InvalidParallelMove(cause=error) }`). The version
that aborts is the one nothing calls. `parallel_edits.mbt:120` raises
`InvalidPlan(message="parallel-transfer cycle has no source owner")` — the
same claim `pick_cycle_scratch` aborts on.

So the package's three `abort()` sites (`temp_register_pool.mbt:119`,
`move_resolver.mbt:79`, `move_resolver.mbt:115`) are unreachable, but for the
uninteresting reason: the code is dead.

## Design
Decide per file, not wholesale. Some of this is a genuinely useful algorithm
library whose only problem is that nothing wired it up; some is a superseded
copy of something `machv/vcode` now owns. The move resolver is clearly the
second. `temp_register_pool.mbt` has no counterpart and no caller — it is
either an unfinished feature or an abandoned one, and its git history should
say which.

Tests that exercise a package nothing uses still pass, which is why this was
invisible: 2129 lines of covered, green, unreachable code.

## Acceptance Criteria
- [ ] Each file is either deleted, or wired into the production path, with the
      choice recorded.
- [ ] No two implementations of parallel-move resolution remain.
- [ ] `for "wbtest"` no longer appears in `modules/regalloc/moon.pkg`, or the
      package is gone.
