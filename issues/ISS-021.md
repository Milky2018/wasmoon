## Description
Replace the pseudo-byte `machv_emit` skeleton with the real machine-code emission pipeline now under `modules/wasmoon/vcode/emit`, while keeping Wasmoon runtime fixups out of the generic emitter.

## Design
Port real encoding, stack frame emission, relocations, fixups, disassembly-support tests, machine-code metadata, and ISA-specific encoding internals into `machv_emit`. Runtime helper references must stay as generic external-symbol relocations or metadata records. Wasmoon-specific helper resolution, executable memory, traps, and hostcall trampoline binding belong in `wasmoon_jit`.

## Acceptance Criteria
- [ ] `machv_emit` emits real machine-code bytes for supported MachV instructions, not pseudo tags.
- [ ] Runtime helper references are generic relocations/metadata; `machv_emit` does not import `wasmoon`, `wasmoon_jit`, `jit_ffi`, or `wasm_core`.
- [ ] Existing `vcode/emit` byte encoding, stackframe, runtime-fixup, and disassembly tests are ported or explicitly split into generic emitter vs Wasmoon JIT tests.
- [ ] `x64_emit` or `aarch64_emit` packages are not introduced unless a later issue proves that split is necessary.
- [ ] WAST JIT correctness gates pass after Wasmoon consumes `machv_emit`.

- 2026-07-04: Added explicit `EmitTarget` selection plus `emit_function_for_target`, and copy-first migrated the old X64 `mov r/m64, r64`, `add r/m64, r64`, `call rel32`, `jmp rel32`, `ret`, and trap-byte encodings into `machv_emit`. The default `emit_function` remains a temporary AArch64 compatibility entry until callers pass real target metadata.
- 2026-07-04: `machv_emit` now emits basic MachV terminators (`TermReturn`, `TermJump`, `TermTrap`) through the same target byte/relocation path as ordinary instructions and records terminator debug entries with `inst_id = -1`. Complex conditional terminators remain explicit unsupported opcodes until branch encoding and block layout patching are migrated.
- 2026-07-04: Copy-first migrated basic conditional branch emission into `machv_emit`. AArch64 now emits `CBZ`/`CBNZ`, `CMP`, `B.cond`, and `B` placeholders for MachV conditional terminators; X64 now emits `test`/`cmp`, `jcc rel32`, and `jmp rel32` placeholders. Both paths record generic block-target relocations and fixups while leaving block-argument moves and final displacement patching as explicit TODOs.
- 2026-07-04: Copy-first migrated the first non-add integer opcode bytes into `machv_emit`: X64 now emits `IntConst`, `IntSub`, `IntMul`, `IntAnd`, `IntOr`, and `IntXor`; AArch64 now emits `IntConst` for unsigned 16-bit immediates plus `IntSub`, `IntMul`, `IntAnd`, `IntOr`, and `IntXor`. Remaining work includes full constant materialization, width-aware encodings, memory operations, floating-point operations, and final fixup patching.
- 2026-07-04: Added constant-offset pointer memory emission for `LoadPtr` and `StorePtr` over integer/pointer widths. X64 now emits base+disp32 loads/stores, and AArch64 now emits scaled unsigned-offset LDR/STR placeholders for I32/I64/Ptr memory types. Floating/vector memory forms and register-offset addressing remain TODO-backed unsupported cases.
