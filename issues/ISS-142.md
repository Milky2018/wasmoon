## Description
The expand phase stores scalar instructions under ScalarOp but retains flat scalar Opcode variants and bidirectional compatibility mappings. This duplicates the scalar protocol and lets new code bypass the semantic family.

## Design
Migrate scalar producers and consumers to direct ScalarOp matching, delete the flat scalar Opcode variants and conversion helpers, and preserve constant bit identity and optimizer behavior.

## Acceptance Criteria
- [x] Opcode contains no flat scalar constant, arithmetic, comparison, conversion, select, or copy variants.
- [x] Verifier, printer, optimizers, e-graph integration, and MachV lowering dispatch directly on ScalarOp.
- [x] No scalar compatibility conversion helper remains.
- [x] MilkIR, MilkIR/MachV, frontend, and JIT tests pass.
