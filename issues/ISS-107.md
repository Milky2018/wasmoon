# ISS-107: Narrow regalloc model mutability and field visibility

## Description
Core model and result types such as `Instruction`, `Block`, `Program`, `Allocation`, live ranges, and many planner structs are declared `pub(all)`, which lets external users mutate allocator-owned arrays and counters directly. This weakens invariants and makes later implementation changes unnecessarily breaking.

## Design
Use `pub(all)` only for enums and small value records that external code genuinely pattern matches or constructs directly. Prefer `pub struct` plus constructors and query methods for larger objects with arrays, counters, or allocator-owned mutable state. Do not make the public program model harder to use; add small constructors or builders where field writes are currently the only ergonomic path.

## Acceptance Criteria
- [ ] Public mutable arrays and allocator-owned counters are not exposed unless they are intentionally part of the stable model.
- [ ] External construction still has a simple documented path.
- [ ] Internal code and tests do not rely on public field writes where methods should express the operation.
- [ ] `moon check --target native --warn-list +73 --diagnostic-limit=400` passes.
