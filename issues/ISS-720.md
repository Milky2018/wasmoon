## Description
The original Core strconv test process yields cooperatively about 1.887 million
times. Parking traverses activation roots twice, allocates a registration and
root array, and copies roots before every stack switch. Independent sampling
attributes significant execution cost to root-frame and root-copy helpers.

## Design
Let an activation own a root-source registration while its native stack is
stopped. Enumerate the stable frame chain only for collection, snapshots and
transaction liveness. Preserve owned exception/continuation arrays, root-owner
binding, heap retention and every unregister-before-stack-release transition.
Keep root masks, cancellation, scheduling quantum, faults and borrow checks.

## Acceptance Criteria
- [x] Fail before the change on parking with the next native allocation denied.
- [x] Preserve exact live roots through collection, resume and cancellation.
- [x] Preserve continuation/exception tracing and transaction rollback checks.
- [x] Pass strict checks, full tests, integrations and sanitizers.
- [x] Measure matched original hot modules and the full serial Core suite.
- [ ] Record exact-head platform acceptance and clean owned scratch files.

## Notes
- Counts and profiles identify repeated root materialization; they are not
  predictions of the speedup from the proposed representation change.
- The native denial regression fails with 0 instead of 1 on the parent and
  passes with the embedded source. Omitting source enumeration fails the
  public snapshot/liveness regression; the restored implementation passes.
- Local acceptance: native 3,235 ordinary and with all three verifier flags;
  wasm 1,512; strict native/wasm warnings, native C, module boundaries and bridge
  checks; Core WAST 258 files/62,563 assertions per engine and Component suites
  59 files/1,385 commands per engine. Fresh precommit ASan/UBSan passes 379 tests,
  the event loop and both positive controls; its source identity remains dirty.
- Five pairs per original hot module all improve: median paired wall changes
  -6.40% strconv, -2.29% vector, -1.89% edit-distance and -1.42% sorted-map.
  Three complete serial Core rounds all pass 7,971 tests. Parent/candidate
  medians are 138.355690/137.357672 s; mixed paired changes (-0.72%, +0.40%,
  -1.73%) do not establish a material total-time improvement. Official median
  10.235260 s leaves a 13.42x total-time gap. See
  [measurement scope](../docs/perf/parked-root-sources.md).
