## Description
Original Argon2id corpus measurements retain about a 15% value gap to serial
Wasmtime. Separate CPU samples concentrate in functions 40/41. Matching native
code to the actual profile cache shows standalone shift/mask sequences in the
hot low-word multiplication formula, including 64 extra shifts in function 41.

## Design
Recognize a single-use constant left shift followed by a contiguous low-field
mask. A product-neutral typed native operation retains the low field and shifts
it left. AArch64 emits UBFIZ; x64 retains ordinary shift/mask lowering. Both the
portable contract and target verifier reject invalid widths, fields and shifts.
Shared intermediates and sparse masks keep the original path. No memory, root,
barrier, safepoint or runtime policy changes. Bump codegen revision to 29.
