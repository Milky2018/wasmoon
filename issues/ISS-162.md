## Description
Define the semantic axes needed to represent integer, floating-point, widening, narrowing, conversion, special, memory, and relaxed vector operations without spelling out every lane combination as a separate `VectorOp` constructor.

## Design
Keep the types in the public `milkir` package because downstream lowering pattern-matches them. Prefer small enums such as integer lane, float lane, signedness, half, and operation kind. The verifier remains the authority for unsupported combinations rather than proliferating nearly identical lane-specific types.

## Acceptance Criteria
- [x] New vector family types cover every currently supported `VectorOp` operation.
- [x] Operation identity retains all lane, signedness, half, conversion, and relaxedness distinctions.
- [x] Tests lock representative equality, hashing, and debug identity for normalized operations.
- [x] `moon check --target all --deny-warn` passes.
