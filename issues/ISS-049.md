## Description
`fallback_root_counts` appears in stackmap-building code in `modules/machv_emit/runtime.mbt`, `modules/wasmoon_jit/cwasm_artifact.mbt`, and related native GC helper wording. The term is technically a local fallback when metadata is absent, but it is easy to misread as interpreter fallback. The code should use a clearer name for the default or candidate root count.

## Design
Rename local parameters and variables without changing behavior. Prefer `default_root_counts` / `default_root_count` unless the implementation proves that `candidate_root_counts` is more accurate. Keep public API impact explicit: if generated `.mbti` signatures change only by parameter names or remain structurally identical, document that in the close notes.

## Acceptance Criteria
- [ ] MoonBit stackmap builders no longer use `fallback_root_counts` or `fallback_root_count` for default root-count data.
- [ ] Native helper terminology is aligned if it uses the same concept.
- [ ] Any retained `fallback` wording is explicitly justified by current behavior in comments or close notes.
- [ ] No behavior changes are included.
- [ ] `moon info --target native` is run if public/generated interfaces are affected.
- [ ] `git diff --check` passes.
- [ ] `moon check --target native --warn-list +73 --diagnostic-limit=200` passes.
