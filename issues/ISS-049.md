## Description
`fallback_root_counts` appears in stackmap-building code in `modules/machv_emit/runtime.mbt`, `modules/wasmoon_jit/cwasm_artifact.mbt`, and related native GC helper wording. The term is technically a local fallback when metadata is absent, but it is easy to misread as interpreter fallback. The code should use a clearer name for the default or candidate root count.

## Design
Rename local parameters and variables without changing behavior. Prefer `default_root_counts` / `default_root_count` unless the implementation proves that `candidate_root_counts` is more accurate. Keep public API impact explicit: if generated `.mbti` signatures change only by parameter names or remain structurally identical, document that in the close notes.

## Acceptance Criteria
- [x] MoonBit stackmap builders no longer use `fallback_root_counts` or `fallback_root_count` for default root-count data.
- [x] Native helper terminology is aligned if it uses the same concept.
- [x] Any retained `fallback` wording is explicitly justified by current behavior in comments or close notes.
- [x] No behavior changes are included.
- [x] `moon info --target native` is run if public/generated interfaces are affected.
- [x] `git diff --check` passes.
- [x] `moon check --target native --warn-list +73 --diagnostic-limit=200` passes.

## Close Notes
Closed by renaming stackmap v2 root-count parameters and locals from `fallback_root_counts` / `fallback_root_count` to `default_root_counts` / `default_root_count` in `modules/machv_emit/runtime.mbt` and `modules/wasmoon_jit/cwasm_artifact.mbt`.

The native stackmap root selector in `modules/wasmoon_jit/jit_ffi/gc_ops.c` was aligned by renaming the same concept to `default_root_count`; its clamp helper now uses `max_root_count` for the upper bound. Other retained `fallback` wording describes unrelated behavior such as slow-path allocation, import resolution, encoder defaults, and tagged-funcref decoding. The public `build_gc_stackmap_blob_v2` type shape remains unchanged, and `moon info --target native` was run to verify generated interfaces.
