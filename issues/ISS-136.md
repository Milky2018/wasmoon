# ISS-136: Group calls under a generic CallOp contract

## Description
Direct, indirect, and raw-pointer calls are separate top-level opcodes. The current pointer-call verifier embeds Wasmoon trampoline assumptions by assigning a special context role to operand 1 even though a reusable IR should only describe a callee and ordinary arguments.

## Design
Introduce `CallOp` for direct-symbol, indirect, and pointer callees. Keep signatures and argument/result counts explicit, but make the core pointer-call contract generic: operand 0 is the callee pointer and the remaining operands are arguments. Wasmoon VMContext placement remains a producer/ABI-adapter responsibility. Migrate all consumers and producers without changing emitted calling conventions.

## Acceptance Criteria
- [x] Direct and pointer calls use `Opcode::Call(CallOp)`; the unsupported core indirect-call form was removed by ISS-134.
- [x] Core verification no longer assigns Wasmoon-specific meaning to a particular pointer-call argument.
- [x] Effect and trap facts remain conservative for every call kind.
- [x] Trampoline, JIT, verifier, and lowering tests preserve current behavior.
