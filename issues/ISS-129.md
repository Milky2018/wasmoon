## Description
The implementation correctly treats `CallableRef` and `OpaqueRef` as 64-bit carriers in fused comparisons, but the `BranchCmp` and `SelectCmp` regression test covers only `Ptr` and `Ref`. Separately, the `CallPtr` negative verifier test covers an invalid function-pointer operand but not an invalid callee-context operand. These gaps allow future per-type or per-operand regressions to escape the focused suites.

## Design
Extend the existing lowering test matrix to all four 64-bit pointer/reference carriers, and add distinct `CallPtr` negative tests for operand 0 and operand 1. Keep production code unchanged because current behavior is correct.

## Acceptance Criteria
- [x] Fused `BranchCmp` and `SelectCmp` tests cover `Ptr`, `Ref`, `CallableRef`, and `OpaqueRef`.
- [x] `CallPtr` independently rejects an invalid operand 0 carrier.
- [x] `CallPtr` independently rejects an invalid operand 1 carrier.
- [x] Targeted and full native/wasm-gc test gates remain green.
