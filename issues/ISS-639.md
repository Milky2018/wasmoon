## Description
Native test helpers currently include jit_ffi/jit_internal.h across package boundaries and allocate private activation structs. Place private-layout operations under the implementation owner, preserving existing MoonBit test imports and behavioral coverage.

## Design
Start from complete executable paths and explicit ownership. Reuse the existing hostcall and root-visitor conventions; preserve machine layout and direct access where required. Move decisions with their state and delete old implementations. Do not equate wrapping C in more FFI functions with migration, or claim the complete architecture is repaired after one slice.

## Acceptance Criteria
- [x] Remove cross-package allocation and field access of jit_ffi private layouts by native test support.
- [x] Preserve test imports and coverage without public getters for internal fields or duplicated layout definitions.
- [x] Review remaining shared native headers and retain only justified small contracts with clear ownership.
- [x] Validate archive membership, strict C, native/ASan tests and Windows compiler/assembly paths; keep ISS-634 toolchain tracking independent.
