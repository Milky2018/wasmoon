## Description
AArch64 constant-displacement address folding unconditionally marks the matched
unsigned I32-to-I64 extension result as skipped. If that extended value has a
second use, lowering later fails with `MissingMappedValue` because its defining
instruction was removed globally.

The minimal dual-use pattern succeeds before commit `5d7e7fec` and fails after
the constant-displacement fold introduced there.

## Design
Use the existing folded-use accounting to decide whether the extension result
is dead. The address fold should count only the use it consumes and must not
force the extension into the unconditional skipped-result set. Preserve
constant displacement selection while retaining the extension when another use
remains.

## Acceptance Criteria
- [x] A constant extended index can be folded into a memory displacement while the extended value remains available to another use.
- [x] Single-use constant extended indices are still eliminated.
- [x] Focused AArch64 lowering tests and the strict native test suite pass.
- [x] Formatting, interfaces, native checks, and module-boundary audit pass.
