## Description
ISS-176 currently claims differential allowed/denied coverage even though the existing tests primarily exercise polling. A shared behavioral matrix is required to prevent the interpreter and JIT rights implementations from drifting.

## Design
Build black-box WASIp1 cases that run through both interpreter and JIT modes. Cover each operation family with allowed, missing-right, post-attenuation, and unrelated-right cases, including observable checks that denied path operations did not mutate the host filesystem.

## Acceptance Criteria
- [ ] Descriptor, path, socket, polling, and attenuation families appear in the matrix.
- [ ] Each family covers allowed, missing, attenuated, and unrelated-right behavior where applicable.
- [ ] The same guest programs run in interpreter and JIT modes with matching results.
- [ ] Denied mutating operations are proven side-effect free.
- [ ] ISS-176 acceptance criteria are re-audited and the parent closes only when all are satisfied.
