## Description

The `pwhash_scrypt_ll` SMix driver (`func_43`) contains 934 Wasmoon
instructions and 128 branch instructions, compared with 840 instructions and 80
branches in Wasmtime. Wasmoon emits multiple branch-only trampolines and
indirect structured-control transfers that survive through final Target VCode
layout. Its code is 3,736 bytes versus 3,360 bytes for Wasmtime.

This is secondary to the BlockMix and Salsa allocator defects, but it adds
front-end pressure and recurring control-flow overhead around the two
memory-hard SMix phases.

## Design

Identify branch-only blocks and redundant branch chains after semantic lowering
and before final layout. Thread edges and choose fallthroughs using a generic CFG
and target-layout pass. Preserve explicit trap edges and block-argument
transfers; do not recognize Scrypt-specific control flow.

## Acceptance Criteria

- [ ] A focused CFG/layout test covers branch-only block threading and
      fallthrough selection with block arguments.
- [ ] `func_43` contains no avoidable branch-only trampoline chain.
- [ ] Its final AArch64 branch count falls from 128 to at most 90 without
      increasing code size.
- [ ] Trap, loop, and structured-control semantics remain unchanged.
- [ ] Native and recursive WAST suites pass.
