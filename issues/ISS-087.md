# ISS-087: Move Wasmoon debug and GC context offsets out of machv_emit

## Metadata
- Type: task
- Status: open

- Updated: 2026-07-07

## Description
`machv_emit` still directly reads and writes debug-current-function and GC allocation cursor/limit offsets from `EmbeddingContextLayout`. Those are Wasmoon runtime fields, not generic emission concepts.

## Design
Move Wasmoon-specific debug/GC offset expansion into Wasmoon-owned lowering or represent the accesses as generic context-slot reads/writes before emission. The generic emitter may emit ordinary loads/stores and traps, but it must not name or interpret debug/GC runtime fields.

## Acceptance Criteria
- [ ] `machv_emit` no longer references debug-current-function or GC allocation field names.
- [ ] Existing debug and GC behavior is preserved through Wasmoon-owned slot mapping or pre-lowered instructions.
- [ ] `machv_emit` APIs remain generic and do not require Wasmoon VMContext field schema.
- [ ] GC/debug-related tests and WAST gates pass.
