## Description
Ordinary struct and array projections repeatedly call generic accessors. Single
heap hints also lose previously admitted objects while traversing larger structures.
Reuse complete checked keys without copying all admission logic into each site.

## Design
See [checked object views and native root links](../docs/perf/object-root-fastpaths.md).
Use sixteen non-root hints per kind and optional bounded loop hit expansion. Preserve
all nominal, shape, null, subtype, legacy, verification and physical-lifetime
checks. Keep the existing allocation-layout API compatible.

## Notes
- Mechanical complete-check expansion was rejected: all twenty measured pairs
  regress, with median changes +15.74%, +13.21%, +6.15% and +9.99%. A simple
  caller grows from 52 to 500 bytes; the parent's shared helper lies outside
  those 52 caller bytes.
- Shared-cache and hit-expansion effects are measured independently. The
  bounded-loop combination passes a complete 8,384-test screen in 233.567269 s
  against the parent 253.287638 s. Independent final confirmation remains due.
- The original 200 async selections are not executed by the official SDK28
  Wasm test driver either; no new test skip is introduced.
- After root/struct specialization, post-compiler samples still locate array
  projection helper costs. A separate array extension passes its predeclared
  hot-module threshold: paired medians -4.12%, -6.72%, -11.51%, +0.50%.
  The five sorted-map regressions are retained. Full aggregate confirmation
  and exact-head platform acceptance remain required.
