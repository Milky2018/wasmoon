## Description
Implement the repository-pinned Preview 3 async command imports over the same
capability context as Preview 2. Preview 3 uses Component Model async
future/stream behavior rather than the Preview 2 `wasi:io` resource protocol.

## Design
Generate or derive exact interface signatures from the pinned WIT snapshot and
map them to the component runtime's typed future, stream, task, and error
context semantics. Keep the version explicit because Preview 3 is not stable.

## Acceptance Criteria
- [x] All imports in the pinned Preview 3 `wasi:cli/imports` world are present.
- [x] Cross-task borrows, stream/future completion, cancellation, and instance
      poisoning follow the current async ABI.
- [x] Preview 3 filesystem and socket operations preserve the Preview 2
      capability policy.
- [ ] Pinned Preview 3 command components pass focused and matrix tests.

## Notes
- 2026-07-27: Added asynchronous host functions and cancellation plumbing to
  the generic runtime, then implemented Preview 3 monotonic `wait-until` and
  `wait-for` as reactor-driven host futures. The rest of the async command
  world remains open.
- 2026-07-27: Added canonical compound stream-payload layout, embedding byte
  stream/result-future construction and consumption, subtask progress while an
  async host call is pending, and native-fd reactor sources. Preview 3 stdin,
  stdout, stderr, and terminal imports now use those runtime seams. Filesystem
  and sockets remain open.
- 2026-07-27: Implemented the pinned Preview 3 filesystem interfaces over the
  Preview 2 capability-rooted descriptor policy. File reads and writes use
  canonical byte streams and completion futures; directory entries use a new
  typed host-stream seam which lowers compound values into the reader's memory
  so embedded strings never retain writer-side pointers. Socket interfaces and
  command-level matrix coverage remain open.
- 2026-07-27: Corrected the embedding completion seam so host futures allocate
  canonical future endpoints instead of masquerading as stream handles. Added
  nonblocking dynamic host-stream producers and reactor-driven completion of
  pending reads as the runtime foundation for Preview 3 TCP receive and listen
  streams.
- 2026-07-27: Added all pinned Preview 3 socket exports. TCP connect/send,
  UDP send/receive, name lookup, accepted-connection streams, receive byte
  streams, and completion futures use nonblocking native descriptors driven by
  the existing host reactor. Deny-by-default and loopback-only policies have
  focused regression coverage. The official command-level matrix remains the
  closing gate.
