## Description
The refreshed70-case screen leaves randombytes about24% behind serial Wasmtime
in repeated paired value measurements. Current native samples implicate checked
callable resolution. Removing register frames alone fails to establish a useful
cross-case gain; the type and executable queries also need joint optimization.

## Design
Inline the existing private resolver into its call boundaries so the C compiler
can reuse context/reference/registry queries. Keep rare legacy subtype dispatch
private and move the unchanged conditional trap/zero-result contract into the
existing trap module. A nontrapping table lookup lets callers report bounds
failure before reading entries. Preserve type-before-executable failure order,
Store/legacy encodings, subtype checks, publication, reentry, close, roots,
quotas and scheduling. No new cache, metadata layout, public helper signature,
MoonBit API, artifact format or global compiler flag.
