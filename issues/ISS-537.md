## Description
Ordinary guest calls consume native recursion and are capped at 256 frames. Nested control flow and composed suspension closures also consume native stack. Replace these with one iterative interpreter while retaining JIT and scheduling behavior.

## Design
Explicit execution frames retain instruction positions, control boundaries, saved module instances and stack heights. Existing leaf instructions and host suspension actions remain reusable. Apply configurable frame, control and value-slot budgets, including locals, and a separate Store-local host reentry bound. Preserve tail calls, exceptions, GC roots, cancellation and single-use continuation ownership.

## Acceptance Criteria
- [x] Deep ordinary calls and structured control execute without proportional native recursion.
- [x] Frame/control/value budgets fail predictably and release invocation state; tail calls do not accumulate frames.
- [x] Deep suspension/resumption, exceptions, GC and host reentry have public regression coverage.
- [x] Existing native and external dual-engine suites pass across all four CI targets.
- [x] Record before/after representative interpreter performance and document limits.
