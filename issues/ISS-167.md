## Description
MilkIR has extensive white-box coverage but only five README black-box examples. Add a dedicated black-box suite that exercises the reusable package as an external consumer and protects the documented public facade.

## Design
Add cohesive `*_test.mbt` files for public construction and printing, verification failures reachable through public APIs, CFG queries, optimization behavior, and scalar/call/memory/vector/extension operations. Keep malformed-internal-state and private-pass tests in the existing white-box suite. Do not change implementation code, public APIs, or visibility for test convenience.

## Acceptance Criteria
- [x] Dedicated MilkIR `*_test.mbt` files are compiled by MoonBit's black-box test harness.
- [x] At least twenty focused tests cover construction, verification, CFG, optimization, call, memory, vector, and extension seams.
- [x] Tests use only the existing public interface and do not require implementation or visibility changes.
- [x] New tests pass on every supported target; full native tests and module-boundary audit pass.
- [x] `moon info` produces no MilkIR public-interface changes.
