## Description
Component input crosses parser, validator, linker, Canonical ABI, WASI host,
and CLI boundaries, but the repository has no component-specific security audit
that locks validation order, stable API isolation, unsafe termination policy,
bounded arithmetic, and hardening evidence.

## Design
Add a deterministic source/interface audit with explicit allowlists for
generated-contract invariants. Verify facade dependency direction, validation
before instantiation, absence of implementation types in stable interfaces,
forbidden abort/unchecked-conversion patterns in untrusted paths, and presence
of all hardening reports.

## Acceptance Criteria
- [x] Stable facade interfaces contain no `runtime_impl` types.
- [x] Component instantiation paths validate before linking or execution.
- [x] New abort and explicit unsafe conversions in untrusted component paths
      fail unless narrowly allowlisted with a reviewed per-file budget and
      rationale.
- [x] Fuzz, differential, lifecycle, sanitizer, and stress evidence is
      enumerated in a machine-readable audit manifest.
- [x] The audit has unit tests proving each missing invariant fails.
