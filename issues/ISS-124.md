## Description
Extend counted-loop proofs from the initial I32 slice to signed and unsigned I64 loops without relying on overflowing host arithmetic.

## Design
Normalize increasing and decreasing predicates, implement checked distance and ceiling-division helpers, and conservatively reject wraparound, zero steps, mismatched directions, and unrepresentable trip counts. Cover signed and unsigned `<`, `<=`, `>`, and `>=` forms, including reversed compare operands and branch polarity.

## Acceptance Criteria
- [x] Signed and unsigned I32 and I64 counted loops compute exact trip counts.
- [x] Increasing and decreasing steps larger than one are supported.
- [x] Boundary values do not overflow analysis arithmetic.
- [x] Wraparound, zero-step, mismatched-direction, and dynamic cases are skipped unchanged.
- [x] Boundary-focused native and wasm-gc tests pass.
