## Description

The formal correctness matrix requires a fixed-seed Wasm-Smith JIT/interpreter differential corpus, but commit `7a54aabe` removed its manifest, wrapper, CI command, and tests without equivalent evidence.

## Design

Restore the checksum-pinned interpreter-oracle gate. Make interpreter mode require and execute only Wasm-tools and Wasmoon, not Wasmtime, while preserving hard failures for generation errors, empty corpora, timeouts, and semantic mismatches.

## Acceptance Criteria
- [x] A versioned seed/config manifest drives a deterministic corpus on both native targets.
- [x] Interpreter-oracle mode does not require or execute Wasmtime.
- [x] Generation errors, zero generated cases, distinct trap reasons, distinct runtime errors, and timeouts fail the gate.
- [x] Equivalent spellings of the same trap reason compare equal across runtimes.
- [x] Regression tests cover trap, runtime-error, and timeout comparisons.
- [x] The command and summary are retained in each cutover manifest.

## Close Notes

The runner now compares successful output, canonical trap reasons, and normalized runtime-error diagnostics including exit status. Timeout and unrecognized outcome kinds fail unconditionally, and the shrink predicate shares the same comparison path. `python3 -m unittest scripts/tests/test_cutover_gate.py` passed 17 tests, and the checksum-pinned 100-case interpreter-oracle corpus passed 100/100 with zero generation errors.
