## Description
The x64 native lowering turns direct comparison branches back into CompareSet,
zero-extension, TEST and Jcc. Emit CMP/Jcc directly and retain typed verification,
edge copies, fallthrough and branch threading.

## Design
One typed BranchCompare terminator has two width-checked inputs, no outputs and
two successors. Immediate comparisons retain the existing constant materialization.
The emitter shares the existing conditional-edge implementation with an explicit
condition and inverse; edge moves happen only after testing flags. No flags SSA,
new runtime state, or relaxed safepoint/root/barrier rules. Codegen revision28.
