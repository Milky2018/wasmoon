# ISS-089: Remove Wasm-named reference types from MilkIR core

## Metadata

## Description
`milkir.Type` still exposes `FuncRef` and `ExternRef` as public core type constructors. These names are WebAssembly reference-type spelling, so downstream users of MilkIR inherit Wasm vocabulary even when they are not building a WebAssembly frontend. This is a real public API leak, not just a stale comment.

## Design
Replace the Wasm-named constructors with generic reference categories owned by MilkIR. Keep Wasm spelling in `wasm_milkir`, where `funcref` and `externref` are translated into the generic MilkIR taxonomy. Do not add compatibility aliases in MilkIR, because that would preserve the leaking API.

## Acceptance Criteria
- [x] `milkir.Type` exposes no `FuncRef` or `ExternRef` constructors.
- [x] `wasm_milkir` owns the mapping from Wasm `funcref` / `externref` to generic MilkIR reference types.
- [x] Reusable modules contain no Wasm-named reference type constructors except Wasm-owned packages.
- [x] `moon info`, `moon fmt`, `moon check --target native --warn-list +73 --diagnostic-limit=200`, `moon test --target native --warn-list +73 --diagnostic-limit=200`, `python3 scripts/audit_module_boundaries.py`, and `git diff --check` pass.
