## Description
Complete compiler profiles put lowering and register allocation near one third
each, with substantial host reference-counting and allocation cost. Test value
representation for private immutable temporary facts before redesigning storage.

## Design
Reuse canonical owner-tagged Instruction handles through a private dense vector.
Both builder insertion paths publish the existing handle; flat queries reuse it
without loading the larger instruction record. Ownership tokens, bounds,
identity, mutable metadata queries and the public reference representation stay
unchanged. The vector does not retain a Function or introduce a cycle.
