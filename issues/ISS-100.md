## Description
`wasm_milkir/reference_encoding.mbt` keeps `FUNCREF_NULL_SENTINEL = -1` for older index-form funcref encodings even though the canonical null representation is `NULL_REF = 0`.

## Design
Verify that no live lowering/runtime path needs the sentinel, remove it, and keep `NULL_REF` as the single null reference encoding.
