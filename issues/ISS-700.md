## Description
An effective current regex2100 CPU sample has 1264/3848 main-thread samples in
struct_data, plus 857 in graph tracing. Diagnostic counters at f382e14 observe
113567720 struct-view requests for regex700 and 84061688 for parse_double. Cached
or uncached exact types account for 78.3% and 97.8%; other identities retain the
registered subtype/legacy path. Counter instrumentation is restored exactly and
its builds/caches removed. Instrumented timings are not performance evidence.

## Design
An optional embedding-supplied identity-directory offset and the existing captured
heap layout permit bounded read-only admission in generated code. Re-read current
context/heap/type bindings; check encoded reference, live identity page/offset,
header kind/count/nominal identity and canonical layout prefix. Unknown settings,
verification/fault mode, subtypes, legacy or mismatching metadata retain the same
complete helper. Do not introduce a pointer/type cache, mutate heap state or cross
a call/safepoint/reentry with a physical borrow. Missing capability keeps helpers.
An independent four-site bound limits selector CFG and code growth. Existing
allocation policies and all 56 captured ABI values remain unchanged.
