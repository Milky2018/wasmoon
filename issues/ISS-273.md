## Description
Implement the resource-free stable Preview 2 interfaces for command
environment, process exit, clocks, and secure/insecure random data.

## Design
Read arguments, environment, initial working directory, clock providers, random
providers, and exit policy from `WasiComponentCtx`. Process exit must unwind as
a structured host result rather than terminate the embedding process.

## Acceptance Criteria
- [x] `wasi:cli/environment`, `wasi:cli/exit`, wall clock, monotonic clock, and
      random interfaces match the pinned stable Preview 2 signatures.
- [x] Clock arithmetic is checked and monotonic deadlines do not wrap.
- [x] Secure random uses the operating system provider; deterministic insecure
      random is configurable for tests.
- [x] Exact component import and invocation tests pass.
