# ISS-561: Tie HTTP response timeouts to body progress

## Description
After the first response body byte, each socket read restarted the between-byte timeout. A peer could dribble chunk extensions or trailers indefinitely without body progress. Keep one deadline across framing reads and refresh only after body data delivery. Exclude consumer backpressure from the next read budget.
