## Description
Parse and execute WAST thread/wait directives with cooperative guest scheduling in both engines. Give each script thread an independent Store, retain actual shared native memories across contexts, join child scopes, and cancel pending invocations before releasing contexts. Separate module preparation/start and action execution/assertion checking so suspended work resumes exactly once through the selected engine.

## Acceptance Criteria
- [x] All eleven unmodified misc threading/pooling/GC scripts pass in both engines.
- [x] Nested and implicit joins, wait-before-notify, producer loops, and suspended module starts have positive and negative controls.
- [x] Child contexts share memory owners and module definitions without sharing Store-local addresses.
- [x] Script cleanup cancels suspended invocations before closing their Stores.
- [x] Native and ASan checks pass; all external lanes are rerun with remaining failures explicitly recorded and no source exclusions.
