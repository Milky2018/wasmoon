## Description
Create `modules/milkir` as the reusable Cranelift-like generic SSA IR. MilkIR must not be semantically owned by WebAssembly and must not contain Wasm-specific opcodes for memory, table, global, GC, exception, or runtime operations.

## Design
Start with MilkIR Core: SSA values, block parameters, generic scalar/vector/reference carrier types, arithmetic, comparisons, select, load/store/address operations, direct and indirect calls, branches, returns, traps, function signatures, external symbols, stack slots, and metadata for stack maps, source mapping, or runtime lowering. Keep known limitations explicit with scoped `TODO(milkir)` comments, but do not make TODOs a correctness gate.

## Acceptance Criteria
- [ ] `milkir` defines function, block, value, type, instruction, signature, external symbol, stack slot, and metadata models.
- [ ] MilkIR has no dependency on `wasm_core`, `wasmoon_jit`, or `wasmoon`.
- [ ] Wasm-specific concepts are absent from core MilkIR opcodes.
- [ ] Known incomplete areas include scoped `TODO(milkir)` comments.
- [ ] MilkIR has basic construction, formatting, and verification tests.
