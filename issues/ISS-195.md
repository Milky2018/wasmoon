## Description

Implement the final target-neutral MachV semantic IR, including construction, printing, verification, and mandatory cleanup, without routing production compilation through it yet.

## Design

- Represent semantic machine operations, block parameters, calls, effects, traps, safepoints, and abstract values without target opcodes, physical registers, encodings, or ABI facts.
- Reject foreign ownership, malformed SSA/CFG, invalid signatures, and illegal operation contracts at construction or verification boundaries.
- Keep the public surface deep and minimal; target and compatibility concerns remain outside the module.

## Acceptance Criteria

- [ ] The semantic MachV IR, builder, printer, verifier, and mandatory cleanup pipeline implement the contracts decided by ISS-181 through ISS-191.
- [ ] Blackbox tests snapshot complete functions and cover ownership, SSA dominance, CFG edge arguments, types, signatures, effects, traps, calls, and safepoints.
- [ ] Negative compile-time or dependency tests show that target opcodes, physical registers, encodings, and ABI-specific facts cannot enter semantic MachV.
- [ ] The semantic module has no dependency on `machv_legacy`, target packages, regalloc, emitters, or Wasmoon product packages.
- [ ] Production JIT behavior remains on the unchanged legacy path.
- [ ] The common ISS-192 quality gates pass.
