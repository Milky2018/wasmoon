## Description
Implement stable Preview 2 network, TCP, UDP, and IP name lookup interfaces
with pollable socket resources.

## Design
All socket creation, bind, connect, listen, accept, datagram, and name lookup
operations must pass through an embedding-provided network policy. No ambient
network access is enabled by default.

## Acceptance Criteria
- [x] Preview 2 network, TCP, UDP, and IP name lookup signatures are complete.
- [x] Socket state transitions and error codes are validated structurally.
- [x] Pollables reflect connect, accept, receive, and send readiness.
- [x] The default context denies all network access.
- [x] Loopback integration and denied-capability tests pass.
