## Description
Restoring `compare_jit_interp` to the production-loaded native JIT path exposed a hang in `table64 table.grow`. Table64 `table.size` returns, but the grow helper does not return through the production JIT call path. The testsuite harness currently guards all `TableGrow` instructions until the helper ABI is debugged, because the compatibility gate must prevent hangs before it can reliably distinguish all table definitions.

## Design
Debug the native `table.grow` runtime helper ABI for table32 and table64 tables. Confirm how the helper receives the table index, nullable funcref initial value, delta, and return value. Keep the fix in shared production JIT setup rather than the testsuite harness.

## Acceptance Criteria
- [x] `table64: table.grow takes and returns i64` returns through production-loaded native JIT.
- [x] `table32: table.grow takes and returns i32` returns through production-loaded native JIT.
- [x] `compare_jit_interp` can remove its `TableGrow` compatibility guard.
- [x] Add or keep a focused regression test for table64 grow.
- [x] `moon test modules/wasmoon/testsuite/memory64_test.mbt --target native --warn-list +73 --diagnostic-limit=200` passes without compatibility fallback.
