## Description
The CI contract test separately hard-codes the number of sanitizer commands
and selected target spellings. Adding or removing a target requires updating
the workflow, individual assertions, and an unrelated count literal.

## Design
Parse the sanitizer step's MoonBit test targets, reject duplicates, and compare
the resulting set with one explicit expected target set.

## Acceptance Criteria
- [x] Sanitizer target membership has one expected source of truth in the test.
- [x] Duplicate commands are rejected.
- [x] The current nine targets are all covered.
- [x] Python gate tests pass.

## Close Notes

The CI contract test now isolates the sanitizer workflow step, parses every
MoonBit test target, rejects duplicate entries, and compares the resulting set
with one explicit expected set. The separate command-count and selected-target
assertions were removed.

The focused sanitizer gate test and all 60 Python tests pass.
