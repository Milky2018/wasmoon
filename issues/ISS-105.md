# ISS-105: Hide backtracking allocator internals from regalloc root API

## Description
The root `regalloc` package exposes backtracking implementation machinery such as queue entries, spillset state, hint caches, conflict scanners, split planners, eviction probes, fixed-constraint edit plans, and the allocation loop. These are not a clean compiler-infrastructure API; they are implementation internals leaked because `machv_regalloc` currently assembles the algorithm directly.

## Design
Move `machv_regalloc` toward a higher-level regalloc integration so it does not need to construct or call the backtracking engine internals directly. Once no external package depends on these details, remove their public visibility from the root package. If an expert hook remains necessary, it must be intentionally named and documented as such rather than mixed into the ordinary root API.

## Acceptance Criteria
- [x] `machv_regalloc` no longer depends on low-level `@regalloc.Backtracking*` engine state or planner helpers.
- [x] Backtracking queue, spillset, hint, conflict-scan, split, eviction, and loop helpers are not public root APIs.
- [x] Behavior is unchanged for existing MachV allocation tests and WAST smoke coverage.
- [x] `moon check --target native --warn-list +73 --diagnostic-limit=400` passes.
