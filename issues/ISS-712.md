## Description
Fresh exact-head repeated-probe samples put about41% of main-thread leaf samples
in gc_struct_data_impl. Isolated counters on the original ten-call probe report
392470983 struct projections with95.6% hits, so single-entry cache thrashing is
not the main issue. Machine code nevertheless builds/restores an80-byte frame
on every hit because the same function contains complete slow-path calls.

## Design
Keep the existing non-root hint, key and lifetime invalidation protocol. A small
entry checks a matching admitted key; malformed references/field spans cannot
match an admitted entry. Misses, verification mode and implicit-TLS calls use
the unchanged complete checked body in a private non-inlined function. This lets
the C compiler generate a leaf hit path without expanding guest IR. Preserve
all traps, nominal/layout checks, aliases, callbacks, quotas and GC/root policy.
No storage layout, public helper signature, artifact or calling-convention change.
