## Description
Fresh exact-head repeated-probe samples put about41% of main-thread leaf samples
in gc_struct_data_impl. Isolated counters on the original ten-call probe report
392470983 struct projections with95.6% hits, so single-entry cache thrashing is
not the main issue. Machine code nevertheless builds/restores an80-byte frame
on every hit because the same function contains complete slow-path calls.

## Design
Keep the existing non-root hint, key and lifetime invalidation protocol. A small
entry checks reference/shape/span before canonical type lookup. On a miss, pass
the already located heap into the private checked body rather than resolving
its dynamic layout and probing the same hint twice. No calls or mutation occur
between these paths. Implicit TLS and verification entries retain resolution
and their original hint/checked fallback. Preserve all reference bounds, traps,
nominal/layout checks, aliases, quotas and GC/root policy. No public helper
signature, storage layout, artifact or calling-convention change.
