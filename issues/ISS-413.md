# ISS-413: Implement an independent linear-time fast allocator

## Metadata

- Status: closed

## Description

`AllocatorStrategy::SinglePass` is misleading: it invokes the same bundle
pipeline as backtracking and merely disables eviction. It is neither a single
pass nor a bounded-complexity fallback.

## Design

Delete the current strategy behavior and implement a separate reverse linear
scan allocator with dense current-allocation tables, per-class register
availability, deterministic eviction, dedicated spill homes, and direct move
insertion. Keep the backtracking pipeline separate; do not share its bundle
state merely to reduce code duplication.

## Acceptance Criteria
- [x] `SinglePass` is removed; `Fast` does not enter the bundle allocator.
- [x] The fast allocator traverses instructions once in reverse layout order
      with bounded work per operand and CFG edge.
- [x] Every current operand constraint is handled by the shared plan contract;
      invalid register preferences still fail explicitly.
- [x] Differential tests cover straight-line code, branches, loops, fixed and
      tied operands, clobbers, and register pressure.
- [x] Native warning check, the complete regalloc suite, and the full native
      workspace suite pass.
- [x] Large-function compile time and generated-code quality are compared
      against backtracking.

## Close Notes

- Removed `SinglePass` from the public enum and documentation. `Fast` has its
  own entry point and never constructs bundles, spillsets, the range treap, or
  either backtracking queue.
- Fast allocation builds dense end-point buckets, scans blocks and program
  points once in reverse layout order, and keeps one active segment per
  physical register. Eviction is deterministic and bounded by the machine's
  register count.
- Fixed, tied, clobbered, branch, loop, and pressure cases pass through the
  same independent symbolic verifier as Backtracking.
- `moon check modules/regalloc --target native --warn-list +73` passed.
- `moon test modules/regalloc --target native --warn-list +73` passed: 86/86.
- On the 12,993-instruction spilling workload, seven runs reduced median total
  regalloc time from 39,275 us to 22,333 us (-43.1%); the allocation core was
  1,828 us. Output grew from 78,264 to 78,356 bytes, reloads from 9,003 to
  9,027, spills fell from 5,355 to 5,354, and dedicated fast-path spill homes
  increased slots from 201 to 754.
- `moon test --target native --warn-list +73` passed: 2644/2644.
