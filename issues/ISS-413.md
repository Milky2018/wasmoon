# ISS-413: Implement an independent linear-time fast allocator

## Description

`AllocatorStrategy::SinglePass` is misleading: it invokes the same bundle
pipeline as backtracking and merely disables eviction. It is neither a single
pass nor a bounded-complexity fallback.

## Design

Delete the current strategy behavior and implement a separate reverse linear
scan allocator with dense current-allocation tables, per-class register
availability, deterministic eviction, dedicated spill homes, and direct move
insertion. Keep the backtracking pipeline separate; do not share its bundle
state merely to reduce code duplication.

## Acceptance Criteria
- [ ] `SinglePass` no longer aliases the bundle allocator with eviction off.
- [ ] The fast allocator traverses instructions once in reverse layout order
      with bounded work per operand and CFG edge.
- [ ] Unsupported operand constraints fail explicitly rather than silently
      weakening correctness.
- [ ] Differential tests cover straight-line code, branches, loops, fixed and
      tied operands, clobbers, and register pressure.
- [ ] Native warning check and full native test suite pass.
- [ ] Large-function compile time and generated-code quality are compared
      against backtracking.
