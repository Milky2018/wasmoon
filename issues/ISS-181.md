## Question

Which operations may exist in target-neutral MachV, what legalization must MilkIR-to-MachV lowering complete, and what precise rule excludes encoding-oriented instructions while permitting any genuinely target-neutral semantic superinstructions?

## Design

An operation may enter MachV only when all of the following hold:

1. Its operands, results, target-neutral attributes, effects, and trap behavior are sufficient for the MachV verifier to define its complete contract without consulting a host ISA or ABI.
2. It is either a target-neutral primitive required after semantic legalization, or a semantic superinstruction whose decomposition would change observable rounding, atomicity, trap behavior, or effect boundaries.
3. It does not encode a host instruction form, physical register or flag constraint, ABI placement, immediate range, addressing mode, trap payload encoding, or performance-only fusion.

MilkIR-to-MachV lowering removes source dialect concepts and makes widths, calls, memory behavior, effects, and traps explicit. MachV target lowering then selects instructions, applies the ABI, introduces physical constraints, and expands unsupported operations into Target VCode.

- 2026-07-15: MachV will not define a stable bytecode, VM ABI, or production interpreter contract. A future production portable interpreter would be a separate downstream target; a debug interpreter may traverse MachV without defining its format.
- 2026-07-15: MilkIR-to-MachV performs semantic legalization only: it removes dialect concepts and makes widths, effects, traps, memory behavior, and call signatures explicit. Target legalization owns instruction availability, physical constraints, and multi-instruction expansion.
- 2026-07-15: A fused operation belongs in MachV only when decomposition changes observable rounding, atomicity, trap behavior, or effect boundaries. Encoding conveniences such as shifted adds, integer multiply-add, compare-select, conditional helper calls, and target extract forms remain target-side fusion opportunities.
- 2026-07-15: Non-atomic memory operations form parameterized semantic load/store families over an already-computed pointer, access width, result or stored value behavior, extension, byte offset, and endianness. Atomics are a distinct semantic family; host addressing modes and Wasm memory indices are excluded.
- 2026-07-15: Calls carry target-neutral callee identity (direct, external, or indirect), signature, explicit arguments and results, normal or tail-call kind, and memory, trap, unwind, and safepoint effects. Hidden context is an ordinary explicit operand when present. ABI registers, stack argument areas, physical clobbers, result locations, prologue and epilogue mechanics, and performance-only call fusion belong to Target VCode lowering.
- 2026-07-15: Explicit traps are unconditional terminators with structured target-neutral reasons. Conditional traps are ordinary compare-and-branch control flow to a trap block rather than `TrapIf*` operations. Division, conversion, memory, and other implicitly trapping operations declare their trap conditions and effects; Target VCode lowering preserves them with explicit checks, hardware traps, or helper calls and owns any encoded trap payload.
- 2026-07-15: Scalar arithmetic, comparison, constants, and conversions carry exact operand and result widths. Signedness, rounding, saturation, bit reinterpretation, and trapping modes are explicit only where they change semantics; floating constants preserve their bit patterns. Carry and overflow may be explicit SSA results when semantically consumed, but MachV has no machine condition flags, fixed-register forms, shifted or extended operands, or immediate-encoding variants.
- 2026-07-15: The current vector contract is limited to `V128`. Vector operations use parameterized lane shapes only where lane interpretation changes meaning; bitwise operations remain lane-agnostic, and shuffle masks or lane indices are semantic immediates. Whole-vector loads and stores reuse semantic memory access, while splat, lane, and narrow accesses whose result layout is observable remain parameterized semantic vector operations. Target SIMD intrinsics, opcode-per-lane duplication, and speculative wider or scalable vectors are excluded.
