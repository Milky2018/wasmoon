## Description
Integrate the proven loop-unroll module into the production O3 pipeline and validate observable behavior against the interpreter across arithmetic, loop-carried state, memory effects, calls, traps, and boundary cases.

## Design
Keep the O3 driver disabled until all prerequisite slices are closed. Add an opt-level-aware differential test seam, deterministic generated counted-loop cases, code-growth limits, documentation of supported and rejected loop forms, and full repository quality gates.

## Acceptance Criteria
- [ ] O3 invokes safe loop unrolling only after a complete `Apply` decision.
- [ ] Unsupported loops remain unchanged and do not make optimization fail.
- [ ] Interpreter and O3 JIT results match for reductions, odd/even trips, memory effects, calls, and traps.
- [ ] Deterministic generated loop cases cover supported predicate and step combinations.
- [ ] MilkIR and architecture documentation describe the actual supported subset.
- [ ] Native, wasm-gc, regalloc-validation, boundary-audit, and repository test gates pass.
