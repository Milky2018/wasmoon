## Description
Extract the reusable WebAssembly specification model into `modules/wasm_core`. This module should own spec-level concepts needed by parsers, validators, and frontends, without depending on compiler backend or Wasmoon runtime code.

## Design
Move or recreate the Wasm value, block, function, module, memory, table, global, tag, type, and index-space models behind a clean `wasm_core` boundary. Keep runtime store, instantiation state, executor behavior, MilkIR lowering, MachV, JIT, and WASI outside this module.

## Acceptance Criteria
- [x] `wasm_core` exposes spec-level Wasm data structures needed by parser and validator code.
- [x] `wasm_core` has no dependency on `milkir`, `machv`, `wasmoon_jit`, or `wasmoon`.
- [x] Parser/validator users can import the extracted model from `wasm_core`.
- [x] `moon check` passes for `wasm_core` and direct dependents.
