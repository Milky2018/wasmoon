## Description
`modules/wasmoon_jit/strategy.mbt` exposes CompilationQueue, CompilationStrategy, TieredConfig and associated request/decision APIs. At `7dec3153`, repository call-site inspection found no production consumers: references are confined to their implementation, generated interfaces/trait support and `strategy_wbtest.mbt`, which contains 15 tests.

This maintains a separate scheduling subsystem without a production integration. Repository non-use does not establish that published public APIs have no external consumers.

## Design
Check public compatibility and the intended supported feature set, then remove the unused subsystem and its dedicated tests, or explicitly deprecate it with a bounded removal plan if compatibility requires a transition. Do not implement tiered execution merely to justify retaining scaffolding. Review dependencies before removing anything shared with actual runtime compilation.
