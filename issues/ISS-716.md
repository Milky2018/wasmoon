## Description
Code-site emission and target validation copy complete instruction metadata,
including GC-root arrays, while consuming only immutable annotation fields.

## Design
Expose an opaque owned InstructionAnnotations view with four immutable queries.
Check instruction ownership and bounds once. Preserve full snapshot isolation,
root/symbol handling, site emission, all verifier policies and codegen29.
The view retains metadata independently of the Function lifetime.
