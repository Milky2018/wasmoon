## Description
Create `modules/machv_regalloc` as the adapter between MachV functions and the pure `regalloc` module.

## Design
Project MachV functions into the abstract `regalloc` program view, run allocation, and apply decisions back to MachV by rewriting operands and inserting moves, reloads, spills, and stack-frame edits. Keep allocator policy generic, and keep MachV-specific mutation in this adapter.

## Acceptance Criteria
- [ ] `machv_regalloc` can allocate a MachV function using `regalloc`.
- [ ] `regalloc` remains independent of MachV concrete instruction data structures.
- [ ] Existing VCode regalloc behavior is preserved for current correctness tests.
- [ ] Known incomplete adapter behavior includes scoped `TODO(machv_regalloc)` comments.
