## Description
Remove the redundant MilkIR vector AndNot opcode while preserving the v128_andnot builder and Wasm semantics. Follow Cranelift's canonical bitwise representation without losing efficient target selection. GlobalValue is outside this change.

## Design
The builder emits And(a, Not(b)). Shared native selection recovers target AndNot for either operand order only when every use of Not is absorbed. Otherwise retain the original Not/And operations to avoid redundant x64 complement/move sequences. Target operation sets retain AndNot. Keep shared/returned negations and preserve operand order on both architectures.

## Acceptance Criteria
- [x] MilkIR has no AndNot opcode; the builder emits canonical nodes.
- [x] Native selection covers commuted, shared, separately used and identical operands.
- [x] Both target emitters preserve efficient code and executable SIMD regressions pass.
- [x] Generated interfaces, strict checks, native tests and external regressions pass.
