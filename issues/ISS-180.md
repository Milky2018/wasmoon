## Destination

Produce a decision-complete architecture specification and migration route in which every Wasmoon native JIT path passes from MilkIR through target-neutral MachV, then through target-specific VCode, register allocation, and emission. The map is complete when implementation can be decomposed without making further architectural decisions.

- [`CONTEXT.md`](../CONTEXT.md) is the authoritative glossary and records the standing destination constraints established before this map was charted.

- This map plans the architecture. It does not carry implementation into the map.

## Not yet specified

- The exact schema or generation mechanism for MachV and target instruction definitions cannot be selected until the semantic contract and Target VCode interface are known.
- Serialization, cache compatibility, and Cwasm consequences cannot be specified until Wasmoon JIT artifact ownership is settled.
- Release/versioning consequences for downstream packages cannot be specified until public package boundaries and the migration route are known.
- Support policy for future machine targets beyond AArch64 and AMD64 remains fog until the first two target contracts are defined.

## Out of scope

- Implementing or migrating the compiler pipeline while this map is open.
- Turning MachV into an interpreter bytecode or adding a Pulley-style execution backend.
- Adding 32-bit host support or a third native ISA.
- Unrelated optimizer work or backend bug fixes that do not block an architecture decision.

## Acceptance Criteria

- [ ] Every child decision ticket is closed or explicitly ruled out of scope.
- [ ] `Not yet specified` is empty because all in-scope fog has either graduated into tickets or proved irrelevant.
- [ ] `Decisions so far` links every closed decision ticket without duplicating its detailed resolution.
- [ ] The resulting decisions specify module ownership, data contracts, verification seams, Wasmoon integration, and a migration route.
- [ ] Implementation work can be split into ordinary execution issues without reopening an architectural decision.
