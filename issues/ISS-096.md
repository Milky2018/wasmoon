## Description
`modules/wasmoon_jit/runtime_symbols.mbt` accepts `wasm.runtime.*` names by mapping them to `wasmoon.runtime.*`. This preserves an older naming convention and makes the runtime-symbol namespace less explicit.

## Design
Delete the alias fallback and require callers to use the canonical symbol names already registered by `RuntimeSymbolResolver::with_wasmoon_runtime_symbols`.

## Acceptance Criteria
- [x] `runtime_symbol_wasmoon_alias` is removed.
- [x] Runtime symbol resolution tests and JIT/WAST gates still pass without alias fallback.
