## Description
The root `regalloc` package publicly exposes internal analysis and planning helpers: dense CFG construction, reverse postorder, dominators, loop discovery, dense live sets, point-order binary searches, conflict scans, spill compaction, rematerialization planning, reload intervals, temp-register choice, and allocation policy helpers. These names make the package look like a bag of internals rather than a deep module.

## Design
Keep these helpers private to the root package unless they are deliberately promoted as stable standalone algorithms. Public APIs should be limited to user-facing allocation, verification, and intentionally documented utility surfaces. Tests for internals should use whitebox tests instead of forcing helper visibility.

## Acceptance Criteria
- [x] Internal CFG, liveness, conflict, rematerialization, reload, spill, and policy helpers are no longer exposed as ordinary root public APIs.
- [x] Any intentionally public helper is documented in the README with a stable use case.
- [x] Internal helper tests use whitebox access where needed.
- [x] `moon check --target native --warn-list +73 --diagnostic-limit=400` passes.
