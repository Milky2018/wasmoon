## Description
Several large packages still contain prefixed implementation families after the independent parser, translator, canonical ABI, and CLI packages are extracted. They are not yet accepted exceptions to the package organization rule.

## Design
For each family, identify owned state and the call/dependency graph, then extract a cohesive package or document a concrete reason to retain it. Avoid exposing private state merely to move files.

Review `wasmoon_jit/native_*` and `artifact_*`, `x64_target/emit_*`, `milkir/optimize/rewrite_*`, `wasmoon/component/runtime_impl` canonical/task/host/core families, `wasm_component/validator/section_*`, `regalloc/function_*`, `vcode/allocation_*`, and `wasmoon/wast/jit_*`.

## Acceptance Criteria
- [x] Every listed family has an ownership and dependency decision.
- [x] Independent subsystems are extracted with minimal APIs and acyclic imports.
- [x] Retained families have specific recorded justifications.
- [x] Existing public APIs, strict checking, and regression tests remain valid.

| `wasmoon/wast/jit_*` | Reference conversion, resumable calls, and memory/table synchronization share `JITModuleContext`, but do not depend on WAST command execution. | Extracted into `wast/jit`, including the context and opaque continuation/registration owners. Root exports remain compatible. `component_native` now imports the child directly instead of the WAST command runner. |
| `wasmoon_jit/artifact_loader` | Artifact compatibility and code-object validation depend only on the portable artifact, native types, and code-object packages. Installation consumes its public `LoadedArtifact` methods. | Extracted into `artifact/loader`; shared loader/installer fixtures live in `artifact/test_support`, imported only by tests. |
| `wasmoon_jit/native_*`, artifact producer/installer | `NativeExecutionState` owns exception and continuation arenas; `NativeCallable` owns an `InstalledTrampoline`. Installation and callable teardown therefore cross the filename groups. | Extracted `artifact/installer` with private executable-memory staging and installation rollback; `native/execution` owns invocation state, handle transitions, and arena retirement. `jit_ffi` owns the shared C archive and opaque native allocations. `NativeCallable` retains its installed trampoline through the public owner API. Context binding stays with the private context handle; compiler-side artifact production stays with private target compilation and code-object conversion. |
| `x64_target/emit_*` | Emission uses private frame layout and tail-call planning. `CompilationSession` calls unchecked allocation/frame/emission stages only after target validation through `SelectedFunction`. | Extracted raw instruction encoding into `x64_target/internal/emit`, with no parent import. Metadata, branch fixups, and frame-sensitive emission remain with their compilation session; unchecked stage functions stay private. |
| `milkir/optimize/rewrite_*` | Rules operate on `OptimizerSession` union rollback, staged candidate commit/discard, and scoped value numbering in `gvn.mbt`. | Extracted rules, session state, and GVN together into `optimize/internal/acyclic`. Shared CFG, opcode-effect, use-count, and materialization facts live in `internal/analysis`. The driver receives an immutable statistics snapshot; mutable sessions remain private. |
| Component runtime canonical/task/host/core families | `TaskRegistry` records reference `ConcurrentResources` and return contracts; host state and core continuations participate in shared close/cancel lifecycle. | Extracted `runtime_impl/core`: error definitions, core references and adapters, continuation leases, terminal close, instance-entry guards, and canonical/core boundary markers. Root handlers use operations rather than mutable marker arrays. Task/host/canonical handlers stay with the resource graph they mutate; see the retained-boundary rationale below. |
| Component validator `section_*` | Section validation mutates the same counts, type/signature tables, and resource identity environment used by the component traversal. | Keep section handlers with that validation environment; extracting individual handlers would publish the internal evolving state. |
| `regalloc/function_*` | Function liveness and allocation feed private `AllocationSession` phases, sharing live-range and clobber indexes. `FunctionView` is the existing external input seam. | Keep the function allocation implementation with its session; no separate public phase API is needed. |
| `vcode/allocation_*` | Builder and verifier directly inspect dense `Function` value/instruction storage and `Allocation` edit/location tables. | Keep them with the owners of those private representations; `allocation_types` already separates portable location types. |

The independent ownership boundaries above are extracted. Remaining families are implementation phases of the private owners described below, rather than additional independently callable packages.

## Final Ownership Review

- Executable mappings, staging, relocation, publication, and rollback now belong to `wasmoon_jit/artifact/installer`. `ExecCode` and failure injection remain private there. The producer integration test now installs through the public transaction and checks the resolved import address instead of calling a private resolver.
- `wasmoon_jit/native/execution` owns invocation IDs, resource reuse, active/parked transitions, release closures, and arena retirement. Its four state-machine tests move with it. `jit_ffi` compiles the existing C translation units once; opaque arena and memory handles cross the low-level boundary without exposing their representations. CI checks the new archive location for test-only symbols.
- Native context memory/WASI/hostcall/fiber adapters remain with `NativeJITContext`: they require its private `handle`, hostcall dispatcher, and execution buffers. `NativeCallable` captures that context and an opaque installed trampoline. Moving these methods individually would require a public raw-context accessor or a callback facade over the same private handle. Neither is justified for file organization. Target lowering and artifact production remain together because they consume private target compilation results and code-object fixups.
- `runtime_impl/core` owns execution requests, references, interpreter adaptation, continuations, lifecycle leases, entry guards, and error translation. Lifecycle counters and close callbacks remain opaque. Canonical suspension/trap storage stays private; parent handlers use getter/setter operations. The stable component interface still exposes no implementation owners.
- Canonical handlers, task registry, and host builders retain one shared graph: `CanonResources`, resource/stream/future tables, task return contracts, subtask completion, and cancellation all participate in that graph. `ComponentValue` also carries internal borrowed `CanonicalGuestString` data backed by canonical memory. Moving the value enum or individual handlers alone would export private memory/resource state; moving the entire graph to a renamed package would only relocate the same coupling. These remain together deliberately. Core execution no longer depends on this graph.
- Legacy type names remain reexported. Implementation callers spelling error constructors directly as `@runtime_impl.HostCallError` now qualify them through `@runtime_impl.ComponentRuntimeError::HostCallError`, following the relocated error owner. No error variants or runtime behavior changed.
