## Description
The native Wasm-to-MilkIR frontend no longer falls back to legacy IR, but several operators and structured-control-flow cases remain incomplete. Unsupported cases currently rely on production interpcall fallback, which is correct for Wasmoon but not enough for a broadly reusable compiler frontend.

## Design
Audit the remaining `TODO(ISS-026)` and `UnsupportedNativeLowering` cases. Implement reusable MilkIR lowering for high-value missing operators and control-flow constructs, and keep unsupported cases explicit with capability reporting. Avoid introducing Wasmoon-specific semantics into `milkir`.

## Acceptance Criteria
- [ ] Remaining structured `if`, label-stack branch, and branch-value cases are either lowered correctly or explicitly rejected with clear capability diagnostics.
- [ ] Memory64 and runtime-helper ABI limitations are aligned with the reusable embedding ABI from ISS-029.
- [ ] Operator coverage is expanded without reintroducing legacy IR/VCode.
- [ ] WAST JIT correctness remains green.
- [ ] `moon check --target native --warn-list +73 --diagnostic-limit=200` passes.
