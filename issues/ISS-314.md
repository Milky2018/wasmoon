## Description
Future and stream operations do not yet implement all current Component Async
state transitions. Cancellation, empty waits, partial copies, and transfers
within the same component can reach guest `unreachable` assertions.

## Design
Make the future/stream state machine explicit for pending, readable/writable,
closed, cancelled, and transferred endpoints. Preserve partial progress and
wake the owning task exactly once when a transition makes an operation ready.

## Acceptance Criteria
- [ ] `async/cancel-stream.wast` passes.
- [ ] `async/empty-wait.wast` passes.
- [ ] `async/partial-stream-copies.wast` passes.
- [ ] `async/same-component-stream-future.wast` passes.
- [ ] Existing closed, dropped, cross-task, and zero-length tests remain
  passing in interpreter and JIT modes.
