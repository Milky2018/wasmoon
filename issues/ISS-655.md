callback without converting ordinary errors/traps/cancellation into exceptions.

## Notes
- Original main reproduction: ordinary sync/async RuntimeError bypasses guest
  catch_all in interpreter and JIT, while a guest throw is caught. That behavior
  is correct; the missing feature was a distinct explicit transport.
- GuestException uses the established CleanupOwner/GcRootLease ownership model.
  A prepared handle rolls back until handoff; an executor-owned lease does not.
- Shared synchronous outcome classification keeps existing HostFunc signatures
  narrow. Async completion recognizes the typed signal before error stringifying.
- Native staging returns through MoonBit cleanup before guest exception delivery.
  v128 expands to two words, preserving following reference-slot masks.
- Eight portable and four actual-JIT regressions pass locally. Source is based on
  the diagnostics PR; this work has not merged or published a version.
