## Description

Target call lowering currently splits ABI knowledge across operand constraints and emitter-local register/stack shuffles. Capture the required atomic transfer behavior before replacing that implementation.

## Design

Keep semantic MachV calls target independent. Specify target VCode call transfer behavior through allocation and final emitted effects, including mixed register/stack arguments, cycles, spills, indirect callees, result-area pointers, and GC roots.

## Acceptance Criteria
- [x] Tests cover mixed register and stack arguments whose sources overlap ABI destinations.
- [x] Tests cover cycles, spills, duplicate sources, indirect callees, mixed register banks, and result-area pointers.
- [x] Safepoint tests prove that protected GC-root homes remain valid through call setup.
- [x] Existing call correctness tests remain green before production cutover.
