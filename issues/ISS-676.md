# ISS-676: Preserve owned uncaught exceptions at native JIT entry

## Description
Native entry converts trap code 12 into a string after clearing the invocation's
exception payload. Embedders cannot inspect the actual escaping tag/payload.
The interpreter exposes exception-aware entry; a last-host-error slot would
misidentify exceptions caught and replaced by the guest or nested invocations.

## Design
Capture the escaping exception before activation cleanup, in an invocation-owned
native delivery with explicit root lifetime. Decode and root it in the same
Store before releasing that delivery. Add synchronous/resumable exception-aware
entry methods while preserving legacy trap-only entry behavior. Keep genuine
traps, host errors, cancellation and quota failures distinct.

## Notes
- Native activation cleanup frees the transient payload; the existing internal
  guest-continuation catcher can snapshot it before cleanup. Delivery must retain
  roots independently of thread-local trap diagnostics and subsequent calls.

- The initial public uncaught-host-exception regression failed with
  `Trap("uncaught exception")` before the repair. Ten public tests cover
  matching/mismatching handlers, guest replacement, nested entries, async await,
  resumed mixed/nested references, Store/handle closure, cancellation, quota
  rejection and both native-root allocation failure points.
- Rooted delivery retains its own PendingWork lease; invocation cleanup releases
  the execution lease independently. Failure to admit a root yields the existing
  resource error and closes the temporary native root.
- Local strict native/wasm, full native 3,090/3,090 with regalloc/GC/barrier
  verification, wasm 1,459/1,459, module boundaries and generated MSVC bridges
  pass. Portable native and actual wasm each pass 258 files/62,563 assertions;
  fresh release JIT/interpreter each pass all 88 upstream exception assertions.
  Python hooks pass 178 tests with 54 existing platform skips.
- Fresh isolated macOS ASan/UBSan passes 305/305 with both ASan positive
  controls. This is dirty-source local evidence based on 2030b601; LSan is
  unavailable here. Its temporary sources/builds/logs were automatically removed.
- Exact-head PR #579 CI passed all six platform jobs, including Windows
  inventories 3,090/63 packages and Linux sanitizer 305/305 with LSan enabled,
  positive controls and no ordinary sanitizer errors. Portable native/wasm
  each passed 258 files/62,563 assertions. This is separate from local macOS
  evidence.
