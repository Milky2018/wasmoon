## Description
Global-cell pointer tables still use manual allocation and transfer through integer addresses. Context replacement overwrites the old table without releasing it. Migrate table construction to MoonBit arrays while retaining the legacy public setter and keeping runtime global-cell ownership unchanged.

## Design
The normal path snapshots cell addresses in an RC-owned FixedArray[Int64]. Native context teardown and replacement distinguish RC arrays from the legacy malloc-owned table. Array entries remain borrowed addresses; no cell ownership transfers. A private ownership flag uses existing alignment padding, preserving the 352-byte context and 128-byte generated prefix on ARM64. Raw callers reinstalling the same table remain valid. Global cells and their binding closures are outside this migration.
