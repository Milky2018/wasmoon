## Description
Delete the temporary `modules/wasmoon_jit/legacy_ir`, `modules/wasmoon_jit/legacy_vcode`, and mistaken `modules/wasmoon_jit/vcode` compiler copies without hiding unsupported cases behind interpreter fallback.

## Design
The accepted correction is copy-first, but with the reusable module boundaries intact: preserve the old production semantics by moving the generic IR implementation into `modules/milkir`, machine IR and ABI data into `modules/machv`, MilkIR-to-MachV lowering into `modules/milkir_machv`, register allocation into `modules/machv_regalloc`, and real emission into `modules/machv_emit`. `modules/wasmoon_jit` keeps Wasmoon-specific Wasm-to-MilkIR translation, runtime glue, artifact loading, and symbol resolution; it must not contain a duplicate VCode implementation or interpreter fallback trampoline.

## Acceptance Criteria
- [x] `modules/wasmoon_jit/legacy_ir`, `modules/wasmoon_jit/legacy_vcode`, and `modules/wasmoon_jit/vcode` are deleted.
- [x] Production IR data structures, verification, printing, and optimization live in `modules/milkir`.
- [x] Production VCode machine model, ABI data, lowering, register allocation, and emission live in `modules/machv`, `modules/milkir_machv`, `modules/machv_regalloc`, and `modules/machv_emit`.
- [x] `modules/wasmoon_jit/ir` is limited to Wasm translation glue and a MilkIR facade; it does not own a duplicate generic IR model.
- [x] Production JIT compilation has no interpreter fallback trampoline or interpcall dispatcher.
- [x] Wasmoon product packages consume the reusable compiler path through explicit module imports.
- [x] Full correctness gates pass after deletion.

## Notes
- 2026-07-05: Deferred because deleting the fallback initially reduced correctness coverage. That stopgap was rejected after review because it duplicated compiler logic inside `wasmoon_jit`.
- 2026-07-05: Removed the interpcall dispatcher, interpreter fallback trampoline generator, runtime symbol, MoonBit wrappers, C FFI exports, and tests that treated fallback as a supported path.
- 2026-07-05: Removed the copied `wasmoon_jit/vcode` path. The old VCode implementation was copy-first migrated into real reusable modules: `machv` for machine IR/ABI, `milkir_machv` for lowering, `machv_regalloc` for allocation, and `machv_emit` for bytes/trampolines.
- 2026-07-05: `wasmoon_jit/native_glue` now lowers MilkIR through `milkir_machv/lower`, allocates through `machv_regalloc`, and emits through `machv_emit`. The target override is scoped through `machv/isa` so the reusable lowering path, not a `wasmoon_jit` copy, selects AMD64 or AArch64.
- 2026-07-05: Restored testsuite JIT helpers to production-loaded JIT execution without interpreter-backed compatibility shims, including GC setup/teardown copied from the old main-branch harness.
