## Description

Before fused shift selection, AEGIS `func_30` uses 19 stack slots, 17 spills,
and 22 reloads. Some pressure may disappear with fewer shift temporaries; the
remaining edits must be reclassified before changing allocator policy.

## Design

Re-run allocation after ISS-257, classify each remaining spill by live-range and
constraint cause, and fix only demonstrated avoidable pressure or coalescing
failures. Prefer shortening/rematerializing target temporaries before adding
allocator heuristics.

## Acceptance Criteria

- [ ] The post-ISS-257 spill/reload set is captured as structured diagnostics.
- [ ] Every implemented allocator or lowering change has a focused regression
      test describing the avoided edit.
- [ ] AEGIS hot-function stack traffic decreases without increasing code size or
      violating fixed-register, ABI, GC-root, or edge-transfer constraints.
- [ ] Full regalloc verification remains green.
