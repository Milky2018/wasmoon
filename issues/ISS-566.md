## Description
The current CI covers component corpora and local WASI tests but not the pinned external Preview 3 guest suite. The audit adapter reports 39 failures, 14 skipped and 2 apparent passes per engine; both apparent passes are startup errors whose exit status happens to equal the expected guest status. HTTP probes also fail before the guest handler.

## Acceptance Criteria
- [ ] Pin the external binaries, metadata and checksums in the corpus workflow.
- [ ] Reject initialization and harness errors even for exit-code-only negative tests.
- [ ] Run HTTP operations with metadata-driven peer servers and guest environment configuration.
- [ ] Isolate mutable filesystem roots per case and grant only test-required network capabilities.
- [ ] Gate the applicable suite on both engines across Linux, macOS and Windows.
