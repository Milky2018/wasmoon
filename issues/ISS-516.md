## Close Notes

- Reproduced under local x64/Rosetta with the current SDK: core simd_lane.wast fails line 688, returning an all-zero vector. The new 20-case floating lane fixture fails all 20 cases under the old x64 JIT, while the old interpreter and pinned Wasmtime both pass.
- The emitter copies the base vector into the destination before consuming the scalar. The allocator permits that destination to reuse the scalar input register. Preserve the overlapping scalar in reserved emitter SIMD register 15 before copying; integer lane inputs use a distinct register class.
- Artifacts now use codegen revision direct-vcode-5 so cached direct-vcode-4 code cannot retain the faulty sequence. Artifact encoding remains version 10.

- Fixed x64 CLI passes the original 463-assertion SIMD file and all 20 independent lane combinations. Broader local Rosetta core sweep: 255/258 files, 62297 assertions, zero assertion failures. Three recursion/stack-exhaustion scripts abort inside Rosetta itself with `unexpectedly need to EmulateForward on a synchronous exception`; native Linux CI remains the platform acceptance gate and these local aborts are not counted as passes.

- Local native verification: 2428 tests passed, plus all 20 combinations through both ordinary and instrumented JIT entry paths. ARM64 official core: 258/258 files and 62563 assertions per engine; local runtime suite and 32 threading/pooling/GC misc executions also pass. Native Linux CI is pending at commit time.
