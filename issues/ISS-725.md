## Description
The native CI release-counter gate reads target/native before install.sh creates
that compatibility link. Both completed native logs report a missing archive.
Because nm runs inside an if pipeline, the failed read produces a successful
step instead of verifying the release library.

## Design
Read the actual _build release archive and write nm output in a standalone
command. A missing archive or failed nm now stops the step; grep then rejects
the existing test-counter symbol. Preserve all source warnings, test inventories,
timeouts and platform jobs. Product module bytes and performance evidence are
unchanged.

## Acceptance Criteria
- [x] Reproduce the old missing-archive false success from complete CI logs.
- [x] Fail a missing archive and an archive containing the counter symbol.
- [x] Accept the actual fresh release archive after direct symbol inspection.
- [x] Verify the corrected gate and every other check on the final exact head.
