## Description
Typed array allocation still prepares a collecting call even when the existing
payload and identity windows suffice. Test a shared no-GC constructor that reuses
the canonical initializer and refuses without mutation when admission is unsafe.

## Design
Use the existing prepared allocation predicate, immutable type mapping and full
payload initializer. A successful call cannot grow storage, collect, reenter,
trap, invoke callbacks or encounter quota/fault controls. Otherwise return zero
without changing allocator state and enter the complete original collecting
path. Preserve vector high words, packed values, reference initialization,
identity publication, quota/failure ordering and root staging at the slow edge.
Do not introduce a second collector or duplicate physical layout logic. Require
explicit embedding ABI opt-in and cap static expansion at sixteen sites; share
struct/array budget inspection and jump directly to the initialized result.
