# ISS-684: Avoid empty pre-mark discovery scans during native collection

## Description
Precise collection counts and copies pre-marked heap objects with two complete
live-identity walks before expanding explicit, execution and arena roots. Most
allocation collections have no pre-marked heap objects. A diagnostic build of
current-toolchain parse_double scans 52 million seed candidates across15
collections although only375–386 objects survive each collection.

## Design
Track whether any payload header may be marked. Both existing native marking
writers set the hint; complete sweep, abort and rollback clear it only after
clearing every retained header mark. Skip only the two header discovery walks
when no marks exist. Explicit, active, parked and arena roots remain mandatory.
Precise JIT collection uses the coordinator's existing execution-root snapshot
instead of also pre-marking the same activations. Conservative collection keeps
its original marking path. No object identity, threshold, tracing or public API
change.
Post-collection callbacks can create new marks for the following collection.
