## Close Notes

- ISS-512 supplies real native wait queues and managed waiter lifetime, independently verified against native-thread notification. It does not yet replace either engine's synthetic guest wait/notify implementation.
- Integration must suspend guest calls directly: interpreter continuations at instruction boundaries and native continuations at safepoints. WAST child contexts need independent Stores sharing only native shared-memory owners. Instantiate without running start first, then execute start through the selected suspendable engine; do not wrap the WAST runner in a native fiber.

- ISS-513 integrates interpreter wait/notify, typed scheduling suspension and instruction quanta. Independent interpreter Stores notify shared waits correctly, and consumed continuation handles no longer cancel newer suspended owners. Native JIT wait/notify and WAST thread scheduling are still pending.

- ISS-514 integrates native guest wait/notify and cooperative safepoints, including cancellation and parked GC-root regressions. Both core engines now have real wait queues and suspendable calls; WAST thread parsing, child Store setup, scheduling and joins remain pending.

- ISS-515 completes parsing, independent child Stores, shared native memory ownership, cooperative scheduling, start suspension, and joins in both engines. All eleven original failing scripts pass in the complete unmodified misc sweep. Remaining typed-continuation failures are ISS-477; the separately discovered Linux SIMD regression is ISS-516.
