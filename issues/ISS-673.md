## Description
An aggressively Binaryen-inlined variant of the asserted parse_double guest
passes wasm-tools validation but Wasmoon rejects compilation with
`MissingTerminator(block_id=129)`. This diagnostic is not the unchanged guest
used for ISS-671's numerical acceptance. Rejection reproduced on both the
pre-current-turn reference-allocation candidate and the later affine-field
candidate; it is not established as introduced by the current changes.

## Design
Regenerate the original asserted 20000-iteration guest using the pinned Core
revision and isolator in `scripts/benchmark_parse_double_gc.py`. Apply the
Binaryen 129 flags below, validate, then minimize the rejected input and
identify the missing CFG terminator. Preserve input
validation and SSA verification. Do not work around the rejection by weakening
the verifier or using a changed guest for numerical acceptance.
