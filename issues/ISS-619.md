## Description
`modules/wasmoon/runtime_assembly.mbt::runtime_assembly` returns hardcoded module names and ownership lists. `runtime_assembly_test.mbt` checks those same constants rather than actual dependencies. The public `compiler_infrastructure_assembly` empty-function probe and `plan_wasm_function_with_compiler_infra` wrapper also have only test callers in the inspected repository at `7dec3153`.

These migration-era APIs enlarge the runtime surface and maintain tests that do not establish the claimed architecture or hidden-context ABI. The same source file contains the production-used embedding environment, which must be preserved.

## Design
Review compatibility, remove or deprecate unused descriptive/probe APIs, and retain meaningful compiler integration coverage through the real production seam. Use actual dependency information for ownership checks rather than maintaining a second hardcoded architecture model. Preserve production embedding configuration and meaningful ABI regressions.

## Acceptance Criteria
- [x] Record consumers and compatibility decisions for RuntimeAssembly, RuntimeComponent, CompilerInfrastructureAssembly and their related helper APIs.
- [x] Remove redundant metadata assertions and unused probes as permitted by compatibility; preserve wasm_frontend_embedding_environment and its production callers.
- [x] Any retained integration test asserts real compilation or ABI behavior rather than only constant lists or nonempty code bytes.
- [x] Regenerate interfaces, run the existing module-boundary audit and relevant native tests, and pass repository validation.
