# ISS-507: Compare WAST floating-point assertions by their required bit patterns

## Description
The WAST runner currently compares ordinary float expectations numerically and accepts any NaN for both canonical and arithmetic NaN patterns. This aliases positive and negative zero, ignores explicit NaN payloads, and permits noncanonical/signaling NaNs. Scalar and SIMD assertions are affected. Fix the oracle before enabling the remaining NaN configuration fixtures.

## Acceptance Criteria
- [x] Independent passing/failing controls distinguish signed zero, explicit NaN bits, canonical NaNs, and arithmetic NaNs for both widths and SIMD lanes.
- [x] Match the pinned Wasmtime WAST assertion semantics without changing upstream expectations.
- [x] Rerun external corpora, fix newly exposed runtime failures, and record the new baseline.

## Close Notes

Independent negative control: /tmp/iss507-invalid-expectations.wast contains ten incorrect assertions (scalar signed zero, explicit NaN payloads, canonical/arithmetic NaNs, and mixed SIMD lanes). Both current engines incorrectly report 10 passed, zero failed. Pinned Wasmtime rejects every assertion when run separately (/tmp/iss507-oracle-results.json). The pinned matcher in crates/wast/src/core.rs uses exact bits for ordinary values, ignores only the sign for canonical NaNs, and requires the quiet bit for arithmetic NaNs.

The strict matcher rejects all ten invalid controls in both engines. Two MoonBit matcher regressions fail before the fix and pass after it. Strict matching exposed 112 interpreter failures in six official core scripts: rounding preserved signaling NaNs, and SIMD min/max used a noncanonical library NaN. Scalar rounding now shares the SIMD helpers, which quiet NaNs explicitly and bypass integer conversion for already-integral large values. SIMD min/max constructs a canonical NaN directly. The new tests/runtime/float-nan-rounding.wast passes the pinned Wasmtime oracle.

Final external gates: all 258 official core files / 62,563 assertions pass per engine; runtime, all four component lanes per engine, and P1 pass. Full high-memory-inclusive misc remains 576 pass, 68 successful assertion-free scripts, 112 thread/continuation failures, and eight unsupported host/config executions (tmp/iss507-final-misc/summary.json). No upstream inputs or expectations changed. Native validation: moon info, moon fmt, moon check --target native --warn-list +73, and all 2,395 native tests passed.
