## Description
Native fiber state and operation results cross the C/MoonBit seam as bare
integers. C returns values such as `0`, `1`, `-2`, and `-3`, while multiple
MoonBit methods independently interpret the same values. Unknown state codes
are also silently treated as `Cancelled`.

## Design
Keep the unavoidable numeric wire encoding private to the FFI adapter. Name the
C protocol values, decode each operation once into internal MoonBit enums, and
make fiber and continuation methods consume only typed results. Reject unknown
state encodings rather than assigning them a valid lifecycle meaning.

## Acceptance Criteria
- [x] C fiber state and operation result codes use named protocol constants.
- [x] One MoonBit adapter owns all integer-to-type decoding.
- [x] Fiber and continuation methods do not match raw status integers.
- [x] Unknown state and result codes remain distinguishable from valid states.
- [x] Fiber, continuation, trap, and sanitizer regressions pass.
