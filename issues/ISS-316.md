## Description
The `component-test --no-jit` command reads the `no-jit` flag from parsed
arguments instead of parsed flags. The command therefore still installs the
JIT core execution engine while the suite runner reports interpreter mode.

## Design
Read `no-jit` from the same typed flag map used by the other CLI commands.
Keep interpreter and JIT execution as explicit, independently testable modes.

## Acceptance Criteria
- [x] `component-test --no-jit` installs the interpreter execution engine.
- [x] The default `component-test` path still installs the JIT engine.
- [x] The suite runner's reported execution mode matches the selected engine.
