## Question

Which MoonBit packages should own MachV, the generic Target VCode shell, AArch64 and AMD64 instructions, target lowering, regalloc adapters, emitters, and Wasmoon orchestration, and which APIs must be public for downstream reusable-module consumers?

## Acceptance Criteria

- [ ] Package dependencies obey the reusable-infrastructure hard boundary.
- [ ] Public APIs are narrow, named by the agreed domain language, and do not expose construction-only or target-union compatibility surfaces.
- [ ] Expected breaking-version consequences are identified for later release planning.
