## Close Notes
`invoke_action` now converts WAST arguments once and delegates JIT calls to `JITModuleContext.call_core_func`. Removed the duplicate native entry, GC setup/teardown, argument/result conversion, and synchronization path. The shared boundary owns native invocation state and preserves structured errors internally; interpreter fallback remains available when no compiled function exists.

Validation: existing callable-context and atomic runtime fixtures pass all 68 assertions on each engine; all 2,354 native tests pass; core spec remains 258/258 files and 62,563 assertions on each engine. Misc results remain unchanged (498 pass, 112 fail, 66 script-only, 72 unsupported, 16 deferred, zero timeout/harness errors). `moon info`, formatting, native warning-73 check, and module boundary audit pass. These pre-ISS-482 counts do not prove correct trap/exception classification: ISS-482 tracks the independently reproduced assertion false positives.
