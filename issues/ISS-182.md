## Notes
- 2026-07-15: The standing project contract currently assumes 64-bit pointer/reference carriers.
- 2026-07-15: Claimed for a HITL Wayfinder design session using domain modeling and deep-module interface analysis.
- 2026-07-15: Every MachV function parameter, block parameter, and instruction result carries an exact target-neutral value type. Register classes are not MachV value types; each target maps MachV types to its own Target VCode register classes after MachV lowering.
- 2026-07-15: A MachV function owns one canonical dense table from opaque value handles to MachV value types. Instructions and parameter lists carry only handles; builders allocate them, and verification, printing, and lowering query the same function-owned facts. Public `{ id, type }` construction and duplicated per-use type fields are excluded.
- 2026-07-15: Opaque value handles internally combine a dense id with a private per-function owner context. Low-level mutation rejects foreign values before changing the function and records a construction error. Clone, rebuild, and deserialization allocate a fresh owner context and remap handles; owner identity is absent from printed and serialized forms.
- 2026-07-15: The complete MachV value-type set is `I32`, `I64`, `F32`, `F64`, `V128`, `Ptr64`, and `GcRef64`. Narrow integers are memory widths rather than values, and comparisons produce `I32`. `Ptr64` is an untraced address or opaque handle; `GcRef64` is a nullable managed root. Both are fixed 64-bit carriers. Source-level callable and opaque reference distinctions are removed during semantic legalization, while call operations validate callee meaning independently.
- 2026-07-15: Constants are typed SSA-producing semantic operations. Integer, floating-point, and `V128` payloads preserve exact bits; null pointer and null managed-reference constants remain distinct. External code or data addresses use symbolic address constants resolved by relocation. Nonzero process addresses, target immediate variants, constant-pool layout, and pooling policy are excluded from MachV.
