## Description
The component conformance runner checks Wasmoon against expected assertions but
does not compare general typed invocation behavior with a current independent
runtime.

## Design
Run the valid generated component corpus through Wasmoon and Wasmtime 45.0.0.
Normalize successful typed values without collapsing distinct traps, errors,
signals, or timeouts. Pin and verify the official Wasmtime binary asset used by
CI.

## Acceptance Criteria
- [x] The oracle version is exactly 45.0.0 and its release asset is verified by
      SHA-256.
- [x] Direct and nested exports cover signed, unsigned, float, string, and
      compound values supported by both CLIs.
- [x] Success values and failure categories are compared structurally.
- [x] Timeout, signal, trap, ordinary error, and malformed output remain
      distinct outcomes.
- [x] Any mismatch retains the component, arguments, outputs, and seed.
