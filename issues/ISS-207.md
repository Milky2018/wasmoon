# ISS-207: Enforce rights for WASIp1 descriptor operations

## Description
Most descriptor operations perform host I/O without consulting the effective rights stored on the descriptor. Successful `fd_fdstat_set_rights` attenuation therefore does not constrain subsequent operations.

## Design
Use the lookup boundary introduced by ISS-206 for read/write, positioned I/O, seek/tell, sync, directory, stat, allocation, advice, and flag operations in both interpreter and JIT modes. Preserve existing ABI validation and descriptor-kind error precedence, but reject missing capabilities before any host side effect.

## Acceptance Criteria
- [x] Read/write and positioned I/O enforce their required rights, including combined rights.
- [x] Seek/tell, sync/datasync, readdir, filestat, allocate, advise, and set-flags enforce their required rights.
- [x] Rights attenuation immediately affects subsequent descriptor operations.
- [x] Interpreter and JIT focused tests cover allowed and denied representative operations.
- [x] No rights-free descriptor operation gains an accidental requirement.
