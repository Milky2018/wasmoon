## Description
Replace the skeletal `modules/wasmoon/wasm_frontend` lowering with the real WebAssembly-to-IR translator now under `modules/wasmoon/ir/translator*.mbt`, targeting the real generic MilkIR API.

## Design
Lower WebAssembly modules through an explicit embedding environment. WebAssembly validation, type-system details, heap/reference typing, tables, memories, globals, imports, and runtime helper choices must remain in the Wasm frontend or Wasmoon runtime adapters, not in MilkIR core. The old translator should be ported incrementally with tests that compare old JIT/interpreter behavior until the legacy path can be retired.

## Acceptance Criteria
- [x] `modules/wasmoon/wasm_frontend` lowers real Wasm function bodies into MilkIR instead of emitting skeleton traps for non-empty bodies.
- [x] The frontend handles control flow, locals, numeric operations, memory/table/global access, calls, traps, and supported reference/GC operations at parity with the old translator or tracks unsupported cases.
- [x] Existing translator tests are ported or replaced with frontend-to-MilkIR tests and Wasmoon correctness tests.
- [x] MilkIR remains free of WebAssembly-specific core opcodes.
- [x] WAST interpreter/JIT correctness gates still pass for the migrated path or failures have explicit follow-up issues.

## Close Notes
Closed after replacing the `wasm_frontend` skeleton lowering with a real adapter over the production Wasm translator. The new `modules/wasmoon/ir/milkir_bridge.mbt` converts legacy Wasmoon IR functions into generic MilkIR functions, supports frontend signature overrides for hidden context parameters, and maps WebAssembly/runtime-specific operations to Wasmoon-owned `Custom` adapter opcodes instead of adding Wasm opcodes to MilkIR. `modules/wasmoon/ir/cfg.mbt` now reuses the same bridge, removing the duplicated CFG-only conversion path. Added frontend-to-MilkIR tests for numeric lowering, locals, control flow, traps, direct calls, and memory adapter operations; the old TODO skeleton trap no longer exists in production code. The physical retirement of the old translator/optimizer/JIT path remains tracked by ISS-017, ISS-022, and ISS-023.
