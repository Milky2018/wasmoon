## Description
Replace the skeletal `modules/wasmoon/wasm_frontend` lowering with the real WebAssembly-to-IR translator now under `modules/wasmoon/ir/translator*.mbt`, targeting the real generic MilkIR API.

## Design
Lower WebAssembly modules through an explicit embedding environment. WebAssembly validation, type-system details, heap/reference typing, tables, memories, globals, imports, and runtime helper choices must remain in the Wasm frontend or Wasmoon runtime adapters, not in MilkIR core. The old translator should be ported incrementally with tests that compare old JIT/interpreter behavior until the legacy path can be retired.

## Acceptance Criteria
- [ ] `modules/wasmoon/wasm_frontend` lowers real Wasm function bodies into MilkIR instead of emitting skeleton traps for non-empty bodies.
- [ ] The frontend handles control flow, locals, numeric operations, memory/table/global access, calls, traps, and supported reference/GC operations at parity with the old translator or tracks unsupported cases.
- [ ] Existing translator tests are ported or replaced with frontend-to-MilkIR tests and Wasmoon correctness tests.
- [ ] MilkIR remains free of WebAssembly-specific core opcodes.
- [ ] WAST interpreter/JIT correctness gates still pass for the migrated path or failures have explicit follow-up issues.
