## Description

The ISS-193 cutover correctness matrix fails `fd_pwrite/fd_pread on file` in both JIT and interpreter modes on macOS AArch64 and Linux AMD64. Both engines reach the fixture's `unreachable`, so this is not currently isolated to native lowering. The failure appeared after the WASIp1 rights work and prevents either target manifest from passing.

## Design

Reproduce the exact CLI fixture and determine whether its requested rights are incomplete or the rights implementation rejects a valid operation. Preserve the tightened rights model; do not restore permissive descriptor behavior merely to satisfy the fixture.

## Acceptance Criteria

- [x] The positional file-I/O fixture passes for the correct WASIp1 rights reason, not through relaxed validation.
- [x] Negative tests still reject missing `FD_READ`, `FD_WRITE`, `FD_SEEK`, or path-open rights as applicable.
- [x] JIT and interpreter modes pass on macOS AArch64 and Linux AMD64.
- [ ] The ISS-193 WASI command records a successful result in both target manifests.
