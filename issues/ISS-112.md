## Description
`wasmoon_jit` owns Wasmoon VMContext layout, runtime helpers, CWASM artifacts, trampolines, and native FFI, but `RuntimeAssembly.reusable_modules` currently includes it. This contradicts the repository's documented ownership boundary.

## Design
Represent product-owned support modules separately from reusable compiler infrastructure in `RuntimeAssembly`. Keep the generic infrastructure list limited to modules that can be embedded without Wasmoon-specific runtime ownership and strengthen tests for both sides of the classification.

## Acceptance Criteria
- [x] `wasmoon_jit` is represented as Wasmoon-owned rather than reusable infrastructure.
- [x] Generic compiler modules remain listed as reusable.
- [x] Runtime assembly tests enforce the ownership distinction.
- [x] Native typechecking and the module-boundary audit pass.
