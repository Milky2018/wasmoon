## Description
The black-box test `public CFG discovers a natural loop and its preheader` intermittently observes loop blocks as `[2, 1]` on the JavaScript backend instead of the expected `[1, 2]`. The semantic loop contents are unchanged, but unstable collection iteration makes the full all-target test gate flaky.

## Design
Identify the unordered collection boundary in natural-loop discovery and define a deterministic block-order contract without weakening the whole-object snapshot. Keep the fix independent of unrelated IR or dialect changes.

## Acceptance Criteria
- [ ] Natural-loop block order is deterministic on every backend.
- [ ] The existing whole-object CFG snapshot passes repeatedly on JavaScript without sorting inside the test.
- [ ] CFG, MilkIR, and all-target test suites pass.
