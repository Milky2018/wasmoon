## Description
`scripts/audit_component_security.py` treats validator error-string presence as evidence of validation limits, cleanup function-name presence as a resource cleanup boundary, and a positive test count as lifecycle coverage. Its unit tests verify these text rules. `scripts/audit_jit_context_lifetimes.py` similarly checks a finite list of raw-context symbol names rather than proving lifetime safety.

On `7dec3153`, a temporary fixture built with ComponentSecurityAuditTests.create_fixture was changed so the validator contained only comments with the two expected messages and the four scanned runtime files contained only comments naming cleanup_closed_stream/cleanup_closed_future. The fixture retained an empty cleanup test. validator-limits, resource-cleanup-boundary and resource-cleanup-tests all passed. Separately, all 27 component audit unit tests passed. This demonstrates a limit of the checks, not a demonstrated runtime leak or missing production validator.

## Design
Replace the specific string/count checks with meaningful boundary and lifecycle regressions, reusing existing coverage where sufficient. Review the JIT lifetime blacklist and its tests for removal, replacement or accurately limited scope. Preserve useful manifest/interface dependency checks and actual runtime cleanup tests. Do not add new ad hoc source-name audits or pretend a structural check establishes runtime memory safety.

## Acceptance Criteria
- [x] Inventory the affected component-security and JIT-lifetime checks, their CI integration and corresponding tests; state the property each can actually establish.
- [x] Validation boundary regressions exercise real size/nesting limits, and lifecycle regressions exercise creation, release, cancellation or rollback with observable outcomes.
- [x] Remove redundant heuristic tests together with retired checks; retain useful tool tests for structural checks that remain supported.
- [x] Preserve existing runtime_cleanup_wbtest coverage and relevant native ownership regressions; verify that disabling a covered behavior fails an appropriate regression in a controlled temporary experiment.
- [x] Run affected Python/native tests and inspect CI wiring so removed heuristics leave no dangling commands or untested required behavior.
