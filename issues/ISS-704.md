## Description
Published 0.18.0 takes a reported 11.31 seconds and 1.42 GiB peak RSS to
compile the 4,938,531-byte distributed Core builtin Wasm-GC module. The public
compile_module control uses O2 and cancellation safepoints, creates no Store,
links no imports and executes no guest code. Input SHA256 is
00002138ac7db01edc9217916b8c7b3c96a8e093f47f765faa465ac3eca792a6.
These observations are not measurements of PR582.

## Design
Verify the public reproduction archive, then establish fresh current-head and
release-baseline controls on the exact input. Separate parse/validation,
translation, optimization, target lowering, allocation, frame planning and
emission. Profile temporary allocation/lifetime separately from ordinary
timing and whole-process RSS. Rank falsifiable hypotheses before changing
production code. Retain eager compilation semantics, strict validation, source
provenance, precise roots, cancellation, quotas and artifact compatibility.
Use auto-cleaned OS temporary directories for sources, logs and caches; retain
only concise conclusions and reusable measurement tooling.
