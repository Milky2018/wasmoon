## Description
Native trap reports label function-relative machine-code displacements as Wasm
byte offsets. Source-map lookup can then select a plausible but unrelated line.
Missing source information must be explicit, rather than fabricated offset zero.

## Design
Retain binary instruction provenance separately from the semantic AST. Carry
original module byte offsets through MilkIR and target metadata into bounded
native source ranges and serialized artifacts. Report Wasm and native offsets
separately. Missing/synthetic provenance remains unknown. Preserve source
identity during optimization and on resumed/caller frames.

## Notes
- The public AST regression originally reported `Some(12)` as a Wasm offset
  without any binary source positions. It now reports None and retains the
  native displacement separately.
- Binary positions are captured during the original parse, including custom
  sections and non-canonical LEBs. Semantic AST equality is unchanged. Tables
  validate tree shape; unreachable nested bodies cannot shift later entries.
- MilkIR instruction/terminator provenance survives alias rewriting, CFG merging
  and rematerialization. Emitters coalesce adjacent equal-origin ranges and keep
  synthetic prologues/epilogues and ambiguous shared trap blocks unmapped.
  Artifact format/cache namespace 12 rejects older layouts; JIT ABI is unchanged.
- Seven public native tests cover O0/O2, binary artifact round trips, non-tail
  caller frames, resumption, checked/folded integer traps, unreachable nesting,
  stack guards and explicit RET versus synthesized epilogue ranges.
- Sanitizer testing exposed an independent recovery-order defect: copying frame
  records after restoring the activation SP lost the non-tail caller at O0.
  Requiring a result after a void call did not remove the failure. Copying only
  bounded frame records before recovery fixes it; post-recovery C/ASan stack
  frames can overwrite the abandoned guest records. POSIX uses its alternate
  signal stack; Windows snapshots its checked readable region before longjmp.
- Final local strict native/wasm, native 3,091/3,091 with regalloc/GC/barrier
  verification, wasm 1,462/1,462, module boundaries and generated MSVC bridges
  pass. Fresh release JIT and interpreter each pass all 258 Core files/62,563
  assertions. Fresh isolated macOS ASan/UBSan passes 302/302 and both ASan
  controls; this is dirty-source evidence based on 2030b601, with no local LSan.
  Temporary builds, sources, reports and logs were automatically removed.
- Cross-platform CI acceptance remains pending on the eventual PR head.
