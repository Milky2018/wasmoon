# ISS-638: Move continuation lifecycle decisions into MoonBit

## Metadata
- Type: task
- Status: closed

- Labels: runtime, continuation, cancellation, ffi, ownership
- Assignee: unassigned
- Created: 2026-10-16
- Updated: 2026-10-19

## Description
Separate guest continuation identities and lifecycle decisions from native stack/context operations. Preserve one-shot semantics, roots of parked work and callback completion before stack transfer.

## Design
Start from complete executable paths and explicit ownership. Reuse the existing hostcall and root-visitor conventions; preserve machine layout and direct access where required. Move decisions with their state and delete old implementations. Do not equate wrapping C in more FFI functions with migration, or claim the complete architecture is repaired after one slice.

## Acceptance Criteria
- [x] Inventory continuation transitions, resource ownership, cancellation and root visibility during every transition.
- [x] Move logical handle/state decisions to a MoonBit owner and delete duplicate C lifecycle policy.
- [x] Keep native callbacks non-suspending and preserve guest-only parked frames; all failure/cancel paths release resources exactly once.
- [x] Validate resume/reentry/throw/cancel/GC/quota behavior across engines and platforms and measure suspension overhead.
