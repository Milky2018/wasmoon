# ISS-156: Derive dead-code and loop safety from opcode semantics

## Description
DCE and loop transforms currently call a misleading `has_side_effects` helper that combines observable effects with trapping behavior. The helper owns a separate opcode match and makes policy hard to distinguish from semantic fact.

## Design
Replace the helper with queries derived from the semantic summary introduced by ISS-155. Preserve existing optimization behavior: unused instructions that may trap or have observable effects must remain, while pure non-trapping instructions may be removed or moved according to the existing pass rules.

## Acceptance Criteria
- [x] DCE preservation decisions use the centralized semantic summary.
- [x] Loop optimization safety checks use the centralized semantic summary.
- [x] The old `has_side_effects` opcode classifier is removed.
- [x] Regression tests cover unused trapping instructions and observable operations.
- [x] Targeted MilkIR tests and warning checks pass.
