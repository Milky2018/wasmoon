## Description
After `legacy_ir` and `legacy_vcode` were deleted, the repository reached the immediate split-and-delete goal. The remaining work is polish that turns the extracted modules into comfortable reusable compiler infrastructure rather than merely Wasmoon-owned implementation packages.

This epic groups the remaining public API, ABI, lowering, trampoline, and test-harness work.
