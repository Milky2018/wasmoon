# ISS-249: Reject non-representable v9 signed metadata values

## Description

The v9 decoder reads signed 64-bit trap payload, stack-root offset, and unwind CFA offset values and converts them to the 32-bit MoonBit `Int` representation without a range check. Malicious artifacts can therefore change values during decode and continue into verification.

## Design

Add one field-aware checked i64-to-Int decoder conversion and use it at all four signed metadata sites. Preserve the wire format and return structured `InvalidValue` errors before object verification.

## Acceptance Criteria
- [x] Values below `Int::min` or above `Int::max` are rejected for every affected field.
- [x] Minimum, maximum, and ordinary representable values round-trip exactly.
- [x] Decoder errors identify the exact field and no public API changes.
