## Description
Machine code shows native semantic expansion materializes five comparison
booleans per poll before branching. Original MilkIR branches already reach the
native builder's direct-comparison terminators, but dialect adapters cannot.
Remove this avoidable intermediate representation without changing any poll.

## Design
Expose the existing integer compare/compare-immediate branch builders through
InstructionContext. Use them for the same five poll conditions. Reuse the
existing decrement constant, including on x64; keep its budget signedness,
callback priority, CFG edges, slow-call roots and reentry contract unchanged.
No new native instruction, environment field, cache or runtime policy. AArch64
already emits fused branches. The current x64 backend still materializes its
condition; compilation there is correctness coverage, not a measured speedup.
Advance generated-code compatibility to27 if retained.
