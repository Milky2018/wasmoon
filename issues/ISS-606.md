# ISS-606: Give native activations their own execution state

## Description
Exception payloads, spilled locals and root chains currently move between instance fields and trap activations. Scratch roots and collection flags remain shared by nested invocations of the same instance. Replace this transfer protocol with activation-owned execution state, keeping native setjmp/signal/stack mechanics in C.

## Design
Install a borrowed pointer to the current activation's execution state in its context. Detaching restores the previous pointer; resuming binds to the actual current caller; abandonment destroys only the parked activation's state. Allocate standalone helper state lazily for compatibility. Preserve generated-code ABI offsets and keep module metadata and invocation controls separate from this change.

## Acceptance Criteria
- [x] Exception, spill, scratch and root-chain ownership stays with its activation.
- [x] Nested entry, detach/attach and abandonment preserve other live states.
- [x] Parked GC registrations include scratch roots.
- [x] Standalone helper cleanup remains supported without eager state allocation.
- [x] Native, sanitizer and external regressions pass; record cross-platform CI status.
- [x] Record storage changes, performance comparison and remaining migration scope.

## Close Notes

Local implementation and validation are complete. The baseline scratch-isolation test fails, while the new implementation passes 2,613 native tests and 68 sanitizer tests. Both-engine core WAST and async component suites pass. Context payload is 352 bytes (previously 440), activation payload is 1,048 bytes (previously 1,008), and optional standalone state is 96 bytes. Bidirectional cache loading succeeds. See `docs/perf/activation-state-2026-09-29.md` for full measurements, including small indirect/GC regressions. Cross-platform CI passed for `577dc23e3879ed0fc18b02366719c10275ccbdcb`: https://github.com/Milky2018/wasmoon/actions/runs/36548749294 (macOS ARM64, Linux AMD64, Windows clang/MSVC and Linux sanitizers).
