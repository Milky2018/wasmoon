## Description
PR #420 made dialect lowering verify MilkIR before instruction selection. This exposed two invalid producer protocols: `return_call*` leaves its block without a MilkIR terminator, and Wasm GC/reference builders produce `I64` values where function and dialect contracts require reference types. Native tests abort with `MissingTerminator`, while GC JIT and sanitizer lanes abort with `I64` versus `Ref` type mismatches.

## Design
Add regression tests at the public verification and JIT/interpreter seams. Give tail-call instructions an explicit verifier-safe end-of-block representation without weakening verification, and make Wasm dialect reference producers preserve `Ref`, `CallableRef`, or `OpaqueRef` carriers consistently through optimization and lowering.

## Acceptance Criteria
- [x] Direct, indirect, and reference tail-call functions pass MilkIR verification without bypassing missing-terminator checks.
- [x] Wasm GC/reference producers and consumers use reference carriers consistently; no `I64`-versus-reference verifier mismatch remains.
- [x] Full native tests pass with register-allocation validation.
- [x] GC differential stress matrix passes all ordinary lanes under sanitizer configuration.
- [x] Existing JIT, frontend, SIMD, and module-boundary gates pass.
