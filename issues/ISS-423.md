## Description
Move x64 to the shared emergency-aware move-plan interface so only one
production cycle-resolution algorithm remains.

## Design
Use one existing reserved scratch per register bank for parallel moves and add
the same optional raw emergency area to x64 frames. Keep the other currently
reserved x64 scratch registers reserved for instruction emission; reclaiming
them is outside this issue.

## Acceptance Criteria
- [x] x64 uses the shared target-neutral cycle linearizer and emergency legalizer.
- [x] x64 frames add no emergency area when plans do not need one.
- [x] Existing instruction-emitter scratch roles and allocator behavior remain unchanged.
- [x] x64 move, frame, call, and full native tests pass.
