## Description
Split the current Wasmoon-internal compiler and JIT pipeline into reusable MoonBit modules that can serve as compiler infrastructure for non-Wasmoon users. The target architecture is documented in `CONTEXT.md`: `wasm_core`, `milkir`, `machv`, `regalloc`, `machv_regalloc`, `machv_emit`, `x64_target`, `aarch64_target`, `wasmoon_jit`, and `wasmoon`.

## Design
Keep the first split correctness-oriented, not performance-oriented. Preserve existing behavior while moving ownership boundaries: WebAssembly semantics stay in Wasm-facing modules, MilkIR is generic, MachV is a reusable virtual-register machine IR, register allocation is algorithmic, and Wasmoon-specific runtime/JIT glue stays in `wasmoon_jit` or `wasmoon`.

## Acceptance Criteria
- [ ] All child issues needed for the first-stage split are closed or explicitly deferred.
- [ ] `moon check` passes for the resulting workspace.
- [ ] Existing correctness tests that are not performance gates pass or have tracked follow-up issues.
- [ ] `CONTEXT.md` reflects the final module names and ownership boundaries.
