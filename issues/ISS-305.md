## Description
The current native Wasm stack belongs to one JIT context and is reset for every
call. A Store may have multiple parked component tasks and nested JIT entries,
so continuation state cannot live in one context-global stack or TLS singleton.

## Design
Add Store-scoped native execution state owning a fiber pool, active activation
stack, parked continuations, and trap/GC registration. Each suspendable
invocation owns a distinct stack and stable argument/result storage.

## Acceptance Criteria
- [ ] Multiple native invocations can be parked without sharing stacks.
- [ ] Nested native entries restore the previous activation.
- [ ] Continuation lifetime keeps code, instance, and buffers alive.
- [ ] Cancel and return release execution state exactly once.
