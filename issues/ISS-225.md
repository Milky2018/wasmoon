## Description

Migrate every AArch64 call family to soft ABI affinities and the verified call-transfer planner, then remove the stack-argument fixed-constraint exception and emitter-local shuffle implementation.

## Design

Migrate direct internal, indirect internal, platform, returns-twice, noreturn, result-area, and tail calls without changing semantic MachV. The call remains one atomic safepoint-bearing VCode operation.

## Acceptance Criteria
- [x] All AArch64 call inputs use `AnyLocation` plus optional legal register preference.
- [x] Every AArch64 call family consumes a verified transfer plan.
- [x] Mixed register/stack calls cannot overwrite an unmaterialized source.
- [x] AArch64 target, JIT differential, WAST, WASI, GC-root, unwind, and code-size tests pass.
