## Description
`modules/machv/instr` classifies call sites with `CallConv { Wasm, C }`. This
name is Wasm-specific, but the live semantic distinction is generic: internal
calls and foreign/helper calls have different clobber behavior for regalloc and
optimization barriers.

This issue removes the Wasm naming while preserving the existing call-clobber
semantics.

## Design
Replace the instruction-level `CallConv` with a generic call-site metadata type,
such as `CallClobberClass` or `CallABIClass`, whose cases express internal ABI
calls and foreign/helper calls without referring to Wasm.

Mechanically migrate existing uses:
- former `Wasm` call sites become the internal call class.
- former `C` call sites become the foreign/helper call class.
- regalloc and LICM keep the same behavior under generic names.
- `modules/machv/instr` no longer imports `wasm_core` only to display this enum.

Non-goal: change `@abi.CallConventionLayout` or the actual machine calling
sequence.
