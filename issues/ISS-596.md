## Description
AArch64 scalar x == 42 currently materializes 42 before CMP/CSET, although branch comparisons already accept an immediate. Extend value-producing comparisons while preserving sharing and target boundaries.

## Design
A target-owned eligibility callback permits shared native selection to consume only constants the target can encode. Add a typed immediate-comparison native operation and AArch64 CMP-immediate/CSET instruction. Preserve normal comparisons for ineligible constants and default-off targets. Other targets support explicit immediate operations through semantic fallback without changing their frontend selection policy.

## Acceptance Criteria
- [x] AArch64 produces CMP immediate + CSET for encodable constants in both widths and operand orders.
- [x] Signed/unsigned conditions, shared constants, ineligible constants and ordinary branch selection preserve behavior.
- [x] Native operation and target validation reject malformed input.
- [x] Full gates, fresh core regressions and representative workload checks pass; no memory-base policy changes.

## Close Notes
The shared native selector consults target eligibility before consuming a comparison constant. AArch64 accepts its unsigned 12-bit / shifted-12-bit immediate forms; other constants preserve materialization and sharing. x64 keeps its default-off selection policy, with a tested fallback for explicit generic operations. No memory-base or register-reservation policy changes.

Validation: generated interfaces, formatting, strict native check and all 2,603 native tests pass. New tests cover all ten signed/unsigned integer conditions, both widths and operand orders, shared/returned/rejected constants, malformed native/target operations, and x64 fallback. Independent clang encodings agree. Fresh CLI core WAST: 258/258 files and 62,563 assertions pass per engine.

The parameterized i64 equality repro shrinks from 16 to 12 bytes (MOV/CMP/CSET/RET -> CMP-immediate/CSET/RET). AEGIS function 30 and scrypt function 41 remain 1288 and 1752 bytes respectively; this does not establish a whole-workload speedup.

All timing samples are retained. Initial seven cold pairs report onetimeauth +1.52% [0.80, 2.59] wall time, and AEGIS -0.36% [-0.82, 1.12]. Investigating the slowdown with seven instrumented pairs found no established compile or invoke regression; compile medians are 39.472 -> 38.915 ms, with a paired change interval spanning zero. A separately fixed 21-pair uninstrumented confirmation reports -0.13% [-0.76, 0.46]. The initial slowdown is not stable across runs; neither a workload speedup nor a precise zero-regression guarantee is claimed on this uncontrolled host. See docs/perf/aarch64-compare-immediates-2026-09-29.json.gz for all 92 runs including warmups, hashes, exact commands, phase data, source patch and code objects.
