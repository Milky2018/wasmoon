## Description
The 544-byte JIT context combines the generated-code ABI with helper-only state. Separate those responsibilities, allocate optional state only when needed, and keep the existing managed owner/finalizer. Report total storage and allocations, not only the visible context size.

## Design
Keep necessary direct-access fields in a compact prefix; keep helper-only definitions private. Derive compiler offsets from the C layout. Preserve instance isolation and Store arena ownership. Validate inactive and active feature lifecycles, trap/cancellation cleanup, GC roots and shared resources. Produce a standalone review diff.

## Close Notes

The generated-code prefix remains 128 bytes; the native owner decreases from 544 to 480 bytes. Optional segment storage adds 64 bytes only when used and is released on reset. Fallback arenas are lazy; Store sharing and trap activation transfers retain their existing ownership. Helpers recover the inline owner without a private-state back-pointer load. Compiler offsets now come from the C layout; old artifacts remain compatible, confirmed by a cross-version cache probe returning 42.

Measured native one-function construction decreases from four allocations / 648 requested bytes to two / 488; corresponding destruction frees every allocation. A 31-pair lifecycle microbenchmark improves by 45.5%, while AEGIS and GC-loop comparisons do not establish a whole-program speedup or stable regression. Total bookkeeping with segment state remains 544 bytes; this is not a universal 160-byte retained-memory saving.

Validation: strict MoonBit checks, 2,606 native tests, 37 strict C compilations, 62 ASan/UBSan tests plus instrumentation proof, both engines passing all 258 core WAST files, and 24 WASI 0.3 component files / 153 commands. A preliminary WAST timeout passed its isolated rerun and the final full sweep. Windows/Linux CI is separate from this local macOS arm64 acceptance.

See [the measurements and retained evidence](../docs/perf/context-storage-2026-09-29.md). A standalone review patch is exported to `/tmp/wasmoon-context-refactor.diff`.
