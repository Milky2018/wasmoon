# ISS-020: Migrate real register allocation into regalloc and machv_regalloc

## Metadata
- Type: task
- Status: in_progress
- Priority: 0
- Labels: regalloc, machv_regalloc, migration, agent
- Assignee: unassigned
- Created: 2026-07-04
- Updated: 2026-07-04
- External ref: none

## Description
Move the production register allocation implementation now under `modules/wasmoon/vcode/regalloc` into the reusable `regalloc` algorithm module plus the MachV-specific `machv_regalloc` adapter.

## Design
Keep `regalloc` purely algorithmic over an abstract program model. Move live ranges, bundles, backtracking, constraints, spill decisions, reload coalescing, stack layout policy that is algorithm-owned, and allocation checking into reusable APIs where possible. Keep MachV projection, operand rewriting, reload/spill insertion, and MachV stack-frame edits in `machv_regalloc`.

## Acceptance Criteria
- [ ] `modules/regalloc` contains the real allocator algorithm rather than the deterministic baseline placeholder.
- [ ] `modules/regalloc` does not import MachV, Wasmoon, VCode, Wasm, JIT, or target packages.
- [ ] `modules/machv_regalloc` applies allocations back to MachV, including operand rewriting, reload/spill insertion, and stack-slot materialization.
- [ ] Old `vcode/regalloc` tests are ported or tracked; allocation checker behavior is preserved.
- [ ] Existing JIT correctness tests pass after Wasmoon consumes the migrated allocator.

Remaining work: insert explicit reload/spill moves around instructions with spilled operands once MachV load/store pseudos are fully owned by the generic emitter path.
- 2026-07-04: `machv_regalloc.allocate_and_apply` now inserts MachV `Load(StackSlot)` and `Store(StackSlot)` pseudos around instructions with spilled operands, reserves scratch registers when possible, rewrites spilled operands through those scratch registers, and has a regression test that verifies reload/store insertion and removal of virtual operands. Remaining work: migrate the old VCode backtracking allocator, checker behavior, reload coalescing, rematerialization, and stress tests into reusable `regalloc` plus MachV adapter APIs before closing.

The linear scan now evicts a longer active interval for a shorter current interval when that reduces spill pressure. Added tests for live-range construction and eviction behavior. Full native gate passed with 1982 tests. Remaining work: adapt the old VCode backtracking allocator/checker/reload-coalescing/rematerialization code to this pure model, then remove the Wasmoon-owned implementations.
