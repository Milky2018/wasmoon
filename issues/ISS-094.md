## Description
`Milky2018/milkir_machv/lower.lower_function` is the main path from MilkIR to
MachV, but its public signature has many optional parameters for ISA, ABI
settings, embedding roles, context layout, call convention, helper symbols,
trap payloads, extension lowering, import counts, and IR optimization.

That is powerful, but it is not a friendly interface for ordinary users who
want to lower a verified MilkIR function with an explicit target.

## Design
Add a small user-facing configuration object or facade that groups lowering
options into coherent concepts. Keep advanced hooks available, but do not force
every caller to understand the full internal lowering context.

The design should preserve the existing explicit-ISA rule: reusable lowering
must not detect the host architecture itself.

## Acceptance Criteria
- [ ] A documented user-facing lowering configuration or facade exists.
- [ ] README examples use the new lower-level configuration path.
- [ ] Advanced hooks such as extension lowering and helper-symbol maps remain available without dominating the simple case.
- [ ] Existing Wasmoon JIT integration still passes explicit ABI/context data.
- [ ] `moon info`, native checks, and relevant README tests pass.
