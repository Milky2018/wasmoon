## Description
The misc forced-GC host contract cannot be implemented as a no-op. Store.collect_garbage currently ignores the interpreter heap, and interpreter host entry does not retain active operand stacks, locals or consumed arguments. Native collection must include the active JIT activation as well as Store and parked-continuation roots.

## Acceptance Criteria
- [x] A public host-call regression proves unreachable objects are collected while live locals, operands and arguments survive on both heap representations.
- [x] Forced native collection uses the active activation's root scopes without dropping parked or Store roots.
- [x] The unchanged forced-GC misc inputs run with a real host callback; failures remain visible until fixed.
- [x] Native tests and relevant sanitizer checks pass.
