## Question

How should Wasmoon select a target, provide embedding and runtime information, invoke the mandatory MilkIR-to-MachV-to-Target-VCode pipeline, resolve symbols, install native code, and own Cwasm or cache artifacts without leaking product concepts into reusable modules?

## Acceptance Criteria

- [ ] The Wasmoon-owned orchestration API and reusable compiler APIs have explicit ownership boundaries.
- [ ] Runtime symbols, VMContext layout, executable memory, traps, stack maps, and code installation each have one owner.
- [ ] The decision states whether any persisted artifact contains MachV, Target VCode, or only emitted code and metadata.
