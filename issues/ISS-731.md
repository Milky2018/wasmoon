# ISS-731: Assign proven register homes without transfer planning

## Description

The general operand assignment phase constructs register residency and
transfer state even when every operand already uses its assigned home.
This phase is a measurable part of cold compilation.

## Design

Admit an entire function before assigning any operands. Its live segments
must occupy their register homes. Every operand must be untied, have a
register home, and satisfy any fixed-register constraint at that home.
An instruction cannot mix early definitions with late uses on this path.
The regular transfer planner handles all other functions. Edge transfers
and final allocation validation still run.

## Acceptance Criteria

- [x] Preserve byte-identical artifacts for twenty original inputs over
  four uncontended cold pairs each.
- [x] Improve aggregate compilation without exceeding the declared family
  regression limits.
- [ ] Verify the final platform run.
