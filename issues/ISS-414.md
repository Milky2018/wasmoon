## Description

One run of `moon test --target native --warn-list +73` reached
`Milky2018/milkir/milkir.whitebox_test.exe` and remained at 100% CPU without
output for more than four minutes. The stall is not reproducible on the current
development tree: a cold-start full native run completes in about 24 seconds,
and the same change SHA has passed Linux AMD64 and macOS ARM64 validation.

Keep this issue open because the original cause is still unknown. Treat it as
an intermittent investigation, not as evidence that the native gate is
currently broken and not as a blocker for ISS-408.
