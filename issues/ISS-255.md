# ISS-255: Wire complete current-version compile phase metrics

## Description

The current metrics schema advertises `regalloc_us`, `emit_us`, allocation
phases, and spill statistics, but production records semantic lowering, target
lowering, allocation, frame planning, and emission together as `lower_us`.
The advertised fields remain zero and cannot guide optimization.

## Design

Time phases at the Wasmoon-owned target composition seam so reusable targets and
regalloc do not import product metrics. Record semantic lowering, target
lowering, allocation, frame planning, and emission separately for both AArch64
and AMD64, and populate allocation summary counts from the final plan.

## Acceptance Criteria

- [x] Metrics distinguish semantic lowering, target lowering, regalloc, frame
      planning, and emission.
- [x] `regalloc_us`, `emit_us`, spill slots, spills, reloads, and register moves
      describe actual production work rather than unwired zero values.
- [x] Per-function phase totals are internally consistent with module time.
- [x] Metrics schema tests and documentation match the produced JSON.
