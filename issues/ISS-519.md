## Description
Implement actual native typed-continuation operations and stack ownership. Suspend only guest/native frames, preserve handler chains and argument/result transport, and retain precise trap and exception behavior without interpreter fallback.

- [x] Parked stack cancellation, root lifetime and completed-stack release pass native and ASan regressions.
