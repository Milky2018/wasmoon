## Description
ISS-601 recorded two reproducible roughly 0.9% AEGIS increases versus 77d901d0. In the later ISS-603 session, the same old comparison measured +0.28% with an interval crossing zero; the final metadata optimization measured -0.14% versus 77d901d0, also inconclusive. Identical cache hashes rule out changed serialized guest code. Fixed mapping/context-offset controls did not establish a version penalty. Do not label the earlier observation fixed or attribute it to a hardware mechanism without new evidence.
