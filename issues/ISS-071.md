# ISS-071: Move subtype indirect-check slow path out of MachV instruction core

## Description
`TypeCheckSubtypeIndirect(Int, ExternalName)` encodes Wasm GC subtype-check
semantics in MachV instruction core. It combines a fast exact-match compare with
a Wasmoon runtime helper call on the slow path.

## Design
Move the existing fast-path plus helper slow-path behavior to Wasmoon-owned
lowering or a generic target-level conditional-helper sequence. The MachV core
must not expose subtype-check instruction names or Wasm type-index payloads.

If the current MachV block representation cannot express the full slow-path
sequence cleanly in one change, add a precise TODO at the temporary generic
boundary and keep the pseudo-op name/payload generic rather than Wasm-specific.

## Acceptance Criteria
- [ ] `TypeCheckSubtypeIndirect(Int, ExternalName)` is removed or replaced by a generic non-Wasm mechanism.
- [ ] Fast exact-match behavior is preserved.
