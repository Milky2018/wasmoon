## Notes
- 2026-09-09: Wasmtime 40 passes sync-streams after wasm-tools 1.254 binary normalization. Minimal positive/negative controls show the two sync-lowered async trap assertions and the invalid subtask.cancel assertion have obsolete precedence expectations: Wasmtime reports unreachable and an invalid handle, respectively. The original full trap script uses newer threading opcodes unsupported by Wasmtime 40, so oracle checks use independent minimal components.
- A ready synchronous future waiter permits the next async call to complete eagerly in Wasmtime 40; the current runtime leaves that call queued. A non-ready waiter must still keep it queued. Those controls differ from the imported task-builtins scheduling expectations. Recheck the oracle version before changing the existing local ready-wait expectations.

- 2026-09-09: The provisional ready-wait change passes all 387 future-gated commands and 64 local commands per engine, but introduces two task-builtins failures in misc. Do not accept this tradeoff. ISS-488 builds the matching 50.0.0-dev oracle to resolve the version mismatch.
