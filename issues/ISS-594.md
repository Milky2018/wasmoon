## Description
Select add/sub of a negative modular constant as sub/add of its encodable positive magnitude. The current i32 add(-64) builds a constant with MOV/MOVK before ADD instead of emitting SUB immediate.

## Design
Keep this decision in AArch64 direct selection, using the actual operation width for modular negation and retaining register-form fallback. Preserve operand direction, shared constants, and existing immediate forms. Do not change memory-base reuse, register reservations, or optimizer budgets.

## Acceptance Criteria
- [x] i32/i64 negative immediates select one arithmetic instruction when encodable, including shifted immediates.
- [x] Unencodable values and wrapping boundaries retain correct semantics; shared constants and reversed subtraction are covered.
- [x] Full native gates and external core regressions pass; report exact code changes without assuming an end-to-end speedup.
- [x] Verify and document historical memory-base pressure decisions against current source.
