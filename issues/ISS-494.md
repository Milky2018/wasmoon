# ISS-494: Preserve atomic memory semantics across interpreter and compiler

## Description
Wasm atomics currently lower to ordinary loads/stores, and read-modify-write instructions become separate accesses. The interpreter does the same and treats fence as a no-op. Native lowering already has sequentially consistent atomic operations on both targets; connect the frontend and generic IR to that contract and provide real interpreter atomics before adding thread scheduling.

## Acceptance Criteria
- [x] Atomic load/store/RMW/compare-exchange/fence retain sequentially consistent effects through IR optimization and native lowering.
- [x] Interpreter atomic operations use native atomic accesses at each supported width.
- [x] Alignment, bounds, truncation and zero-extension behavior agree across engines.
- [x] Independent concurrency and optimizer regressions plus existing conformance gates pass.
