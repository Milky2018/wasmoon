## Description
Published 0.17.2 reportedly stalls while compiling the pinned Core builtin
wasm-gc test module, reaching about 9 GiB RSS before the first test. A direct
public `compile_module` call reproduces the report without a Store, imports or
guest execution. The 0.17.1 embedding completed its 2808 selected tests.

## Design
Keep the precise function-root frame and completely overwrite each safepoint's
bitmap. Emit compact native indexed-store loops for adjacent equal mask words
instead of expanding every word at every safepoint. Short runs and one-time
entry initialization retain straight-line stores. Loops contain no calls or
safepoints; no predecessor bitmap cache, runtime ABI or root policy changes.

## Notes
- Fresh pinned Core build matched the issue's exact input SHA256
  `932992a2ea94328f723cace528eaaf9311d12e20d3be87fedc5d98a3f6c84305`.
  Published 0.17.2 and unmodified current source both crossed a 6 GiB diagnostic
  RSS ceiling while compiling `____moonbit_init`, with no guest execution.
- Its 17,459 root slots require 273 bitmap words. At every safepoint the old
  emitter expanded all words, even with only 1–41 live roots. At update 13,312
  its native value table already held 3,872,443 entries. This generated-code
  multiplication, not a running guest collector, caused the memory growth.
- The new bounded-work lowering regression failed before repair. Actual GC
  tests cover sparse sibling paths and five dense words at O0/O2/O3; x64
  selection/register-allocation tests cover the loop block parameters.
- Performance optimization in ISS-661/ISS-671 remains deferred. This task
  addresses a blocking compiler regression rather than the throughput target.

## Close Notes
Local repair and original full-module public compilation verified. All 9,612
functions compile in 11.14 seconds at 1.33 GiB sampled peak RSS; additional
complete runs also verify the returned artifact. These are local diagnostic
observations, not clean CI acceptance or paired performance estimates.

Native 3,068/3,068, wasm 1,458/1,458, fresh isolated ASan/UBSan 294/294 and both
ASan positive controls passed. Full release CLI interpreter/JIT each passed
258 Core files/62,563 assertions with register-allocation, GC and barrier
verification enabled. Strict both targets, info/fmt, boundaries and Python
178 tests/54 existing skips passed. Actual execution is macOS ARM64; Linux
LSan, Windows/x64 execution and the original 2,808-test builtin driver are not
claimed. All owned diagnostic copies, builds, logs and caches were removed.
See the [diagnosis and receipt](../docs/evidence/builtin-compilation-2026-10-23/README.md).
