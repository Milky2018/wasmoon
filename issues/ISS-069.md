# ISS-069: Remove VMContext memory-base pseudo-op from MachV instruction core

## Description
`LoadMemBase(Int)` encodes Wasmoon VMContext memory layout in MachV instruction
core. Its payload is a memory index and its emitter behavior knows primary
memory, memory directory, descriptor stride, and mem0 caching policy.

## Design
Lower memory-base access before generic MachV emission. The replacement should
use existing generic pointer loads and explicit runtime-context layout data, or
generic function metadata for cached runtime fields.

Do not remove mem0 caching behavior accidentally. Replace opcode scanning such
as `Function::uses_mem0` with explicit generic metadata or another non-Wasm
mechanism.

## Acceptance Criteria
- [ ] `LoadMemBase(Int)` is removed from MachV instruction core.
- [ ] Memory base access is represented with generic loads or explicit generic runtime-context field access before emission.
- [ ] `Function::uses_mem0` or equivalent logic no longer scans for a Wasm memory opcode.
- [ ] Existing mem0 cache behavior is preserved.
- [ ] Relevant memory, memory64, and multi-memory WAST tests pass.
- [ ] Public `.mbti` diffs are reviewed with `moon info --target native`.
- [ ] `git diff --check` passes.
- [ ] `moon check --target native --warn-list +73 --diagnostic-limit=200` passes.
- [ ] `moon test --target native --warn-list +73 --diagnostic-limit=200` passes.
