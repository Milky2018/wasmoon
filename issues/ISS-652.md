## Description
Replace the fixed cooperative instruction interval with a positive per-invocation
quantum. Keep scheduling granularity independent of total budgets and stack limits.

## Acceptance Criteria
- [x] Default 1024 remains compatible; reject nonpositive quanta.
- [x] Preserve the remainder across suspension and ordinary guest calls.
- [x] Document fresh guest-body and host-reentry counters.
- [x] Poll cancellation without charging extra safepoints at quantum boundaries.
- [x] Cover independent invocations, parked GC roots, cancellation and scope accounting.
- [x] Measure sync, inline resume and event-loop integration separately.

## Close Notes
- Add `cooperative_quantum` to the public resumable call seam and preserve it in
  newly created guest bodies. Captured contexts keep their remaining count.
- Four public tests run on native and wasm. A fixed-counter counterfactual fails.
- The serial auto-cleaned benchmark checks loop/call/memory workloads and accepts
  compiler-produced binaries. A Clang -O2 wasm32 volatile-memory loop also passes
  all modes: at one million iterations, 15625 vs 976 yields (1024 vs 16384).
- One local ARM64 release trial: compiler-module sync 257ms, inline 252/242ms,
  scheduled 436/266ms. These are diagnostic samples, not general speed claims.
- Historical #549 measurements are not relabeled as current acceptance.
- Final full native 2886/2886 and wasm 1354/1354 pass, with strict checks on
  both targets, info/fmt and native GC/register-allocation verification.
