# ISS-525: Port the complete runtime to native Windows AMD64

## Metadata
- Type: feature
- Status: in_progress
- Priority: 1
- Labels: windows, runtime, jit, abi, ci

- Updated: 2026-09-15
- External ref: none

## Description
Provide the native Windows runtime required to validate WASIp1 descriptor readiness through both actual execution engines. The current C runtime still depends on POSIX fiber stacks, signal recovery and host descriptor operations; Windows-specific stubs alone do not establish support.

## Acceptance Criteria
- [ ] Native Windows CI builds and executes the CLI and tests.
- [ ] Host/JIT transitions preserve the Windows ABI, stack alignment and nonvolatile registers.
- [ ] Fibers, traps, GC roots, executable memory and cancellation work on Windows.
- [ ] Both engines execute core/component regressions and the Windows readiness guest tests.
- [ ] Linux AMD64 and macOS ARM64 gates remain green.
