## Description

Cwasm v8 serializes per-function code plus lossy integer fixups and a single cancellation bit. It cannot reconstruct the verified `UnlinkedCodeObject` seam or express the strict compatibility contract selected by ISS-190.

## Design

Introduce the target-portable `Milky2018/wasmoon_jit/artifact` package and define ordinary-data records for module identity, compilation policy, the complete compatibility manifest, function identities and signatures, and every `UnlinkedCodeObject` field. Persist symbolic identities only; never persist resolved addresses, linked images, compiler IR, or executable memory.

## Acceptance Criteria
- [ ] The manifest covers format, target/OS ABI/endianness/pointer width, CPU features, JIT ABI, codegen revision, source/semantic digest, and compilation policy.
- [ ] Artifact code records preserve relocations, traps, sources, safepoints, stack maps, unwind, signatures, and stable function identity without resolved addresses.
- [ ] Unknown targets, symbols, policy fields, and manifest fields are structurally representable as decode errors rather than fallback values.
- [ ] Public artifact types remain ordinary target-portable data and do not import native FFI or installers.
