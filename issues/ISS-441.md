## Description

Seven cache-isolated AEGIS-128L captures put median in-process module
compilation at 161,372 us. The current top-level attribution is 34,729 us for
MilkIR optimization, 20,885 us for semantic lowering, 23,100 us for target
lowering, 62,377 us for register allocation, 4,011 us for frame planning,
4,452 us for emission, and 10,783 us of aligned residual work.

The remaining stage boundaries are too broad to choose safely between verifier,
construction, analysis, adapter, and environment work. Detailed metrics add
only about 1.9 ms, so the gap is real rather than an instrumentation artifact.
On the same host, Wasmtime 40.0.0 with cache and parallel compilation disabled
has a 36.757 ms median command-level compile time.

## Design

Extend the existing embedding-owned timing protocol without putting clocks in
reusable compiler modules. Attribute at least:

- MilkIR verification, semantic construction, mandatory cleanup, and each
  cleanup verification;
- target analysis, VCode construction, target finalization, and any target
  verification fallback;
- `VCodeFunctionView` construction separately from allocation phases;
- Wasm translation, semantic-environment construction, and other work currently
  included in the module-level residual.

Detailed metrics may change schema, but compact metrics must retain negligible
overhead. Do not use sampling results that materially perturb compilation, and
do not add parallel compilation to the benchmark.

## Acceptance Criteria
- [ ] Detailed metrics assign the semantic, target, regalloc-adapter, and residual costs to named subphases whose totals reconcile with their enclosing stages.
- [ ] Reusable compiler modules report phase boundaries through optional observers and do not read a clock directly.
- [ ] Disabled metrics do not allocate phase records or call observers.
- [ ] At least seven cache-isolated AEGIS-128L captures record the new fields, the exact revision, unchanged per-function code sizes, and the compact-versus-detailed measurement tax.
- [ ] The report compares against serial, cache-disabled Wasmtime only as context and does not make Wasmtime a CI dependency.
- [ ] Metrics schema tests, focused native compiler tests, formatting, warning-73 checking, and generated interfaces pass.
