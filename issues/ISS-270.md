## Description
The exact official Component Model snapshot at
`d6b48f2f28880fbf3cbc3777fba7ac31084c7540` has 13 files with at least one
valid form requiring a post-0.3 gated proposal. Wasmoon passes 5 files
strictly. The remaining 8 files expose 70 command failures involving
additional async built-ins, the stackful async ABI, component threading,
64-bit canonical ABI contexts, component attributes, and composite-value
harness coverage.

## Design
Implement each gated feature behind its explicit semantic boundary while
keeping the official files assigned by their highest required feature level.
Do not enable a syntax without its validator and runtime contracts.

## Acceptance Criteria
- [x] All 13 `future-gated` files pass.
- [x] Each accepted gated syntax has corresponding validation and runtime
      behavior rather than parse-only acceptance.
- [x] The component WAST harness executes all actions and values in the lane.
- [x] Focused regressions and all component snapshot/quality gates pass.
