## Description
Extend the managed DWARF ownership model to GC heaps, linear-memory descriptors and shared indirect tables. Resource handles must retain the allocation instead of relying on callers keeping an unrelated Store alive.

## Design
Allocate each descriptor directly as a MoonBit external object with a C finalizer. FFI parameters borrow handles. Context bindings, parked roots, exception roots and atomic wait registrations retain the resources they use. Logical close drops its reference and invalidates aliases of that logical view; independently retained handles and native bindings remain valid. Stable table descriptors publish entry-array relocation to every context. Native backlinks are non-owning and are unlinked before dropping references. Native test workers retain on the calling thread and release after joining.

## Acceptance Criteria
- [x] Memory, heap and table handles use MoonBit RC without a parallel native owner count.
- [x] Contexts, wait registrations and exception roots outlive the creating scope safely.
- [x] Final-reference release frees allocations without explicit close; logical close is idempotent.
- [x] Table growth updates multiple contexts and repeated bindings to the same table.
- [x] Managed empty handles safely preserve null checks and reject growth.
- [x] Strict MoonBit/C checks, full native tests and ASan/UBSan pass.

## Notes
The C binding list on a table and the root-registration list on a heap are non-owning, avoiding reference cycles. Empty handles are managed objects rather than NULL, because normal MoonBit RC requires an object header. Public descriptor retain/free operations are removed; raw byte addresses still require a live owner.

## Close Notes
Converted all three resources to directly allocated MoonBit-managed descriptors with C finalizers. Removed public manual descriptor retain/free and native owner counters. Contexts and registrations retain their dependencies; table growth updates all bound contexts and aliases. Added retaining context memory access and documented raw-address lifetime requirements.

ASan caught premature owner release in a new test that extracted a raw integer address as its last context use. The replacement descriptor API retains the allocation through the read; the regression also verifies a descriptor remains usable after the context finalizer runs. Lexical scope is not used as a lifetime guarantee.

Validated on macOS arm64: 2576 native tests, 57 ASan/UBSan tests with positive instrumentation controls, 35 warning-clean C translation units, strict MoonBit warning checks, module-boundary and JIT-context-lifetime audits, and 168 Python tests (54 platform-dependent skips). Sanitizers cover generated MoonBit C and native stubs, not JIT-generated machine code or MoonBit runtime internals. Cross-platform CI is dispatched after push; local results do not imply remote completion.
