## Description
Add bounded factor-two unrolling for larger canonical loops whose exact trip count is known, including correct handling for odd trip counts and loops shorter than the factor.

## Design
Execute `trip_count % 2` iterations in the preheader, then compose two body state transitions per remaining loop iteration and rewrite the latch arguments to the second transition's state. Keep the header condition and original exit path. Apply the transform only when the counted-loop proof guarantees all skipped intermediate checks would continue.

## Acceptance Criteria
- [ ] Even trip counts execute two original iterations per transformed loop iteration.
- [ ] Odd trip counts execute the exact remainder before the factor-two loop.
- [ ] Zero-trip, one-trip, and factor-larger-than-trip cases preserve behavior.
- [ ] Loop-carried values and side effects remain exact under partial unrolling.
- [ ] Code-growth policy rejects oversized transformations without mutation.
- [ ] Focused and differential tests pass.
