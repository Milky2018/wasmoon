# ISS-243: Remove raw JIT FFI and implementation-detail public surfaces

## Description

The public `Milky2018/wasmoon_jit/jit_ffi` package still exposes hundreds of raw C declarations, and product packages import memory-descriptor functions directly. Root interfaces also expose native-stub inventory and glue-coverage helpers that are implementation details rather than the deep JIT facade chosen in ISS-191.

## Design

Move native declarations into the Wasmoon-owned root implementation, replace external raw imports with narrow domain operations, delete the public FFI package, and contract generated interfaces to compiler, artifact, installation, installed-code, and required runtime operations.

## Acceptance Criteria
- [x] No package imports `Milky2018/wasmoon_jit/jit_ffi` and that package/interface is deleted.
- [x] Runtime and JIT consumers use narrow root operations instead of raw C symbols.
- [x] Native-stub inventory, raw address getters, patch helpers, and construction-only glue leave public interfaces.
- [x] Boundary audits enforce the final product funnel without migration exceptions.
- [x] Strict checks, native tests, and JIT/WASI regression gates pass.

## Close Notes

Closed on 2026-07-22 after moving all MoonBit native declarations into the private implementation of `Milky2018/wasmoon_jit`, deleting the `jit_ffi` package and interface, and routing product consumers through memory-descriptor, native-value-slot, hostcall-slot, import-trampoline, and runtime-symbol facades. Native glue inventories, native address getters, and code-object construction/fixup helpers no longer appear in generated public interfaces. The internal compatibility audit now rejects the retired package, imports, raw address getters, and construction-only types.

Validation passed with strict native and default `moon check`, 2277 native MoonBit tests, 940 wasm-gc plus 1337 native default tests, both boundary audits, 258/258 JIT WAST files (62,563 assertions), and 90/90 WASI Preview 1 JIT/interpreter cases.
