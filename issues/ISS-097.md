## Description
`machv_regalloc` still exposes helpers documented as historical or backwards-compatible: `Loc::is_spilled`, `Loc::get_spill_slot`, and `verify_allocation_aarch64`. These retain old API shapes after the regalloc output migration.

## Design
Replace internal call sites with direct pattern matching or the generic verifier, then delete the compatibility helpers.

## Acceptance Criteria
- [x] `Loc::is_spilled` and `Loc::get_spill_slot` are removed.
- [x] `verify_allocation_aarch64` is removed.
- [x] No compatibility wording remains in `machv_regalloc` code for these APIs.
