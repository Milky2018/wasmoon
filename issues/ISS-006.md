## Description
Create `modules/machv` as the reusable low-level virtual-register machine IR used after instruction selection and before machine-code emission.

## Design
MachV should express functions, blocks, instructions, operands, virtual and physical registers, register classes, constraints, calls, clobbers, stack slots, branches, and stack effects. It must not own ISA-specific ABI policy, Wasmoon runtime helper resolution, JIT executable memory, or `.cwasm` metadata.

## Acceptance Criteria
- [x] `machv` defines the common machine-level IR model needed by ISA targets, register allocation, and emitters.
- [x] MachV does not depend on `milkir`, `wasm_core`, `wasmoon_jit`, or `wasmoon`.
- [x] MachV can represent the existing VCode shapes needed by current JIT lowering.
- [x] Known incomplete machine IR features include scoped `TODO(machv)` comments.
