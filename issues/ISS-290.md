## Description
The component runtime has pinned conformance suites and ordinary unit tests, but
it lacks adversarial binary fuzzing, a current Wasmtime semantic oracle,
logical resource-lifecycle checks, a repeatable security audit, and large
component stress coverage.

## Design
Add a deterministic component hardening harness with retained seeds and
machine-readable reports. Keep bounded deterministic smoke lanes in pull
requests and run larger campaigns on a scheduled or manually dispatched
workflow. Check MoonBit-managed resource tables directly in addition to
ASan/LSan, because native leak sanitizers cannot detect retained Map entries.

## Acceptance Criteria
- [x] Fixed-seed component parser, validator, and invocation fuzzing is
      reproducible and rejects empty campaigns.
- [x] Semantic component cases agree with the current pinned Wasmtime release.
- [x] Resource, stream, future, task, and waitable lifecycle tests detect
      retained logical state.
- [x] A source and generated-interface security audit runs as a blocking gate.
- [x] Large generated components exercise width, depth, exports, and repeated
      invocation under explicit time and size limits.
- [x] CI retains machine-readable reports and failing seeds.
