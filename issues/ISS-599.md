## Description
ISS-592 established a causal context-offset effect in controlled AEGIS runs, but did not identify its hardware or instruction-level mechanism. Distinguish load/store dependency effects, cache/data placement, and process-level scheduling/layout interference without treating alignment as a production fix.

## Design
Extract the exact hot machine-code function into a same-process harness. Compare original code with a diagnostic version reusing an already-live memory-base register. Capture actual guest input/stack addresses if a synthetic fixture fails to reproduce. Verify findings against the full original workload and preserve negative results.

## Acceptance Criteria

- [x] Run discriminating address/code interventions and report which hypotheses remain.
- [x] Retain raw data and state explicitly whether a hardware mechanism is established.

## Close Notes
Instruction/address-level causality is established on the fixed original baseline. Same-process replay shows a +1.577% context-offset difference; native SP +64 reverses it, +128 removes the established gap, and +256 restores it. Moving only the context load sources shows the corresponding address dependence while preserving load/instruction counts. Relocating the two 32-bit native slots whose low bytes are 0xc8/0xcc removes the first-call replay gap; a frame-size-only control does not.

The full program has nine entry-SP residues, so moving those two slots alone leaves a +0.648% residual. A 31-pair whole-program confirmation instead reuses the already-live x12 memory base for all eight redundant loop loads: original offset difference +1.133% [0.812, 1.475], altered difference +0.036% [-0.273, 0.275]. Runtime code edits are diagnostic only; no production change or current-revision speedup is claimed.

This closes the instruction/address-level investigation, not the identification of an exact hardware unit. Partial-address load/store disambiguation/forwarding is the leading interpretation; no event-specific PMU confirmation was obtained. Negative experiments, residual effects and all samples are retained in [the report and evidence archive](../docs/perf/context-mechanism-2026-09-29.md).
