# ISS-734: Compute only flat types for Component signature queries

## Metadata
- Type: task
- Status: in_progress
- Priority: 2
- Labels: component, performance
- Assignee: Codex
- Created: 2026-11-04
- Updated: 2026-11-04

## Description

Canonical argument and result conversion repeatedly queries flat core
types. The query also computes a memory layout and a memory-use flag
that its callers do not consume.

## Design

Use the existing flat-type query with the same pointer width, flat
limit, and error mapping. The full canonical plan remains available to
callers that consume memory metadata.

## Acceptance Criteria

- [x] Compare the original asserted scalar Component workload in five
  cold process pairs with the same input, ABI, and engine options.
- [x] Reduce median paired invocation time by at least eight percent.
- [ ] Verify the final platform run.

## Notes

- The 200,000-call invocation median was 597.115 ms before and 496.473 ms
  after the change. The paired median reduction was 17.42%.
