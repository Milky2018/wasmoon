## Description
Finish the vector operation migration by removing every lane-encoded legacy constructor, temporary adapter, and redundant builder surface, then validate public interfaces and end-to-end SIMD behavior.

## Design
Use source search and generated interface review to prove the old representation is gone. Keep ergonomic source-language helpers only where they hide real construction logic; generic wrappers that merely accept arbitrary `VectorOp` values should not duplicate the verifier contract.

## Acceptance Criteria
- [x] No legacy `V128Add8`-style copied constructor remains.
- [x] No temporary conversion, compatibility adapter, or public generic `VectorOp` builder wrapper remains.
- [x] Generated interfaces document the normalized vector operation families.
- [x] Formatting, warning-denied checks, full tests, module-boundary audit, and diff checks pass after the API contraction.
