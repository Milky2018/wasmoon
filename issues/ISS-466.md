# ISS-466: Fix filesystem defects exposed by explicit-rights P1 guests

## Description

Removing the scratch-rights coverage blocker exposed repeatable defects:
readdir heap corruption and stale directory cursors, UTF-8 readlink/readdir corruption,
lost trailing-slash constraints in unlink/symlink/hardlink operations, and
Darwin JIT positioned writes ignoring the required append behavior.

## Design

Replace the duplicated two-pass directory serializers with a single-pass,
growing-buffer implementation. Reopen `.` relative to the directory fd for
independent cursors, retaining descriptor identity after rename. Extract native
directory handling and share its file-type classifier with the filesystem FFI.
Keep readlink payloads and serialized directory names as UTF-8 bytes. Preserve trailing separators at native leaf
operations and align Darwin JIT append behavior with the interpreter.

## Acceptance Criteria
- [x] Reproduce the directory heap-buffer-overflow under AddressSanitizer.
- [x] Pass the same ASan repeated-read probe after the single-pass refactor.
- [x] Cover truncated UTF-8 readlink and trailing slash behavior through guest ABI tests.
- [x] Cover append size and unchanged cursor through both execution engines.
- [x] Preserve source snapshot and upstream assertions in adapted guest runs.

## Notes

The original directory serializer counted zero entries from an already-consumed
shared cursor, rewound, then wrote new entries into a four-byte allocation.
ASan identified the out-of-bounds store before the later allocator crash observed
under LLDB. A fresh cursor alone would not make two-pass sizing safe against
concurrent directory mutation; the serializer now writes each entry once.

## Close Notes

The retained native ASan probe reads an empty directory, creates an entry, then
verifies 100 repeated scans. Native and public guest regressions cover the
other fixes. `explicit-rights` remains a strict diagnostic profile: its known
rights-errno incompatibilities are not counted as passing tests.
