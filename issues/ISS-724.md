## Description
Repeated inlined polls invalidate ordinary object projections. Small live root
sets also maintain whole-function shadow definitions along pure paths. Address
both boundaries while preserving the complete checked execution path.

## Design
See [guarded object reads and sparse call frames](../docs/perf/sparse-root-regions.md).
Thread constant empty dispatches, version bounded acyclic read regions using the
existing independent credit proof, and reuse the existing stack-owned root-frame
protocol only around producer-admitted sparse rooted calls. Keep original poll
charges, exact views, roots, barriers, quotas, faults, unwind and parking rules.
