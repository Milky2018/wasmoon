## Description
Extend safe full unrolling beyond pure scalar bodies so multiple loop-carried values, dependent instruction chains, multi-result instructions, calls, stores, loads, and traps retain their original execution order and dynamic count.

## Design
Generalize per-iteration value remapping across all header parameters and instruction results. Clone zero-result and multi-result instructions through `Function::new_inst`, preserve metadata, and compute each iteration's next header arguments from the remapped latch edge. Reject any operand or edge that cannot be mapped completely.

## Acceptance Criteria
- [ ] Multiple loop-carried block parameters are remapped across every unrolled iteration.
- [ ] Dependent chains and multi-result instructions use the correct cloned values.
- [ ] Calls, stores, loads, and traps retain execution order and dynamic count.
- [ ] A failed mapping leaves the original function unchanged.
- [ ] Verifier, snapshot, and effect-focused tests pass on native and wasm-gc.
