# ISS-240: Delete v8 Cwasm and public patch surfaces

## Description

After production and cache cutover, the v8 `/cwasm` package, resolved-before-serialization adapters, negative runtime fixup identities, and public executable patch helpers become dead compatibility surface.

## Design

Delete those implementations and their compatibility tests rather than forwarding them. Keep native executable-memory primitives behind the `wasmoon_jit` root installer, update generated interfaces and documentation, and prove the old names and package imports are absent.

## Acceptance Criteria
- [x] `/cwasm`, `PrecompiledModule`, `CompiledEntry`, `CwasmArtifact`, v8 target adapters, and negative fixup-index helpers are deleted.
- [x] Public raw allocation/copy/patch helpers leave generated interfaces; only the root installer owns executable-memory mutation.
- [x] Package manifests, READMEs, examples, boundary audits, and generated interfaces describe only the v9 artifact seam.
- [x] Source search finds no legacy compatibility aliases or forwarding APIs.
- [x] Full native/default tests and required WAST/component/WASIp1 gates pass after deletion.
