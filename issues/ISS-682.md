# ISS-682: Compact context-bound callable entries without sharing mutable code

## Description
Callable registry addresses reveal 16 KiB spacing between context-binding
entries. Each ARM64 entry is only 36 bytes; the previous JITModule installed each
with its own executable mapping. Main function code already has a separate
transactional installation. Bound entries remain an independent layout target.

## Design
Measure asserted monomorphic and polymorphic indirect-call controls first.
Consider one immutable, fully initialized installation per context, with one
owner and entry offsets. Keep existing standalone NativeCallable behavior and
all context-binding instructions. Do not introduce a mutable global executable
pool or release shared code while Store callable owners still retain it.
