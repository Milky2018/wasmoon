## Description
C-owned memory descriptors, GC heaps, indirect tables and DWARF builders use Int64 handles across MoonBit FFI. Distinct external types can represent those pointers directly without an additional allocation or a change in ownership.

## Design
Use nominal external types and matching C pointer signatures throughout resource operations and pointer arrays. Keep integers for machine-code addresses, tagged guest values and actual address arithmetic. Preserve the existing explicit ownership and managed-object finalizers. Change null checks to typed operations; do not introduce public integer-to-handle casts.

## Notes
The existing managed resolver, reactor, fiber and executable-code objects retain their finalizers. External types do not provide automatic cleanup or extend a borrowed pointer's lifetime.
