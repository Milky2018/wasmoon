## Description
Support building the complete native Windows AMD64 runtime with Microsoft cl.exe, including interpreter and JIT execution. The existing Windows build relies on Clang's SysV ABI attribute and assembler.

## Design
Keep guest calling conventions explicit at host boundaries. Compile native C with cl.exe and provide compatible assembly/build integration without silently substituting Clang for C compilation. Retain the existing Clang gate and run the full Windows acceptance suites independently for MSVC.

## Acceptance Criteria
- [ ] cl.exe builds the complete native runtime and native tests.
- [ ] Guest/host ABI crossings preserve arguments, results and nonvolatile registers.
- [ ] Independent MSVC CI passes native tests and both engines' core, component, misc, WASIp1 and readiness suites.
- [ ] Existing Clang, Linux and macOS gates pass.
- [ ] Windows documentation describes prerequisites and reproducible build commands.
