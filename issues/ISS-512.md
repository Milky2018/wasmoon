## Description
Replace the missing synchronization foundation with descriptor/address keyed native wait queues. Comparison and enqueue must be indivisible with respect to notification. Waiters retain their memory, have monotonic deadlines, and leave queues before cancellation or destruction. This issue supplies the shared primitive; ISS-476 integrates suspendable guest execution and WAST scheduling.

## Acceptance Criteria
- [x] Wait32/wait64 compare, zero and finite timeout, unsigned notify counts, and address/memory isolation are tested.
- [x] Cancellation, notification, timeout and finalization release queue membership and descriptor ownership exactly once.
- [x] An independent native-thread control verifies notification against real concurrent queue operations.
- [x] Native and ASan tests pass without changing the external test baseline.
