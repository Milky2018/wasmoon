## Description
`modules/wasmoon/README.mbt.md` describes the interpreter as `Full WebAssembly 1.0 support as fallback`. That wording can be read as saying the migrated JIT depends on an interpreter fallback path. The interpreter is a full execution engine and should be documented that way.

## Design
Update README wording only. Describe interpreter support as an independent execution engine with full WebAssembly 1.0 coverage. Do not change runtime behavior or CLI defaults in this issue.
