## Description
After removing duplicate root transport, the 2048-object initializer still spends
1.675s calculating live ranges. A sparse-mask regression emits 129 terminated
blocks for one logical source block because each repeated run becomes a CFG loop.
The bounded store count prevents code explosion, but the allocator still pays for
those artificial cycles and their live references.

## Design
A product-neutral StoreRepeated64 operation checks a positive nonwrapping constant
range and a typed address. Its caller owns allocation and lifetime, as for native
stores. Each target selects one VCode instruction with a late address and three
independent early register temporaries. The emitter writes the bounded local loop;
there is no hidden fixed-register clobber, C helper, call, safepoint or runtime ABI
change. Complete masks, zeros and unknown-predecessor semantics remain intact.
Advance codegen 23 and reject 22 caches; artifact format 12 and JIT ABI 8 remain.
