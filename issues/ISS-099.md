## Description
`wasm_core/types.extract_func_types` is documented as backwards compatibility and replaces non-function subtypes with placeholder empty functions. This behavior is dangerous as a public helper because it can hide type-model mistakes.

## Design
Move any required conversion to the Wasm frontend call site where errors or filtering are explicit, then delete the public helper and stale tests.

## Acceptance Criteria
- [x] `extract_func_types` is removed from `wasm_core/types`.
- [x] Callers no longer rely on placeholder conversion of non-function subtypes.
- [x] Type and frontend tests pass.
