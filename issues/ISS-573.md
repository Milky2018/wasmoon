# ISS-573: Parse implicit recursive groups and compact singleton encoding

## Description
Implicit singleton recursive groups are decoded before the current composite kind is registered, rejecting valid function, struct and array self references. The encoder unconditionally emits explicit singleton wrappers to work around this defect. GitHub #512 reports the same parser problem.

## Design
Use the existing explicit-group pre-scan and placeholder reservation for implicit groups of size one. Omit wrappers only for singleton groups; preserve multi-type boundaries and indices.

## Acceptance Criteria
- [x] Independently encoded singleton self references parse and validate.
- [x] Singleton encoding omits the wrapper, including self references.
- [x] Mutual recursion, three-type cycles and separate groups retain indices and group membership.
- [x] Invalid cross-group forward references remain rejected.
- [x] Strict checks, native tests and external core corpora pass.
