## Description
The pinned Component Model async suite rejects legal synchronous calls made
from async component execution and reports the wrong failure after resource
access poisons an instance. The current dynamic `may_enter` guard conflates an
active native activation, a suspended task, and a permanently poisoned
instance.

## Design
Represent active entry and permanent poisoning as separate state. Apply the
Component Async task-ancestry rules when entering from callbacks or resumed
continuations, and poison only on traps that the specification defines as
poisoning the instance.

  separately records instantiation readiness, active execution, and permanent
  poisoning. Suspended continuations release and reacquire only the active

  them.

  callback steps that reach sync-lowered async imports preserve their
  interpreter or native activation. Removed exception-driven callback replay:
  genuine initial-step errors now propagate and poison the instance.
