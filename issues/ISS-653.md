## Description
Expose an optional accounted-byte limit independent of existing frame/value/
control counts. Include varying local counts and shallow operand/control growth.

## Acceptance Criteria
- [x] Admit before growth, returning a structured recoverable runtime error.
- [x] Account value/local slots, function metadata and control/label metadata.
- [x] Preserve reservations across repeated host/cooperative suspensions.
- [x] Release on returns, tail replacement, exception unwind and cancellation.
- [x] Keep independent count limits and document per-context host reentry.

## Close Notes
- `max_stack_bytes` defaults to None. Portable logical charges are 32/value or
  local, 64/function frame and 96/control with label. Array spare capacity,
  referenced guest objects and host/root-copy buffers are explicitly excluded.
- The stack owns the counter; suspension retains it rather than constructing
  a new budget. New host/guest-body contexts have independent accounting;
  Store-wide reentry depth and pending-work limits still apply separately.
- Five public native/wasm regressions cover exact operand/control boundaries,
  varying locals at equal depth, repeated suspension, host reentry, tail calls
  and 1000 guest exception unwinds. Disabling byte admission makes tests fail.
- No JIT/native-fiber/guest-linear-memory budget or process-memory claim.
- Full native 2891/2891 (with GC/register-allocation verification) and wasm
  1359/1359 pass locally. Strict checks on both targets and info/fmt pass.
