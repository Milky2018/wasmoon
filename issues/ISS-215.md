## Description

The Linux AMD64 paired runner cannot produce a performance report because the fixed legacy binary exits with status 1 during the `gcd.wat` warmup. Metrics are written, but the required output and successful execution contract are not satisfied. Consequently the current tree has no formal x64 runtime, compile-time, or code-size comparison evidence.

## Design

Determine whether the failure is an existing fixed-baseline x64 execution defect, a workload compatibility error, or a runner path/environment error. Preserve one shared, checksum-pinned corpus when possible. Any replacement workload or baseline change requires explicit review and rebuilding both target baselines; do not silently skip the failing workload.

## Acceptance Criteria

- [x] The exact legacy AMD64 warmup failure is reproduced and explained.
- [x] Every checksum-pinned workload executes successfully under both fixed legacy and candidate binaries on Linux AMD64.
- [ ] The runner emits a complete AMD64 performance report and retained raw evidence.
- [ ] Any newly exposed x64 performance regression is filed as an explicit ISS-193 blocker.

## Notes
- 2026-07-20: Run 29716402331 failed at `warmup-legacy` for `docs/perf/machv-migration/workloads/gcd.wat`; the runner exited before writing `perf-report.json`.
- 2026-07-21: Reproduced the fixed commit under an x86_64 Docker environment with the CI MoonBit nightly. A single `i32.rem_u` succeeds, but the remainder-based loop-carried GCD returns the wrong result in the legacy x64 JIT. An equivalent subtraction-based Euclidean GCD succeeds in the same binary, so the pinned self-checking workload now uses that form rather than skipping legacy validation.
- 2026-07-21: The corrected GCD exposed a second fixed-legacy defect: the original monolithic matmul workload trapped at Wasm address `0x100` during initialization. A self-checking 4x4 matrix workload with static input segments and a split hot function preserves nested-loop memory and multiply-add coverage without executing incorrect legacy code. A two-pair Linux AMD64 run then executed all 17 workloads on both binaries and emitted a complete schema-v2 report; native CI evidence is still required before closure.
