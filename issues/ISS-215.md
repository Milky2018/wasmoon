## Description

The Linux AMD64 paired runner cannot produce a performance report because the fixed legacy binary exits with status 1 during the `gcd.wat` warmup. Metrics are written, but the required output and successful execution contract are not satisfied. Consequently the current tree has no formal x64 runtime, compile-time, or code-size comparison evidence.

## Design

Determine whether the failure is an existing fixed-baseline x64 execution defect, a workload compatibility error, or a runner path/environment error. Preserve one shared, checksum-pinned corpus when possible. Any replacement workload or baseline change requires explicit review and rebuilding both target baselines; do not silently skip the failing workload.

## Acceptance Criteria

- [ ] The exact legacy AMD64 warmup failure is reproduced and explained.
- [ ] Every checksum-pinned workload executes successfully under both fixed legacy and candidate binaries on Linux AMD64.
- [ ] The runner emits a complete AMD64 performance report and retained raw evidence.
- [ ] Any newly exposed x64 performance regression is filed as an explicit ISS-193 blocker.
