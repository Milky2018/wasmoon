## Description
The exact official Component Model snapshot at
`d6b48f2f28880fbf3cbc3777fba7ac31084c7540` has 53 files whose valid forms
require only the stable 0.2 feature set. Wasmoon passes 44 files strictly. The
remaining 9 files expose 71 command failures across linking and resource
identity, validator contracts, composite-value WAST harness support, string
trap matching, and resource runtime behavior.

The exact current counts are recorded in this issue and reproduced by the
dedicated strict CI lane. No expected-failure baseline is permitted for these
repository-owned failures.

## Design

tests. Keep the upstream snapshot byte-exact. Do not skip commands or weaken
expected trap and validation behavior.
