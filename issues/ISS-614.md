## Confirmed root cause (2026-09-30)

Darwin's saved-mask siglongjmp restores masks through the process-wide sigprocmask implementation, overwriting async's signal-thread mask. The SIGUSR2 shutdown wakeup can run the ordinary handler before the worker enters sigwait; main then waits indefinitely in pthread_join. Wasmoon's outer native trap boundary uses sigsetjmp(..., 1). This predates the recent RC migrations.

The independent condition-variable proof changes the worker mask in 5/5 saved-mask runs and preserves it in 5/5 no-mask controls. A pure C reproducer using async's unchanged signal.c hangs after adding a single trap/nonlocal jump. Instrumented Wasmoon stress reproduced 34 hangs, all JIT; every one stayed blocked for over 23 seconds and exited successfully after a second wakeup signal. See [reproduction and raw evidence](../docs/evidence/darwin-signal-mask-2026-09-30/README.md).

The runtime fix remains outstanding: Darwin trap recovery must restore only the current thread's mask while preserving alternate-stack and nested trap semantics. Do not merely switch the save-mask flag to zero. Original CI did not record stacks, so local reproduction proves this failure mechanism rather than retrospectively observing the original CI process.

## Runtime repair (2026-09-30)

Darwin trap activations now save their caller-thread mask explicitly and use sigsetjmp with mask saving disabled. Ordinary native trap jumps restore only that thread via pthread_sigmask at the landing boundary. Signal handlers redirect the interrupted ucontext to a recovery function on the captured invocation stack, then return normally: the kernel restores the signal mask and alternate-stack bookkeeping before the recovery function jumps to the catcher. Other platforms keep their existing saved-mask jump behavior.

The new native regression failed before the fix and passed after it. It synchronizes with a second thread and covers its independent SIGUSR2 mask, the caller's mask, repeated SA_ONSTACK SIGSEGV recovery, and an inner signal trap followed by an outer native trap. No sleeps or probabilistic timeout assertions are required. Full local validation and CI results are recorded below.

Local strict checks, 39 native C stubs, 2,621 native tests and 75 sanitizer tests pass. Raw validation logs are archived alongside the diagnosis in `fix-validation.json.gz`. Local external acceptance: both core engines pass 258 files / 62,563 assertions each; async-0.3 passes 24 files / 153 commands; full misc including high-memory cases reports 692 passes, 72 script-only entries and no failures/timeouts/deferred entries. The original detailed signal-probe stress harness completes 6,000 runs (2,000 JIT, 2,000 interpreter, 2,000 async-only controls) without a hang. Darwin x86_64 strict C compilation succeeds; local runtime evidence is ARM64. CI is pending.
