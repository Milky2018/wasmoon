## Description
`moon check --target native --warn-list +73` reports 22
`unnecessary_annotation` diagnostics. The existing CI command enables warning 73
but does not make it blocking, so new instances can be merged without failing
the build.

## Design
Remove every warning 73 instance with a semantics-preserving annotation cleanup.
Make warning 73 a CI error with MoonBit's per-warning `@73` configuration.
Do not use global `--deny-warn`: it would also promote the repository's existing
deprecated-API warnings and would expand this focused cleanup into unrelated
migration work.

## Acceptance Criteria
- [x] `moon check --target native --warn-list +73` reports no warning 73.
- [x] CI treats warning 73 as an error.
- [x] Formatting, interface generation, and native tests pass.
