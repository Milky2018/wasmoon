## Description
The current 70-workload cold screen has no failures but retains a randombytes
value gap. Five independent Wasmoon/Wasmtime pairs reproduce a median 1.262
value ratio. CPU samples repeatedly land in table_call_target_impl, not WASI
entropy copying. Machine code decodes dynamic VMContext table fields on every
call even when the context already retains the table owner.

## Design
Use the existing bound owner for live entries and size after the same context,
table-index and 64-bit element-index checks. Keep dynamic ABI-array access for
unbound standalone contexts. Do not cache resolved entries, targets or types;
retain null/type/subtype checks and the current trap codes. Existing owner
bindings retain lifetime; growth and close update the same descriptor. No ABI,
artifact revision, allocation or publication protocol changes.
