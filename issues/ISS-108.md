## Description
`modules/regalloc/README.mbt.md` and blackbox tests currently demonstrate or depend on implementation-level APIs such as `build_live_ranges` and direct mutable field access. This makes internal helpers look public and prevents API visibility from being tightened without noisy test failures.

## Design
Rewrite README examples around the canonical public facade. Convert tests that intentionally exercise internals to whitebox tests and import private names with MoonBit's `for "wbtest"` mechanism. Keep blackbox tests focused on stable user-facing allocation behavior.

## Acceptance Criteria
- [ ] README examples use the canonical public API and pass as `moon check` code blocks.
- [ ] Internal helper tests are whitebox tests instead of requiring root public visibility.
- [ ] Blackbox tests cover stable behavior through the public facade.
- [ ] README tests and `moon test --target native --warn-list +73 --diagnostic-limit=400` pass.
