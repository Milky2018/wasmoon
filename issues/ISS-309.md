## Description
After native fibers are safe, `CoreExecutionEngine` must return native
continuations to the existing Component Async scheduler instead of routing
stackful calls through the interpreter.

## Design
Implement a native `CoreExecutionEngine` adapter that translates fiber yield,
wait, return, cancel, exit, and trap outcomes into the existing typed runtime
outcomes. Preserve instance-entry guards, task ownership, borrow scopes, and
continuation one-shot semantics.

## Acceptance Criteria
- [x] Stackful component calls suspend and resume through native JIT.
- [x] The guest function is not replayed from entry.
- [x] Yield, waitable wait, explicit guest threads, cancellation, and poisoning match the interpreter.
- [x] Multiple component subtasks interleave on one Store.
