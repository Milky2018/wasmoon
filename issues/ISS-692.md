## Description
Current-head regex sampling identifies struct-view admission as the largest
remaining native helper hotspot. Independent counters observe 1,042,931,643view
requests at n=2100, including232,097,087subtype admissions. The existing path
validates the live struct, then calls general ref.test to decode the same object
and retrieve its kind/type again before checking canonical subtype ancestry.

## Design
Reuse the already admitted live object's canonical runtime identity for the
existing immutable registry subtype relation. Keep legacy/abstract/incomplete
identity fallback, exact-object cache, shape/prefix/field/bounds checks, root
verification and physical-borrow contracts unchanged. Do not introduce a new
cache or expand generated guest code. Measure this single change before keeping it.

- [x] Pass relevant public regressions and full native/wasm/strict gates.
- [ ] Pass fresh sanitizers and exact-head platform CI.
