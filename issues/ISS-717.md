## Description
The accepted 1d183b2e tree still takes about 3.23 seconds for the original
ten-call, 10,000-check import-free probe, versus about 0.40 seconds in the
matched official October23 runner. Previous-stage samples cannot establish
the final tree's remaining cost distribution.

## Design
Rebuild the exact final sources and archived downstream ed848ac5 with a frozen
October23 SDK. Preserve the original zero/one/ten-call inputs and assertions.
Separate cold startup from execution sampling, then independently measure
object projections, safepoints, root maintenance and actual collection.
Map sampled generated-code addresses to installed functions before choosing
an optimization. Architectural changes are permitted when the evidence calls
for them; preserve strict ownership, physical-borrow verification, roots,
barriers, traps, reentry, cancellation, cooperation and quota contracts.

## Acceptance Criteria

- [ ] Remove temporary instrumentation and owned experiment outputs.

## Notes
- Fresh three-pair medians reproduce zero/one/ten process times of
  0.853/1.111/3.268 seconds, versus official 0.010/0.057/0.397 seconds.
- Two independent main-thread execution samples attribute 48.93% and 48.86%
  of leaf samples to the existing struct/array projection helpers together.
  Sampling uses a separate 100-call wrapper with the original probe and
  assertions unchanged. These are sampled CPU shares, not a wall-time
  decomposition or an additive speedup budget.

- Original ten-call counters record 392470983 struct projections, 395997591
  array projections, 485779 slow polls/yields, 25 sweeps (24 young), and about
  45.4 million examined root slots. Counts are activity, not time attribution.
- Address-mapped samples identify Decimal left/right shift loops. Existing
  local-struct scalar promotion already removes the private counter boxes;
  allocation removal is not part of this change.
- Guarded loop versions charge every header/inlined poll in its original
  position, retaining the original slow loop and an independent budget proof.
  The final private diagnostic records 123908389/118611971 struct/array
  projections and exactly the original 485779 slow polls/yields.
- The first five-pair prototype improves ten-call wall time by 17.7%; the final
  source requires its own measurements. No universal or pure-guest claim.
- Runtime regressions compare O0/O2 at six quanta while replacing differently
  sized arrays and collecting during suspension. Forcing an insufficient guard
  to succeed trips the unchanged charge assertion; restoring it passes.

- Strict native/Wasm checks with warning 73 denied, native 3221 ordinarily and
  with all three verifiers, full Wasm, C warnings, module boundaries, guest
  bridges and the existing Python script suite pass locally. Exact committed
  sanitizers, integrations and CI remain required.
