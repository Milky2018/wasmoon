# ISS-063: Narrow machv_emit to generic emission artifacts

## Description
`machv_emit` currently owns more than generic machine-code emission. It exposes
entry trampolines, hostcall trampolines, JIT runtime/code-cache management, and
APIs that mention Wasm value types.

Evidence:
- `modules/machv_emit/pkg.generated.mbti` exposes `emit_entry_trampoline`, `emit_hostcall_import_trampoline`, and `JITRuntime`.
- `modules/machv_emit/trampoline.mbt` builds Wasm entry trampoline functions.
- `modules/machv_emit/hostcall_trampoline.mbt` accepts `Array[@types.ValueType]`.
- `modules/machv_emit/runtime.mbt` owns executable-memory and code-cache runtime support.

## Design
Keep `machv_emit` focused on converting MachV functions plus allocation results
into bytes, relocations, stackmaps, and metadata. Move Wasmoon entry/hostcall
trampolines, executable-memory management, and runtime integration into
Wasmoon JIT or Wasmoon-owned packages. Preserve current bytes by moving the
existing code first, then narrowing public APIs.

Non-goal: change code-cache policy or trampoline ABI behavior.

## Acceptance Criteria
- [x] `machv_emit` public APIs do not mention `@wasm_core/types.ValueType`.
- [x] Wasmoon entry and hostcall trampoline generation is owned by Wasmoon JIT or a Wasmoon-owned runtime integration package.
- [x] `JITRuntime` and executable-memory management are no longer exported from generic `machv_emit`.
- [x] `machv_emit` returns generic emission artifacts suitable for Wasmoon JIT to link and install.
- [x] Existing native JIT trampolines and hostcall behavior are preserved.
- [x] `moon info --target native` is run and generated `.mbti` diffs are reviewed.
- [x] `git diff --check` passes.
- [x] `moon check --target native --warn-list +73 --diagnostic-limit=200` passes.
- [x] `moon test --target native --warn-list +73 --diagnostic-limit=200` passes.
- [x] `python3 scripts/run_all_wast.py --rec --dump-failures --timeout-sec 20` passes.
