# ISS-415: Replace fragment-preallocation Fast with instruction-state allocation

## Metadata
- Type: feature
- Status: deferred
- Priority: 2

- Assignee: unassigned

## Description

`AllocatorStrategy::Fast` is structurally independent from bundle allocation,
but it still precomputes live ranges and allocation segments, assigns each CFG
fragment independently, and chooses one value home afterward. A value becomes
spill-homed when any fragment spills or uses a different register. On
multi-block code this creates excessive stack homes, transfers, and emitted
code, erasing the allocator's compile-time advantage.

## Design

Replace the segment-preallocation path with a direct instruction-state
allocator. Keep dense current allocations per virtual register, one owner per
physical register, fixed-size per-class availability sets, deterministic LRU
victim selection, and lazily allocated spill homes. Process operand
constraints and insert moves while walking instructions; do not recover one
global home from independently allocated fragments afterward.

Do not add an adaptive function-size threshold, a preferred-register patch, or
partial range splitting to the current algorithm. Those approaches retain the
incorrect fact producer and make strategy behavior depend on tuning constants.

## Acceptance Criteria
- [ ] Fast allocation no longer builds allocation segments or assigns value
      homes after fragment allocation.
- [ ] Work is bounded by instructions, operands, and the fixed machine-register
      set; no bundle, spillset, or range-index state is constructed.
- [ ] Fixed, tied, clobber, branch, loop, and pressure cases pass the independent
      allocation verifier.
- [ ] On AEGIS128L, Fast emitted size and spill/reload counts stay within 5% of
      Backtracking, and end-to-end wall time does not regress.
- [ ] On the retained 12,993-instruction stress case, Fast total regalloc time
      remains at least 25% below Backtracking.
- [ ] Native warning check, the complete regalloc suite, and the full native
      workspace suite pass.

## Notes
- 2026-08-11: Deferred after measurement showed that local changes cannot meet
  the quality gate. Five interleaved AEGIS128L runs measured Backtracking at
  213,757 us module compile, 79,384 us regalloc, 59,500 bytes, 347 spill slots,
  407 spills, and 1,222 reloads. Current Fast measured 227,490 us module
  compile, 75,810 us regalloc, 80,384 bytes, 1,648 spill slots, 1,365 spills,
  and 3,799 reloads; wall time was about 1.33 s versus 0.98 s.
- 2026-08-11: A temporary stable-register preference reduced Fast to 78,060
  bytes, 1,445 slots, and 3,585 reloads. Adding conflict-point prefix splitting
  reached 77,992 bytes and 3,568 reloads. Both remained far outside the quality
  gate and were discarded rather than committed as heuristics.
