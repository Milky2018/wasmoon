## Description
After context-slot metadata, Wasm-owned lowering, memory facts, and debug/GC relocation are migrated, the old `EmbeddingContextLayout` fixed field schema and `RuntimeContextLayout` compatibility alias should be removed. Keeping them would invite future regressions back into fixed Wasm/Wasmoon runtime-context assumptions.

## Design
Delete fixed runtime-context fields from reusable public APIs and remove `RuntimeContextLayout`. Update Wasmoon JIT to own its concrete VMContext layout and only pass generic slot metadata or explicit pre-lowered instructions into reusable modules.
