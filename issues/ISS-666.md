## Description
Implement the user-approved three-engine research design at baseline c7e407d5.
See [the design and measurement contract](../docs/perf/issue568-three-engine-comparison-2026-10-22.md).

## Design
- Generate safepoint maps from final allocated reference locations, indexed by function/return PC; keep stable-ID words initially.
- Use a proved function-lifetime frame if needed; share enumeration across active, detached reentry and parked stacks before deleting per-call scopes.

## Acceptance Criteria
- [x] Ordinary guest calls no longer copy roots into push/pop scope buffers.
- [x] Actual execution covers direct/indirect/builtin/tail calls, traps, active reentry, detached outer activations, parked resume/cancel and nested transaction exceptions.
- [x] Incomplete discovery forbids reclamation; arena-owned payloads remain edges and transaction journals preserve identity/quota lifetimes.
- [x] Both target code and available native execution plus sanitizer checks pass; unexecuted platforms remain explicitly pending.
