## Description

A fixed short bulk copy and a read from the primary table entered native
runtime helpers on each iteration. The two helpers performed checks that
can be expressed in the same native IR as surrounding loads and stores.

## Design

- Lower 1-, 2-, 4-, 8-, and 16-byte copies within non-shared memory zero.
  Check the current length and both unsigned offsets before reading and
  writing. A whole-source read before the store preserves overlap.
- Read primary-table entries after checking the live published size.
  The same layout used by table.size reflects binding, growth and close.
  Load the stable reference payload without materializing a call target.
- Keep the runtime operations for other copy shapes, non-primary reads,
  and table mutations. Reject cached artifacts from earlier code generation.

## Notes

- The short-copy probe has 300,000 iterations. Four eligible matched pairs
  reduce Wasmoon invocation medians from 1.913 to 0.237 ms. Serial Wasmtime
  takes 0.146 ms. Wasmoon compile time changes from 0.403 to 0.427 ms.
  The median paired invocation reduction is 87.7%. Two memory controls
  stay within the declared regression bound.
- Four eligible pairs on the primary-table read probe reduce invocation
  medians from 6.403 to 2.130 ms. Wasmtime takes 2.476 ms and eager
  TurboFan takes 3.717 ms on that input.
- The mixed table probe drops from 8.525 to 6.417 ms, with 24.9% median
  paired improvement. Its remaining 9.60x ratio to Wasmtime includes
  the checked table write on each iteration.
- The two independently measured variants remove the selected helper
  relocations on AArch64 and x64. The timings are local AArch64 results
  from fresh processes, with overlapping compiler work excluded.

- The combined clean-parent source passes both strict warning targets,
  3,280 native tests in ordinary and verified modes, and 1,536 Wasm
  tests. Its release binaries pass 8,968 assertions in ten targeted
  Core scripts and 1,385 assertions across 59 Component files, with
  no failures or skips in those corpora. The generated 220-assertion
  bulk-copy supplement also passes.

- A single checked table write now stores an already canonical Store
  reference and its type directly. Four eligible pairs on the mixed probe
  reduce invocation medians from 6.362 to 3.500 ms, with a 44.7% median
  paired reduction. Serial Wasmtime takes 0.660 ms. All three table
  controls remain within the declared regression bound. Both native
  targets emit identical guest code before and after the runtime change.
