# ISS-300: Execute callback-driven async steps through native JIT

## Description
Component callback continuations currently use the interpreter even though
each callback step returns to the runtime normally. These calls do not require
a parked native stack and should use ordinary JIT entry and return.

## Design
Teach the component JIT adapter to execute callback-step calls natively while
retaining interpreter fallback only for functions without native code. Preserve
callback status, waitable event delivery, cancellation, and instance-entry
guards.

## Acceptance Criteria
- [x] Initial and resumed callback steps execute through native JIT.
- [x] Callback status and event payloads match the interpreter.
- [x] Tests fail if callback cases silently use the interpreter.
- [x] Current Component Async conformance remains green.
