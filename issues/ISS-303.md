## Description
The Wasmoon-owned async runtime needs real Linux descriptor readiness, timers,
and wakeups without polling loops or threads.

## Design
Implement an internal native adapter using epoll plus appropriate timer and
wakeup file descriptors. Use the same reactor contract and generation-safe
operation identity as the macOS adapter.

## Acceptance Criteria
- [x] Read, write, timer, wake, cancel, and stale-event behavior is tested on Linux.
- [x] No busy polling is used.
- [x] Dropped registrations cannot deliver events to reused operation IDs.
- [x] Native sanitizer coverage passes.

## Close Notes
- Added a Linux backend using epoll one-shot registrations, timerfd timers,
  and an eventfd wakeup source.
- Duplicated each registered descriptor so simultaneous read and write
  registrations retain independent kernel tokens and cancellation lifetimes.
- Removed and closed the duplicate or timer descriptor before delivering an
  event; monotonic tokens and generation-safe runtime operation IDs reject any
  stale readiness left in the kernel queue.
- Verified all four adapter tests on Ubuntu Linux and macOS, ran the Linux and
  macOS ASan/UBSan builds, and compiled both platform branches with
  `-Wall -Wextra -Werror`.
