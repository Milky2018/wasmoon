## Description
Implement `wasi:io/error`, `wasi:io/streams`, and `wasi:io/poll`, including
standard input/output/error stream resources and readiness subscriptions.

## Design
Represent streams and pollables as typed host resources in the shared component
resource table. Reuse the platform readiness backends where their semantics
match, but keep Preview 2 blocking, nonblocking, splice, flush, and error
contracts at the component-host boundary.

## Acceptance Criteria
- [ ] Input/output stream methods implement exact partial-progress and error
      contracts.
- [ ] Pollables compose clocks, files, sockets, and standard streams without
      busy waiting.
- [ ] Standard streams respect inherited, captured, and closed configurations.
- [x] Resource drop closes owned handles exactly once.
- [ ] Component-level stream and poll tests pass on macOS and Linux.
