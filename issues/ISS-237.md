## Description

The production Wasm compiler still converts target code objects into v8 `CompiledEntry` records, losing symbolic relocation and typed metadata structure before installation and serialization.

## Design

Add one Wasmoon-owned producer that converts verified AArch64/x64 target compilation results directly into v9 `artifact.FunctionCode` records and builds a complete compatibility manifest from the validated module, compilation policy, host target, and SHA-256 module identity. Do not route through v8 adapters or negative runtime fixup indices.

## Acceptance Criteria
- [ ] Live AArch64 and x64 compilation retains unlinked bytes, symbolic relocations, sources, traps, safepoints, unwind directives, frame size, entry offset, function identity, and logical signature.
- [ ] The manifest records exact target/OS ABI, CPU requirements, JIT ABI, codegen revision, module identity, and compilation policy.
- [ ] Runtime and internal function targets remain named symbols; no negative fixup identity is produced.
- [ ] Unit tests snapshot complete produced artifacts and verify encode/decode plus live verification parity.
