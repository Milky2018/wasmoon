## Description
Frame planning separately scans every selected instruction for incoming, outgoing,
tail and result areas, stack objects and call presence. Sampling attributes most
flat instruction queries to these repeated walks.

## Design
Compute these related target facts together in one private scan on both backends.
Planning and verification each recompute them from the supplied target function;
never cache or trust earlier validation facts. Preserve every ABI maximum,
stack-object descriptor check, saved register and independent allocation check.

- [x] Preserve independent area maxima with live roots and real direct/tail calls.
- [x] Pass both target checks, full native/wasm and integration gates.
