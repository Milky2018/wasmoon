## Description

ISS-459 completed the authoritative DFG and bounded acyclic optimizer
architecture, but it intentionally migrated only the compact integer rewrite
set. The deleted matcher described 276 rules, while the current direct
dispatcher implements only the core identities, limited reassociation,
conversion folding, simple comparisons, and select folding.

Complete the useful semantic migration without restoring the deleted e-graph,
schema, generator, generic matcher, or saturation loop. The old rules are an
inventory, not a specification: several are insufficiently guarded or can
increase live ranges, so every migrated rule needs a fresh legality and
profitability argument.

## Design

Keep rules as handwritten, root-opcode-specific MoonBit in the existing
acyclic optimizer. Prefer in-place canonicalization or a strictly cheaper
staged candidate. Do not introduce target costs into MilkIR or duplicate rules
owned by target address and instruction selection.

Migrate in evidence-backed groups:

1. Boolean/integer comparison normalization and safe extend/reduce rules.
2. Bitwise, mask, shift, and rotate rules.
3. Select, min/max, and integer absolute-value canonicalization.
4. Vector splat and exact constant rules.
5. Deep reassociation only where use counts and measured allocation pressure
   prove it profitable.

Classify rejected legacy rules explicitly as obsolete, target-owned, unsafe,
or unprofitable. In particular, do not migrate narrowing arithmetic through
extensions without an overflow proof, trapping division/remainder rewrites
without definedness facts, or floating-point identities that relax exact Wasm
semantics.

## Acceptance Criteria
- [x] Every registered legacy name is classified as migrated, obsolete, target-owned, unsafe, or unprofitable, with explicit reasons and no unclassified entries.
- [x] Safe comparison and extend/reduce rules use direct root-opcode dispatch and have exact IR regressions.
- [x] Safe bitwise, mask, shift, and rotate rules have exact IR regressions.
- [x] Safe select and vector rules have exact IR regressions.
- [x] Rebuilding transformations require single-use children and lower cost; the measured representative workloads do not materially regress.
- [x] Strict native validation, warning-73, generated interfaces, formatting, and module-boundary checks pass.
- [x] Optimizer documentation describes the bounded directional aegraph rather than the deleted union-find implementation.

Nine exact IR tests include constant-left normalization, extended booleans, and a shared-extension non-expansion control. A ten-pair alternating cold AEGIS-128L comparison against `93188c08` measured 56,322.5 us versus 55,969.5 us compile medians (+0.63%, within noise) while generated code fell from 58,576 to 58,300 bytes (-276 bytes); all twenty runs exited successfully. Capture: `/tmp/wasmoon-iss461.iCMzmL`.
- 2026-09-03: The legacy extend catalog is not treated as authoritative. In particular, pushing addition through unsigned extension is invalid when the narrow addition overflows, and replacing wide subtraction of unsigned-extended operands with a sign-extended narrow subtraction is invalid for positive differences above the narrow signed maximum. Those rules remain rejected until a range proof can establish legality.
- 2026-09-03: The bitwise/shift batch added complement identities, absorption and nested-idempotence, XOR cancellation, opposite-rotation cancellation, constant-rotation combination, shift-overflow folding, saturating arithmetic-shift combination, and constant shift-pair masks. Nine exact IR tests and four multi-input JIT/interpreter differential tests cover edge values and masked rotation amounts.
- 2026-09-03: The first bitwise/shift implementation repeated definition lookup through small matcher helpers. Ten alternating AEGIS pairs showed no code-size change and a +4.49% compile median, so that implementation was rejected. The retained direct dispatcher resolves each bitwise child once and folds shift-pair matching into the existing nested-shift path. Twenty alternating cold pairs against the comparison-only binary measured 56,401.5 us versus 56,074.5 us (+0.58%, within noise), with identical 58,300-byte generated code and all forty runs successful. Capture: `/tmp/wasmoon-iss461.iCMzmL`.

ISS-461 remains open for the remaining rule-family inventory, select/vector work, and documentation correction.

## Close Notes

Completed on 2026-09-04. The [per-rule ledger](../docs/milkir-rewrite-inventory.md)
accounts for all 276 names from `98921fe7^`: 195 migrated families, 36 obsolete,
35 unprofitable under the existing strict-cost contract, 8 target-owned and 2
unsafe. "Migrated" means the legal, representable, profitable cases; it does
not reinstate missing guards or promise every equivalent expression is selected.
Equal-cost tree balancing and target-specific instruction expansion remain
deliberately excluded rather than labeled implementation progress.

The remaining implementation adds comparison bounds and relations, canonical
select proofs, modular arithmetic cancellation, bitwise factoring, constant
reassociation, typed narrowing, constant count/rotate folding, lane-aware
vector splats, and precise float simplification. Rules remain handwritten and
directly dispatched. No new module, opcode language, matcher or saturation
loop was introduced. The old unlowerable min/max/abs/spaceship nodes were not
recreated. Scalar min/max bound proofs operate on existing compare/select IR.

Legality corrections include explicit lane widths (the old splat folder always
used 64-bit lanes), actual-width sign extraction, guarded narrowing of wide
shift counts, normalized i32 constant facts, float ties-to-even/signed-zero
handling, payload-preserving float sign operations, and f32 arithmetic folding
at f32 precision. Unsafe wide arithmetic through zero extension remains intact.

Verification:

- `VCODE_REGALLOC_VALIDATION=1 moon test --target native`: **2,250/2,250 passed**.
- Nine migration test groups include optimized IR/constant assertions,
  independent before/after straight-line evaluation at both integer widths,
  300 comparison-condition/bitwise combinations, and rejection controls for
  shared or mismatched-lane splats.
- Eight JIT/interpreter differential test groups cover extensions, arithmetic,
  compare/select, shifts/rotates, narrowing, vector wrapping and float bit
  semantics (four groups were added by this completion batch).
- `moon fmt`, `moon info`, `moon check --target native --warn-list +73`,
  `python3 scripts/audit_module_boundaries.py`, and `git diff --check` passed.
  No generated public interface changed.

`3568315000` and `3593725000` on successive runs).

seconds before a candidate run was attempted. No comparative result or
regression conclusion is recorded for it. This completion did not run a full

[MilkIR optimizer](../docs/milkir-optimizer.md); historical comparison reports
now link to it instead of serving as current implementation documentation.
