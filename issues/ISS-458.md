## Description
The production O2 optimizer still translates bounded pure-expression regions
from MilkIR into a separate `EGraph`, saturates and extracts that graph, then
elaborates the selected expressions back into MilkIR before streaming GVN can
number the rewritten instructions. This duplicates instruction vocabulary and
ownership, makes optimization cost depend on representation conversion, and
prevents rewriting and value numbering from sharing one canonical value graph.

## Design
Make MilkIR instructions and values the authoritative optimization graph. Walk
the dominator tree once, number available expressions as they are encountered,
and apply bounded acyclic rewrites directly to canonical value definitions.
New alternatives must be ordinary unplaced MilkIR instructions and are placed
only when selected. Keep matching indexed by root opcode and preserve explicit
legality checks and work budgets. Delete the production region conversion,
union-find saturation, extraction, and duplicate opcode translation after the
replacement covers the existing observable optimizer behavior.

This is an architectural correction, not a benchmark-specific fast path. Do
not add size-based semantic switches, cache results across functions, weaken
verification, or retain two production optimizers.

## Acceptance Criteria
- [x] Production optimization uses MilkIR `Value` and `Inst` definitions as its canonical graph and does not build `EGraphRegionTable` or copied `ENode` regions.
- [x] Pure rewrites and GVN execute in one dominator-order traversal with dominance-safe scoped availability.
- [x] Rewrite dispatch is indexed by root opcode, bounded, deterministic, and preserves the existing legality boundary.
- [x] Obsolete production e-graph conversion, extraction, elaboration, and duplicate opcode translation code is removed rather than layered underneath the replacement.
- [x] Focused optimizer tests preserve identity, constant, strength-reduction, cross-block GVN, memory-version, deep-chain, and large-function behavior.
- [x] AEGIS-128L preserves runtime behavior and does not regress generated code, register-allocation pressure, or cold compile time.
- [x] Formatting, generated interfaces, warning-73 checking, module-boundary validation, and strict native tests pass.

## Close Notes
MilkIR is now the optimizer's only expression graph. O2 applies deterministic,
acyclic local rewrites and available-expression numbering during one iterative
dominator traversal. Memory analysis retains its explicit 300-source-
instruction budget, while pure rewrite helpers do not consume that budget.
The standalone e-graph module, duplicate opcode language, regional conversion,
saturation, extraction, and elaboration paths were deleted.
