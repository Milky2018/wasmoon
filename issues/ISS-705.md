## Description
The new published-0.18.0 embedding control executes the retained 1,000-case
parse_double property zero, one or ten times after one module startup. Every
probe must return one. Cancellation and cooperative execution remain enabled.
Reported incremental observations retain an approximately 23.9x gap against
official moonrun; these are not isolated generated-code timings or PR582 data.

## Design
Retain the exact zero/one/ten-call artifacts and downstream contracts. Compare
release and current Wasmoon under matched settings, then independently vary
cancellation and cooperation to attribute their cost. Separate startup,
compilation, invocation, GC, polling and downstream driving. Include the new
distributed Core workloads alongside the earlier pinned property and linear
memory corpus; preserve every guest assertion and upstream platform contract.

## Acceptance Criteria
- [ ] Verify original hashes and repeat zero/one/ten-call successful controls.
- [ ] Establish release/current comparisons with matched execution settings.
- [ ] Attribute a remaining cost with profiles and single-variable controls.
- [ ] Protect any retained optimization with semantic regressions and controls.
- [ ] Report phase/memory tradeoffs and independent engine boundaries explicitly.
- [ ] Pass relevant correctness, strict, sanitizer and cross-platform gates.
- [ ] Clean owned temporary workspaces; do not commit raw profiles or logs.
