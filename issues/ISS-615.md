## Description
Even functions without safepoints triggered a dense per-context native descriptor
table. Repeated artifact instantiation also rebuilt immutable stack-map payloads.
Keep portable artifact verification independent of native storage; prepare an
RC-owned immutable native owner at the native facade and retain it from contexts.

## Acceptance Criteria
- [x] Empty metadata does not allocate a descriptor table; existing entries clear correctly.
- [x] Instances share descriptor identity and retain payloads after the creating owner is released.
- [x] Compatibility rebinding detaches a private table without changing parked frames in another instance.
- [x] Native, external and sanitizer regressions pass.
- [x] Record before/after allocation accounting and isolated performance evidence.

## Close Notes
Completed locally with 2,630 native tests, both-engine core/misc and P1
capabilities, Component suites, and 79 sanitizer tests. [Evidence and accounting](../docs/evidence/shared-safepoints-2026-09-30/README.md)
include shared-owner overhead, identical artifact hashes, and independent A/A
controls. This is a storage/ownership optimization, not a demonstrated speedup;
a small positive AEGIS timing difference remains tracked in ISS-604. The native
facade now exposes the portable installer input through LoadedArtifact::verified.
No remote CI or cross-platform execution is claimed.
