## Description
Implement the stable Preview 2 filesystem types and preopens interfaces,
including descriptor resources, metadata, directory iteration, path
operations, and stream conversion.

## Design
Use capability-rooted descriptors. Resolve guest paths beneath configured
preopens without ambient host filesystem access or symlink escape. Descriptor
rights and open modes must be checked before native operations.

## Acceptance Criteria
- [x] All stable Preview 2 filesystem functions have exact signatures.
- [x] Preopen traversal cannot escape configured roots through `..` or symlinks.
- [x] Rights, open modes, timestamps, metadata, and directory streams follow
      component contracts.
- [x] Descriptor and stream resources share ownership without double close.
- [x] Component filesystem conformance and adversarial path tests pass.

## Notes
- 2026-07-27: Started after the shared stream/poll/resource lifecycle seam was
  completed in ISS-274. The implementation will use capability-rooted native
  descriptors for synchronous Preview 2 calls; the public async library is
  reserved for Preview 3 operations and the async CLI execution seam.
- 2026-07-27: Registered every generated Preview 2 filesystem method and
  preopen contract. Native path mutation now resolves a stable parent
  descriptor and verifies its inode ancestry beneath the capability root;
  final symlink following is validated before destructive open flags take
  effect.
- 2026-07-27: Descriptor streams use explicit `pread`/`pwrite` positions rather
  than the shared offset of `dup`, owned descriptors and streams close once,
  and contexts provide idempotent cleanup for embedding-owned preopen roots.
  Focused tests cover reads, independent stream offsets, `..`, and an
  intermediate symlink to `/etc`.
- 2026-07-27: The remaining acceptance item requires the CLI component-host
  execution seam from ISS-278 so the pinned upstream component filesystem
  corpus can execute end to end.
- 2026-07-27: Added a command component which imports
  `wasi:filesystem/preopens@0.2.11` and exercises the canonical ABI for
  `list<tuple<own<descriptor>, string>>`. This exposed and fixed missing
  indirect list-result lowering. The component now runs with an explicit
  preopen, while focused path tests continue to cover parent traversal and
  symlink escape.
