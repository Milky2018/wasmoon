## Description
Implement the stable Preview 2 filesystem types and preopens interfaces,
including descriptor resources, metadata, directory iteration, path
operations, and stream conversion.

## Design
Use capability-rooted descriptors. Resolve guest paths beneath configured
preopens without ambient host filesystem access or symlink escape. Descriptor
rights and open modes must be checked before native operations.

## Acceptance Criteria
- [ ] All stable Preview 2 filesystem functions have exact signatures.
- [ ] Preopen traversal cannot escape configured roots through `..` or symlinks.
- [ ] Rights, open modes, timestamps, metadata, and directory streams follow
      component contracts.
- [ ] Descriptor and stream resources share ownership without double close.
- [ ] Component filesystem conformance and adversarial path tests pass.
