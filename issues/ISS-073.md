## Description
After moving the legacy Wasm-to-MilkIR translator out of `wasmoon_jit/ir`,
`modules/wasmoon/wasm_frontend/ir` still exposes implementation details as
public API. The package currently re-exports many MilkIR types/functions and
publishes low-level `Translator` and `FuncEnvironment` constructors/methods.

That is technical debt because callers can couple to the frontend's internal
translation state instead of depending on a small Wasm frontend entry point plus
the real reusable MilkIR API.

Evidence:
- `pkg.generated.mbti` exposes MilkIR aliases such as `Function`, `IRBuilder`,
  `Opcode`, `OptLevel`, `optimize_with_level`, and `instruction_count`.
- `pkg.generated.mbti` exposes `Translator::Translator`, `Translator::from_module`,
  and `Translator::translate`.
- `pkg.generated.mbti` exposes `FuncEnvironment` memory/global/table helper
  methods even though they are translator internals.
- The production CLI compile path calls `@ir.Translator::Translator` directly because
  no narrow body-translation facade exists.

## Design
Keep Wasm-to-MilkIR translation behavior unchanged. Add a narrow public
frontend function for translating one decoded Wasm function body with explicit
module metadata and embedding layout. Move the CLI compile path to that
function. Callers that need MilkIR optimization, validation, or statistics
should import `Milky2018/milkir` directly.

Then make low-level translator/environment methods private and remove the
MilkIR re-export facade from `wasm_frontend/ir`.

Non-goal: change MilkIR, lowering, register allocation, emission, or JIT
correctness behavior.

## Acceptance Criteria
- [x] Production code no longer calls `@ir.Translator::Translator`,
  `@ir.Translator::from_module`, or `@ir.Translator::translate`.
- [x] Production code uses direct `@milkir` APIs for optimization/statistics
  instead of MilkIR re-exports from `wasm_frontend/ir`.
- [x] `modules/wasmoon/wasm_frontend/ir/pkg.generated.mbti` no longer exposes
  MilkIR type/function re-exports.
- [x] `pkg.generated.mbti` no longer exposes `FuncEnvironment` helper methods.
- [x] `pkg.generated.mbti` no longer exposes low-level `Translator` methods.
- [x] The remaining public Wasm frontend IR API is an intentional translation
  facade, not the translator's mutable implementation state.
- [x] Public `.mbti` diffs are reviewed with `moon info --target native`.
- [x] `git diff --check` passes.
- [x] `moon check --target native --warn-list +73 --diagnostic-limit=200`
  passes.
- [x] `moon test --target native --warn-list +73 --diagnostic-limit=200`
  passes.
- [x] WAST correctness gate passes for the native host.
