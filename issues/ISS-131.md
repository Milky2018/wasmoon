## Description
The Wasmoon JIT test producers construct a `Function` from a non-empty signature and then treat the first N calls to `new_value()` as undeclared implicit parameters. That protocol is incompatible with explicit `Function.params` and prevents removal of the lowering compatibility fallback.

## Design
Migrate each signature-based producer to canonical construction and explicit parameter lookup. Preserve instruction and block construction otherwise; do not rewrite tests to a different builder abstraction. Confirm that every non-empty signature producer uses the materialized parameter values rather than allocating replacements.

## Acceptance Criteria
- [x] All non-empty signature producers use canonical construction.
- [x] No producer relies on the first N calls to `new_value()` being function parameters.
- [x] Wasmoon JIT focused tests remain green.
- [x] The migration introduces no unrelated test or formatting churn.
