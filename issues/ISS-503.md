## Close Notes

The Linux CI artifacts reproduce both errors against unmodified upstream P1 programs. Zero-length readlink now uses a one-byte native scratch buffer to validate the link without writing guest bytes. Failed symlink creation preserves EEXIST for directories and normalizes a trailing-slash regular file to ENOTDIR. Public API regressions include missing paths, ordinary files, unchanged output buffers, and all five upstream destination cases. Native tests: 2373 passed. Linux revalidation is pending.

CI run 34345576882 confirms the interpreter fixes on Linux, while the independent JIT C implementation still failed the same two programs; macOS completed successfully. The follow-up factors both syscalls into `wasmoon_jit/jit_ffi/wasi_path_portability.h`, used by both engines, and preserves errno before freeing JIT path buffers. A guest-import regression checks zero and nonzero readlink buffers, missing and ordinary paths, untouched output on error, and all five symlink destinations with explicit expected values for each engine. Linux revalidation remains required.
