## Description
The pinned Core parse_double property passes but spends substantially more CPU
in native Wasmoon than Wasmtime. Preserve the original guest, assertions and
scheduling policy when measuring; do not confuse throughput with correctness.

## Design
- Share checked compact/wide field access between native host and JIT helpers.
  Fixed-width memcpy permits scalar loads/stores without alignment assumptions.
  Keep reference barriers, verification, tombstone checks and existing C symbols.
- Resolve active/fallback trap state through one TLS slot. Preserve activation
  push/pop, parking, reentrancy and foreign-context ownership.
- Add a Wasm-owned, context-validated GC read-forwarding pass before generic
  optimization at O2/O3. Forward struct fields and immutable array lengths only
  within extended basic blocks. Invalidate all potentially aliasing fields on
  writes, and all facts at calls, allocations, merges and loop headers.
- Apply it to CLI, Component compilation, preflight and exploration; keep the
  language-neutral MilkIR optimizer independent of Wasm. Bump codegen revision
  so existing caches cannot silently reuse pre-optimization artifacts.
- Retain the pinned property as a repeatable cold-cache comparison against
  Wasmtime with parallel compilation disabled. Remove all scratch artifacts.
- Promote nonescaping entry-created integer struct fields into SSA while
  retaining allocation failures and quota admission. Keep escaping, packed,
  reference and non-entry objects on the ordinary heap path.
- Inline bounded exact-module integer callees without calls, polls or memory
  effects; retain callsite locations and revisit GC reads after promotion.
- Keep scalar write widths distinct so Clang cannot reintroduce a runtime
  memcpy. Invalidate older artifacts with codegen revision 13.
- Pass a mutable explicit heap field to scalar native helpers. Fuse array
  bounds checking and element access around one identity/header resolution.
  Retain actual physical descriptors and old helper wrappers; codegen 14
  invalidates older argument contracts.
- Reject static layout hints without a concrete reference proof. Cover the
  raw entry boundary where an actual compact byte array can reach an entry
  declared with a word-array parameter, plus wide objects and two heaps.
