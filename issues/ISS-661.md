## Description
The pinned Core parse_double property remains slower than optimized V8 despite
completed GC access, root transport and allocation improvements. Correctness
and CI acceptance do not satisfy the outstanding performance targets.

## Design
Retain checked memory SSA, conservative effects/borrow verification, shared
Store identities, precise function frames and bounded allocation fast paths.
Measure compiler preparation separately from guest invocation before further
changes. Preserve assertions, quota/failure behavior, raw-entry admission,
barriers, reentry and rollback. See the compact
[contracts and measurement summary](../docs/perf/parse-double-gc.md).
