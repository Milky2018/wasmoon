## Description
Linux AMD64 CI fails the mixed HTTP/native timer guest at its client.send result check in callback function 18. The same failure exists at merged main `145348b2`. The guest's unconditional error-path unreachable hides the HTTP error category. The test peer also closes after headers without necessarily consuming the empty chunked request body.

## Design
Retain guest files, process output, peer stages and received bytes as CI artifacts. Enable opt-in HTTP command debug diagnostics to expose the original exception and the host result before canonical lowering. Consume the fixture's complete empty chunked body before responding and closing. Continue diagnosis from real Linux CI evidence if the failure remains.

## Acceptance Criteria
- [ ] Failed HTTP commands preserve enough evidence to distinguish host transport errors from result-delivery errors.
- [ ] The successful timer/HTTP fixture consumes the complete request without arbitrary sleeps or weakened success assertions.
- [ ] Linux CI passes both-engine HTTP acceptance and subsequent corpus gates.
- [ ] Record the established root cause or clearly bound what remains unproven.

## Notes
- Original debug/release fixtures passed repeatedly in an emulated Linux AMD64 environment; this is not reproduction on a native GitHub runner. Independent TCP tests confirmed the reset risk of closing unread requests, but not its attribution to the CI failure.
- Added opt-in `component --run --http --debug` client diagnostics and persistent `target/http-results` guest/process/peer evidence, uploaded even on CI failures. The peer now reads the fixture's exact empty chunked body before returning its response. Two socket-based regressions cover body bytes coalesced with headers and premature EOF.
- Local macOS ARM64 acceptance passed the full HTTP script on both engines, all 2620 native tests, strict warnings and the module-boundary audit. This does not establish the native Linux CI cause; inspect the new head's evidence before attributing the old failure to peer closure.
