## Description
Implement guest continuation creation, binding, suspension, resumption, exception injection and stack switching with delimited handlers and explicit Store ownership. Preserve suspension composition with the existing cooperative scheduler.

## Acceptance Criteria
- [x] Every unmodified typed-continuation script executes through the interpreter with correct values and traps.
- [x] Consumed aliases cannot resume or cancel a newer owner; imported tags retain Store identity.
- [x] Store close and terminal paths release parked continuations and their roots.

## Close Notes
- Added Store-owned one-shot continuation bodies and explicit delivery of values or exceptions. Creation, binding, nested resumption, suspension forwarding and switch handlers execute through the interpreter's existing captured-control-flow mechanism.
- Consumed handles are never reused. Cancellation checks ownership before releasing a body, so a stale alias cannot cancel a newer owner. Terminal return, trap and Store close release captured state and GC leases.
- Guest continuation creation inherits cancellation, host suspension, asynchronous host drivers and cooperative scheduling. Embedding APIs distinguish unhandled guest suspension from traps and host waits.
- All 45 unmodified stack-switching scripts pass in the interpreter (`tmp/iss518-all-misc/summary.json`). The additional pinned GC-storage assertion also passes: used GC storage containing continuation references is an explicit engine build restriction; unused types and independent GC usage remain valid. Portable validation still accepts that valid WebAssembly module.
- Added public regressions for stale aliases, terminal release, suspension/trap/exception separation, and GC locals retained while parked then reclaimed after completion, with both MoonBit and native GC heaps.

All existing external core/component/P1/runtime gates pass. Misc now reports 647 pass, 72 successfully executed assertion-free scripts, and 45 failures confined to native typed continuations.
