## Description
The previously corrected trap-on-reenter script still assumes a yielded parent callback prevents a child from calling the parent. The pinned Wasmtime 50 oracle instead executes the callee and traps at its unreachable instruction. Audit ancestry checks against active execution and synchronous wait ownership; retain real reentry protection.

## Acceptance Criteria
- [ ] Positive yielded-parent and negative active-parent controls agree with the pinned oracle.
- [ ] Runtime entry checks follow actual execution locks without removing poisoning or sync-wait protection.
- [ ] The reviewed fixture correction and component suites pass on both engines.
