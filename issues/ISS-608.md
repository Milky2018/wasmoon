## Description
Safepoint blobs and offsets already originate in MoonBit but are copied into C allocations. The legacy GC function-address snapshot also has a separate malloc/free contract. Move these payloads to MoonBit RC while keeping native descriptor addresses stable for active GC frames.

## Design
Bind Bytes and FixedArray payloads through JITContext. Retain incoming arrays before releasing replaced arrays, including aliasing rebinding. Raw C setters copy into managed arrays to preserve their existing copy contract. Native function-pointer conversion remains a C FFI operation; the resulting Int64 snapshot is RC-managed and does not own executable code. Stable descriptor storage remains native.

## Acceptance Criteria
