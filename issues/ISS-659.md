## Description
Keep native internal function frames unwindable and consume every captured
owned guest frame rather than only the trapping PC and one saved return address.

## Acceptance Criteria
- [x] Reproduce missing non-tail callers and recursive guard-page frames.
- [x] Establish AArch64 FP/LR records before remaining frame allocation probes.
- [x] Keep x64 RBP setup for internal leaves and preserve target unwind metadata.
- [x] Bound capture by the activation's usable stack, independent of DWARF owner.
- [x] Preserve recursive repeats and normalize caller return-PC range lookup.
- [x] Cover host/cooperative suspension, nested modules and owned post-close data.

## Close Notes
- Internal AArch64 functions use a separate 16-byte FP/LR header; ordinary frame
  allocation, argument staging, tail cleanup and local offsets remain separate.
  x64 internal leaves retain the existing RBP setup. Platform ABI policy remains.
- Frame walking validates both words against usable stack bounds; the old extra
  16-KiB exclusion and process-global debugger-range termination are removed.
  Capture remains bounded by the existing 32 native records. Reports are owned,
  module-scoped, preserve recursive repeats and never read freed fiber memory.
- Five actual native regressions cover O0/O2 calls, leaves, independent debugger
  owners, guard-page recursion/context reuse, async/cooperative resumption and
  nested modules. Two target tests assert internal leaf unwind records on both
  architectures. Reviewed byte/unwind snapshots reflect the required headers.
- Final native2892/2892 with GC/register-allocation verification, wasm1352/1352,
  strict both/info/fmt, boundaries and MSVC bridges pass locally. Fresh release
  JIT Core258/258 files and62563 assertions pass without failures/errors.
- Fresh isolated macOS ASan/UBSan241/241 and both controls pass with final dirty
  functional sources based on1392df43. Local LSan is unavailable. This is local
  ARM64 execution plus cross-target structural validation, not x64 execution or
  clean CI acceptance. No publication, version change or merge occurred.
