## Description
The `wasmoon run` path parses a core module and immediately instantiates it, while the standalone compile API validates first. Invalid modules can therefore reach interpreter or JIT runtime assumptions through the main CLI path.

## Design
Introduce one command-package validation seam that formats contextual validator errors consistently. Call it for the main module and preloaded modules before instantiation. Add focused tests that prove an invalid decoded module is rejected and a valid module remains accepted.

## Acceptance Criteria
- [x] Main and preloaded core modules are validated before instantiation.
- [x] Validation failures are reported with the existing contextual validator formatting.
- [x] A focused regression test rejects an invalid module before runtime execution.
- [x] Command-package tests and native typechecking pass.
