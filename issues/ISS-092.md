# ISS-092: Make FunctionBuilder construction failures explicit

## Description
The old `IRBuilder` API allowed some invalid construction states to fail
silently. For example, emitting an instruction without a current block could
create and return a `Value` without inserting the corresponding instruction
into any block. External users could accidentally build malformed functions and
only see the problem later during verification or lowering.

For a reusable compiler IR, builder misuse should be caught at the builder seam
with clear diagnostics.

## Design
Replace `IRBuilder` with a Cranelift-style `FunctionBuilder`: create blocks,
`switch_to_block`, emit instructions directly on the builder, and `finalize`
the function. Builder operations that require a current block must fail
immediately instead of silently no-oping or creating orphan values.

Do not redesign SSA construction wholesale in this issue.

## Acceptance Criteria
- [x] `IRBuilder` is removed from the public MilkIR API; `FunctionBuilder` is the builder entry point.
- [x] Emitting instructions without a current block cannot silently create orphan values.
- [x] Builder misuse has a clear error mode documented in README or API docs.
- [x] Existing valid builder examples remain concise.
- [x] Tests cover at least one missing-current-block misuse case.
- [x] `moon check --target native --warn-list +73 --diagnostic-limit=200` and `moon test -p Milky2018/milkir --target native --warn-list +73 --diagnostic-limit=200` pass.

## Close Notes
Closed by replacing MilkIR's `IRBuilder` public API with `FunctionBuilder`, keeping the Cranelift-style `create_block` / `switch_to_block` flow while emitting instructions directly on the builder. Instruction and terminator emission now require a current block before allocating result values, so missing insertion position fails immediately instead of creating orphan SSA values. Added `finalize`, block-parameter helpers, seal protocol hooks, README documentation, and a panic test for missing-current-block misuse. Validation passed: `moon check --target native --warn-list +73 --diagnostic-limit=200`; `moon test -p Milky2018/milkir --target native --warn-list +73 --diagnostic-limit=200`; `moon test modules/milkir/README.mbt.md --target native --warn-list +73 --diagnostic-limit=200`; `moon test --target native --warn-list +73 --diagnostic-limit=200`; `python3 scripts/audit_module_boundaries.py`.
