## Description
After guarded poll regions, Decimal left/right shifts still account for about
35% of main-thread execution samples on the original import-free probe. Compare
the same functions in Wasmoon, official-version V8, and Wasmtime before choosing
the next compiler/runtime change.

## Design
Pin the clean 5b699ce8 parent, original module bytes and frozen October23 SDK.
Match actual installed Wasmoon code, V8 Liftoff/TurboFan tiers and Wasmtime
Cranelift code by function identity. Separate diagnostic instrumentation from
retained timings. Test one causal change at a time; retain every sample and all
trap, root, barrier, ownership, cancellation, fuel and cooperation contracts.
