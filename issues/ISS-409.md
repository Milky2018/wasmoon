## Description

The allocator contains bridge coalescing, deferred-home state, edge-target
register bias, edge-affinity preference propagation, and loop-entry split
hoisting. These mechanisms patch over missing range and spill semantics and
add scans and mutable states to the hot allocation loop.

## Design

Delete those heuristics and their dedicated state. Retain ordinary operand
preferences, fixed-register constraints, spill weights, and correctness moves.
If a named mechanism turns out to carry correctness rather than preference,
reduce it to the smallest correctness mechanism and document the distinction.

## Acceptance Criteria
- [x] No bridge-coalescing or deferred-home state remains.
- [x] Edge affinity and loop-entry split-position heuristics are removed.
- [x] Regalloc tests and native warning check pass.
- [x] The public interface is unchanged.

and edge-target register state, loop-entry split hoisting, and the special
three-to-four-fragment eviction-weight rule. The allocator no longer mutates
finished bundles to retrofit edge behavior. Net production and focused-test
code shrank by roughly 800 lines.
