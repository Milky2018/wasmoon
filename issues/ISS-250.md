# ISS-250: Register GC metadata before executable artifact commit

## Metadata
- Type: bug
- Status: closed

- Updated: 2026-07-23

## Description

`JitCodeInstaller::install` finalizes RX mappings before `JITModule` registers per-function GC safepoints. A registration failure raises after executable commit and relies on eventual GC instead of explicit transaction ordering.

## Design

Register verified artifact safepoint metadata into the unpublished JIT context before invoking the executable installer. Add an internal injectable registrar seam solely for deterministic white-box ordering and rollback tests; do not widen the public API.

## Acceptance Criteria
- [x] A safepoint registration failure occurs before executable allocation or RX transition.
- [x] The failure returns `FunctionMetadataRegistrationFailed` and leaves the executable mapping count unchanged.
- [x] Successful load still publishes function addresses only after installation and metadata registration succeed.
- [x] Existing installer rollback tests remain green.
