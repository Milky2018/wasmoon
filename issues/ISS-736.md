## Description

The original SDK flate whitebox closure accessor repeatedly enters the
generic reference cast and subtype helpers for a concrete type match.

## Design

Read the canonical identity from the current heap identity page. Admit the
fast path only after checking the reference encoding, live identity range,
page, current canonical registry and current module-local type index.
Return the original reference on an exact match. Use the existing helper for
nulls, abstract targets, legacy metadata, subtypes and other misses.
Keep field projections and their address-epoch checks independent.
