## Description

The original SIMD lane probe builds a vector from a scalar and a constant,
performs a vector addition, and then observes only one integer lane. The
native backends still emit the splat, vector arithmetic and extraction.

## Design

Use the existing acyclic optimizer and its cost model to project demanded
I32 and I64 lanes of splats and little-endian vector constants. Replace
eligible single-use vector arithmetic with the same width of wrapping
integer arithmetic. Keep shared arithmetic, mixed lane widths, narrow
extensions, memory, floating-point and relaxed mask behavior intact.

## Acceptance Criteria

- [x] Recompile the original SIMD probe for AArch64 and x64 and verify that
  all three vector operations disappear.
- [x] Match four cold rounds with serial Wasmtime and eager V8. Keep
  the original relaxed SIMD, memory SIMD and scalar inputs as controls.
- [x] Verify lane ordering, integer overflow, shared vector uses and
  relaxed and mixed masks in the release JIT.
- [ ] Verify the final platform run.

## Notes

- In the exact 7e16 parent comparison, original SIMD invocation changes
  from 1.918 to 1.038 ms, a 45.90% paired median reduction across four
  cold rounds. Serial Wasmtime 49.0.1 and eager Node TurboFan invoke it
  in 1.009 and 1.741 ms. The paired Wasmoon compile median falls 1.42%.
- The original hotspot changes from 96 to 60 bytes on AArch64 and from
  115 to 83 bytes on x64. The relaxed and memory SIMD code objects
  match their parent bytes on both targets.
- A separate combined trial also rewrote uniform relaxed SIMD masks. Its
  relaxed execution gain fell below the predeclared threshold, so the
  delivered source excludes that rule.

- Local native tests pass 3,284 in each verification mode and Wasm
  tests pass 1,537. All 258 Core WAST files and 62,563 assertions pass
  in each of interpreter and JIT modes. All three selected Component
