## Description
Suspendable JIT execution needs a fixed-address native stack and a machine
context that can yield to the host executor and later resume at the original
hostcall return point.

## Design
Implement single-threaded stackful fibers for macOS AArch64 and SysV AMD64.
Save all ABI callee-preserved integer and floating-point state, retain guard
pages, and use a fiber-owned entry frame. Do not support cross-thread resume.

## Acceptance Criteria
- [x] Start, repeated yield/resume, return, cancel, and guard protection are tested.
- [x] Callee-preserved integer and floating-point registers survive suspension.
- [x] Two fibers interleave without state corruption.
- [x] A fiber cannot be resumed or cancelled twice.
