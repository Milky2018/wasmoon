## Description
Replace implicit scratch reuse in `machv/vcode` with a resolved move plan that
models saving and restoring one transfer scratch through an abstract emergency
spill location.

## Design
Split move resolution into cycle linearization and stack-to-stack legalization.
The legalizer tracks whether the transfer scratch is free, holds a cycle value,
or has parked that value in emergency storage. Add a symbolic interpreter that
checks the sequential plan against the original parallel assignment.

## Acceptance Criteria
- [ ] A stack-slot swap is expressed with one transfer scratch plus emergency save and restore steps.
- [ ] Register-only cycles and acyclic stack transfers do not request emergency storage.
- [ ] Resolved plans contain no stack-to-stack transfer.
- [ ] Symbolic tests cover integer, FP/vector, mixed-location, and multi-node cycles.
- [ ] The committed Lane-derived whitebox regression passes.
