# ISS-085: Move table and context-pointer lowering behind wasm_isa_lower

## Metadata
- Type: task
- Status: open
- Priority: 0
- Labels: isa_target, wasm_isa_lower, reusable-infra, abstraction-leak, agent
- Assignee: Codex
- Created: 2026-07-07
- Updated: 2026-07-07
- External ref: none

## Description
`isa_target/lower` still owns helper state and APIs for function-table and table0-base lowering. Even after Wasm ExtOp dispatch moved to `wasm_isa_lower`, the generic lowerer still exposes table-shaped caches and emits context loads using fixed runtime-context fields.

## Design
Move table0/function-table context load helpers and caches into `wasm_isa_lower`, or replace them with generic context-slot helper APIs that do not carry table-specific names. Preserve the existing generated instruction shape by mechanically moving the current implementation.

## Acceptance Criteria
- [ ] `isa_target/lower` no longer exposes `emit_load_table0_base`, function-table caches, table0 caches, or table-specific invalidation APIs.
- [ ] Wasm call/ref lowering in `wasm_isa_lower` still emits the same logical context loads through generic context-slot APIs or local Wasm-owned helpers.
- [ ] Reusable `isa_target` public API no longer contains table0/function-table wording except in documentation explaining boundaries.
- [ ] Native tests and rebuilt WAST gates pass.
