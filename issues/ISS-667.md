## Description
Implement the user-approved three-engine research design at baseline c7e407d5.

## Design
- Emit scalar header/payload initialization after one shared no-GC C reservation, with a cold precise-root slow path. Preserve the interpreter Store heap and atomic quota contract instead of duplicating admission in generated code.
- Add generic constant-divisor legalization, redundant-trap/address simplification and bounded cost-based inlining; remove superseded narrow workarounds.
- Do not erase observable allocation accounting merely because private fields become SSA.

## Acceptance Criteria
- [x] Known constant division retains exact signed rounding and required zero/-1 overflow traps; both target code paths are covered.
- [x] Fast allocation retains object/byte quotas, failure injection, identity mapping and subsequent reuse behavior.
- [x] Measure the dependent compiler implementation and independent budget counterfactual against the exact guest without weakening checks/assertions; include compile/code-size/RSS costs and do not claim isolated additive speedups.
- [x] Native/wasm and broader corpus validation pass.
