# ISS-337: Make the release symbol gate pipefail-safe

## Description
The release archive gate pipes `nm` into `grep -q`. Under the `pipefail`
setting used by GitHub Actions, an early match makes `grep` exit while `nm` is
still writing. `nm` then exits with SIGPIPE status 141, the complete pipeline
is considered false, and the gate fails to reject the forbidden symbol.

## Design
Let `grep` consume the complete `nm` output and redirect only its output to
`/dev/null`. Preserve the existing match and failure message without adding
temporary files or platform-specific shell state.
