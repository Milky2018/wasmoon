## Description
Function root frames still enter and leave through generic helpers on every
invocation. Preserve the exact root protocol while removing common-path calls
through an embedding-owned current-invocation admission contract.

## Design
See [checked object views and native root links](../docs/perf/object-root-fastpaths.md).
Keep definition stores, precise masks, stack ownership, active-context fallback,
chain-head traps, parking, reentry, exceptions and cancellation unchanged.

## Acceptance Criteria
- [x] Keep a call-free admitted path and both checked helper fallbacks.
- [x] Preserve the source-body entry after the optional native prologue.
- [x] Disabling the opt-in fails the code-path regression; restoration passes.
- [x] Measure independent original hot modules and complete-suite candidates.
- [ ] Pass final strict checks, full tests, integrations and sanitizers.
- [ ] Record exact-head platform acceptance and clean owned scratch files.
