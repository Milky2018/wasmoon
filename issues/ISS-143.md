## Description
Vector instructions are stored under VectorOp, but the flat V128 Opcode surface and inverse conversion tables remain public.

## Design
Migrate builders, the Wasm frontend, verifier, printer, and MachV lowering to direct VectorOp construction and exhaustive matching, then delete all flat V128 Opcode variants and compatibility mappings.

## Acceptance Criteria
- [ ] Opcode contains no flat V128 variants.
- [ ] All vector producers construct VectorOp directly.
- [ ] Verifier, printer, effect analysis, and lowering dispatch directly on VectorOp.
- [ ] No vector compatibility conversion helper remains.
- [ ] SIMD frontend and JIT/interpreter differential tests pass.
