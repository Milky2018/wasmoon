## Description
All four native CI platforms reject two modules in Wasmtime's
`gc/ref-test.wast`, causing four failed commands. The frontend encodes legal
`RefNone` as its invalid `-100` marker instead of the existing `none` heap-type
ID `-8`. Strict contextual validation correctly rejects the malformed IR.
Explicit nullable `ref.test`/`ref.cast` forms have the same omission because
heap type identity and instruction nullability are encoded separately.

## Design
Encode `RefNone` with `NullRef` as heap type `none`, preserving the separate
nullability flag. Keep contextual rejection of unknown heap types intact.
Cover public interpreter/JIT behavior at O0/O2/O3, including legal nullable
casts and trapping non-null casts; rerun the original upstream case and suite.
