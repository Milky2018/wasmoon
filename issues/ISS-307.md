# ISS-307: Preserve hostcall suspension and trap activations

## Description
`wasmoon_jit_hostcall` currently turns every nonzero callback status into a
`siglongjmp`, destroying the active Wasm frames. Trap state is also held in
thread-local singletons whose entry frames may have already returned when a
continuation resumes.

## Design
Introduce a typed internal suspension status. Let the MoonBit callback return
fully before yielding the native fiber. Keep `sigsetjmp`, trap metadata, and
active stack bounds in the fiber activation, with TLS pointing only to the
currently running activation.

## Acceptance Criteria
- [ ] Suspension preserves the instruction after the hostcall without replay.
- [ ] Trap after resume reports the correct function and source location.
- [ ] Nested activations do not overwrite each other's trap state.
- [ ] No MoonBit callback frame remains parked on a native fiber stack.
