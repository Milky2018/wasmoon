## Close Notes

Closed on 2026-10-08 as covered by ISS-614's existing repair, `de537e14`.
Fresh release builds of the original `8d950c08` source with async 0.21.2
reproduce the unchanged original fixture's shutdown deadlock: one uninstrumented
and two instrumented processes remain blocked past 120 seconds. Samples place
main in `pthread_join` and the signal worker in `sigwait`. Signal traces show
the worker mask overwritten by the caller's mask and the shutdown SIGUSR2
consumed by the ordinary handler. An additional diagnostic wakeup lets all
three exit zero with both WAST assertions passing.

Backporting only the existing three-file trap repair to the original source
passes 10,000 instrumented JIT repetitions. Original interpreter controls pass
10,000; current JIT passes 10,000 plain and 10,000 instrumented repetitions.
The current deterministic native trap regression and the unchanged misc
fixture through the standard runner both pass. No production code, timeout or
test expectation changed. This closes the local reproduction/evidence gap;
the historical CI process itself still has no captured stack.

See [full method, raw evidence and limitations](../docs/evidence/iss567-original-fixture-2026-10-08/README.md).
