# ISS-308: Trace precise roots on suspended native fibers

## Description
A parked native fiber can be the only owner of live Wasm GC references.
Current GC metadata describes active safepoints but does not register every
parked stack and saved register context as an updateable root set.

## Design
Record the exact suspension return PC and stack map, expose saved register and
stack slots as mutable root locations, and register parked fibers with the
Store heap. Add continuation-safepoint metadata only if existing call-site
metadata cannot identify the required locations precisely.

## Acceptance Criteria
- [x] A reference held only by a parked fiber survives collection.
- [x] Moving collection updates suspended register and stack roots.
- [x] Multiple parked fibers are scanned independently.
- [x] Return and cancel unregister every root exactly once.
- [x] Native continuation is not enabled for GC code until this gate passes.

## Notes
- 2026-07-28: Initial issue.
- 2026-07-28: Claimed by `codex`. The current JIT ABI already materializes
  every live GC reference into a heap-owned caller-root scope before a
  suspending hostcall. The collector uses stable encoded handles while compacting
  object storage through the object table, so it must enumerate parked
  activations but does not need to rewrite saved machine registers. Tests will
  cover object movement through compaction and the continuation lifecycle.

## Close Notes
- Implemented Store-heap-owned registration of precise caller-root scopes for
  detached native JIT activations, including continuations parked in different
  JIT contexts that share the heap. Registration allocation failure rejects
  the suspension instead of parking an untracked root set.
- Resume, return, cancellation, and finalization remove the registration before
  restoring or destroying activation state. Multiple registrations use
  independent intrusive-list nodes.
- The collector's compact phase moves object storage and updates its object
  table; encoded reference handles in saved registers and stack slots remain
  stable by design. The regression test forces that movement and reads the
  rooted object after resume.
- Validation: `moon fmt`, `moon info`, `moon check`,
  `moon test -p Milky2018/wasmoon_jit` (156/156), and
  `moon test -p Milky2018/wasmoon/testsuite` (521/521). `moon check` reports
  only 16 pre-existing hash deprecation warnings. The changed C sources also
  pass strict Clang syntax checks for both `arm64-apple-macos14` and
  `x86_64-apple-macos14`.
