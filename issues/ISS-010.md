## Description
Create `modules/machv_emit` as the reusable emitter that lowers MachV into machine-code bytes and generic metadata records.

## Design
The emitter should output code bytes, generic relocations, stack maps, debug metadata, and fixup records. It must not resolve Wasmoon runtime helpers, import `jit_ffi`, allocate executable memory, know VMContext layout, or encode `.cwasm` semantics. Keep a single `machv_emit` package with ISA-specific internals rather than splitting `x64_emit` and `aarch64_emit` in the first stage.

## Acceptance Criteria
- [ ] `machv_emit` emits supported MachV functions into object-like records.
- [ ] Runtime helper references are represented as generic external-symbol relocations or metadata.
- [ ] `machv_emit` does not import `wasmoon_jit`, `jit_ffi`, `wasm_core`, or `wasmoon`.
- [ ] Existing machine-code emission tests are ported or adapted to the generic output model.
- [ ] Known incomplete emitter features include scoped `TODO(machv_emit)` comments.
