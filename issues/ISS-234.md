## Description

The v8 decoder uses an unbounded mutable model and a single string error. The final artifact seam must treat every file as untrusted, enforce resource limits without aborting, validate compatibility, and reconstruct verified code objects.

## Design

Implement the new breaking Cwasm codec over ISS-233 data. Decode through checked arithmetic and configured limits, reject v8 and every older version, validate the complete manifest, rebuild each ordinary `UnlinkedCodeObject`, and invoke its verifier before returning a loadable artifact.

## Acceptance Criteria
- [x] Valid artifacts round-trip every manifest and code-object field exactly.
- [x] Old versions, malformed sections, unknown tags, truncation, overflow, excessive counts/sizes, and inconsistent ranges return structured decode errors.
- [x] Compatibility mismatches return structured `ArtifactIncompatible`; cache callers can distinguish them from malformed artifacts.
- [x] Every decoded code object passes the target-owned verifier before the loader succeeds.
- [x] Fuzz-style truncation and resource-limit matrices cover every variable-length section.

## Notes
- 2026-07-22: The current v8 `ByteReader` performs unchecked reads and the model admits `Unknown` target architecture.
- 2026-07-22: MoonBit `Int` is 32-bit on the native backend. The decoder
  therefore assembles wire `u32` values as `UInt` and rejects values above
  `Int::max` before conversion; it never allows a large unsigned count or
  offset to wrap negative.

## Close Notes

- 2026-07-22: Added the v9 UTF-8 codec, structured encode/decode errors, and
  configurable pre-allocation limits for every variable-length section.
  Exhaustive proper-prefix truncation, old-version, bad-magic, unknown-tag,
  invalid-UTF-8, trailing-byte, unsigned-overflow, invalid-entry, and limit
  matrices pass.
- 2026-07-22: Added the root `load_artifact` seam. It checks exact target,
  JIT ABI, codegen, module, and compilation-policy identity; permits only a
  host CPU-feature superset; validates stable code/external/data symbols; and
  reconstructs every function through `code_object.build`. `ArtifactLoadError`
  preserves decode, incompatibility, and code-object failure classes without
  linking or executable-memory allocation.
