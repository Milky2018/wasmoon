## Description

The v8 decoder uses an unbounded mutable model and a single string error. The final artifact seam must treat every file as untrusted, enforce resource limits without aborting, validate compatibility, and reconstruct verified code objects.

## Design

Implement the new breaking Cwasm codec over ISS-233 data. Decode through checked arithmetic and configured limits, reject v8 and every older version, validate the complete manifest, rebuild each ordinary `UnlinkedCodeObject`, and invoke its verifier before returning a loadable artifact.

## Acceptance Criteria
- [ ] Valid artifacts round-trip every manifest and code-object field exactly.
- [ ] Old versions, malformed sections, unknown tags, truncation, overflow, excessive counts/sizes, and inconsistent ranges return structured decode errors.
- [ ] Compatibility mismatches return structured `ArtifactIncompatible`; cache callers can distinguish them from malformed artifacts.
- [ ] Every decoded code object passes the target-owned verifier before the loader succeeds.
- [ ] Fuzz-style truncation and resource-limit matrices cover every variable-length section.
