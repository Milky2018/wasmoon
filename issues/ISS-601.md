## Description
Every native context copies the Store-wide type parent graph and callable entry map. Publishing new identities refreshes all contexts and recopies instance-local metadata as well. Share the Store data through a managed native owner while retaining per-instance local type and tag mappings.

## Design
Use one RC-managed native registry per Store, with no back-reference to contexts or the Store. Update its arrays transactionally. Contexts retain the registry; rebinding and teardown release it. Preserve the existing standalone context setter by constructing a private registry. Avoid registering per-instance refresh closures on the normal JIT path. This is a Store-ownership improvement, not completion of module-shaped VMContext layout.
