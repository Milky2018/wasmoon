# ISS-127: Preserve reference widths during MilkIR-to-MachV lowering

## Description
MilkIR permits word-level bitwise operations and equality comparisons on pointer and reference carrier types, whose machine representation is 64 bits. MilkIR-to-MachV lowering currently selects 64-bit `Band`, `Bor`, and `Bxor` instructions only when the result type is exactly `I64`, and selects 64-bit `Icmp` only for `I64`, `CallableRef`, and `OpaqueRef`. Consequently valid `Ref` and `Ptr` operations may be lowered as 32-bit instructions and silently truncate pointer high bits. The production native frontend emits `Bor(Ref, Ref) -> Ref` while constructing non-null function references.

## Design
Define one package-local representation-width predicate in MilkIR-to-MachV lowering and use it consistently wherever word operations choose 32-bit versus 64-bit MachV instructions. Lock down the real lowering seam with regression tests over reference and pointer carrier types. Do not change MilkIR's public type model or weaken verifier contracts.

## Acceptance Criteria
- [x] `Band`, `Bor`, and `Bxor` lower `Ptr`, `Ref`, `CallableRef`, and `OpaqueRef` values as 64-bit MachV operations.
- [x] Equality comparisons lower `Ptr`, `Ref`, `CallableRef`, and `OpaqueRef` operands as 64-bit MachV comparisons.
- [x] A regression test covers the production `Bor(Ref, Ref) -> Ref` shape and pointer/reference comparisons.
- [x] Native, wasm-gc, and register-allocation validation gates remain green.
