## Description
The platform CI matrix does not run the repository's Python unit tests or
`audit_component_security.py`. Regressions in these tools and in the component
security invariants therefore do not block a pull request even though both
checks pass locally.

## Design
Add both commands to the existing source-quality step shared by the Linux AMD64
and macOS ARM64 matrix entries. Do not create another job or duplicate the
workflow structure.

## Acceptance Criteria
- [x] CI runs all `scripts/tests/test_*.py` tests.
- [x] CI runs `scripts/audit_component_security.py`.
- [x] Either command failing fails the platform job.
- [x] Both commands and workflow validation pass locally.
