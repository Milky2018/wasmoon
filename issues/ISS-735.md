## Description

AArch64 currently emits an exclusive-load/store retry loop for every
atomic read-modify-write. Hosts with Large System Extensions can perform
a sequentially consistent atomic add in one instruction.

## Design

Select LDADDAL for the seven integer add forms in eligible shared-memory
modules. Record the host requirement in the artifact and its cache key.
Use the existing retry loop on hosts without a confirmed capability.
Keep the original operand, alignment, bounds and trap contracts.

## Notes

- On the measured arm64 macOS host, median invocation falls from
  1.982 to 1.091 ms. The paired median reduction is 44.93%. The
  compatible V8 reference takes 1.051 ms.
- The product's cached atomic function shrinks from 96 to 84 bytes.
  MVP and multi-memory function records are byte-identical. An initial
  multi-memory timing variance was investigated using 18 balanced
  three-arm rounds with the same parent binary as a placebo.
- The manifest test caught selection on normalized rather than encoded
  atomic subopcodes. The selector uses the original Wasm subopcode.
