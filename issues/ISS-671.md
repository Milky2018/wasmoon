## Description
The previous numerical V8 targets were explicitly superseded on 2026-10-24.
Continue measuring the same pinned asserted property, but evaluate improvements
across broader workloads with separate execution, compilation and RSS evidence.
Retain cold caches, serial compilation, assertions, roots and runtime contracts.

## Design
Measure current invocation and compiler phases first. Rank and independently
control repeated checked-view admission, root/allocation boundary work and
repeated compiler analysis. Implement measured changes with failing semantic
or work-count regressions, both target selection and full platform-appropriate
local gates. Keep reusable modules product-neutral and preserve raw-entry,
legacy layout, reentry, alias, GC and rollback safety.

- [x] Implement evidence-backed compilation improvements with bounded-work regressions.

- [x] Pass full native/wasm, strict, corpus and sanitizer gates; state platform limits.
