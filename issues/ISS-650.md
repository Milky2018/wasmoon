## Description
The typed continuation consumer historically mapped fiber resource failure (-5)
to a backend trap. PR #545 already corrected that mapping and closes consumed
resources before reporting exhaustion. Preserve that implementation and guard
the missing parked-resume integration path.

## Acceptance Criteria
- [x] Repeated denied resumes retain resource error classification.
- [x] A denial before consumption preserves a usable handle; a consumed handle stays consumed.
- [x] Reclamation releases parked ownership and quota; fresh calls remain usable.
- [ ] Windows CI executes thread conversion denial through typed guest resume.
