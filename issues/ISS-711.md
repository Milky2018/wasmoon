## Description
Fresh current-head compiler profiles still show adapter emission thunks and
reference-count/allocation work. Generated C allocates both a captured closure
and an eager fallback Array for every wrapped emit, including successful calls.
The wrapped DirectBuilder construction APIs are already statically non-raising;
actual construction errors are retained for the existing finish boundary.

## Design
Call the non-raising builder API directly throughout InstructionContext and
remove the unused generic attempt helper. Keep result completion/error records,
call metadata, roots, control flow and final builder/target validation. This
simplifies the semantic adapter and removes success-path temporary allocations
without changing any API, generated guest code or artifact revision.
