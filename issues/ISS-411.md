## Description

Edge transfer construction currently loops over every value for every CFG
edge, then repeatedly scans per-value segments to rediscover live-out and
live-in facts. This creates an avoidable `edges * values` phase.

## Design

Derive per-edge live-through values while liveness and per-block segments are
already available. Consume those sparse facts directly when emitting edge
transfers. Preserve block-argument transfers and parallel-move correctness.

## Acceptance Criteria
- [ ] Edge transfer construction contains no loop over all function values.
- [ ] Each edge visits only its arguments and sparse live-through values.
- [ ] Diamond, loop, critical-edge, and unrelated-dead-value tests pass.
- [ ] Native warning check passes and phase evidence is recorded.
