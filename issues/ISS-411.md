# ISS-411: Build edge transfers from live edge facts

## Description

Edge transfer construction currently loops over every value for every CFG
edge, then repeatedly scans per-value segments to rediscover live-out and
live-in facts. This creates an avoidable `edges * values` phase.

## Design

The allocator gives every value one stable home across all of its segments.
Consequently, a live-through value has identical source and destination homes
and requires no edge transfer. Emit transfers only for SSA block arguments,
whose value identity and home can differ across the edge.

## Acceptance Criteria
- [x] Edge transfer construction contains no loop over all function values.
- [x] Each edge visits only its block arguments; stable-home live-through
      values require no transfers.
- [x] Diamond, loop, critical-edge, and unrelated-dead-value tests pass.
- [x] Native warning check passes and phase evidence is recorded.
