## Description

Make verified semantic MachV the sole production result of MilkIR and Wasm lowering. Use the private semantic-to-legacy adapter only to preserve the downstream backend temporarily, and delete the old direct MilkIR-to-union lowering in the same milestone.

## Design

- Implement target-neutral `milkir_machv` and `wasm_machv` producers.
- Compare the new semantic route with the old route only in tests or diagnostics.
- Keep the semantic-to-legacy adapter private to migration internals and absent from generated interfaces.
- Cut production over atomically; do not retain a fallback or supported backend selector.

## Acceptance Criteria

- [ ] MilkIR and Wasm producers construct verified semantic MachV with matching signatures, CFG edges and arguments, operations, effects, traps, calls, and safepoints.
- [ ] A test-only normalization harness compares the old and new semantic behavior across representative and regression inputs.
- [ ] Production JIT compilation consumes semantic MachV and reaches the legacy backend only through the private adapter.
- [ ] The old direct MilkIR-to-union lowering and all of its production entry points are deleted in the cutover.
- [ ] Existing JIT/interpreter differential tests and WAST suites show no new failures.
- [ ] No public API, generated interface, README, or reusable package exposes the adapter or a dual-backend option.
- [ ] The common ISS-192 quality gates pass.
