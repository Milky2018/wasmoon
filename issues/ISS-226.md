## Description

Adopt the shared call-transfer planner in AMD64 and remove its independent call argument shuffle.

## Design

Keep SysV layout, frame alignment, scratch selection, and machine encoding in the AMD64 adapter. Reuse the same normalized transfer and verification contracts as AArch64.

## Acceptance Criteria
- [x] All AMD64 call families use the shared planner.
- [x] Register and stack argument mixtures, indirect callees, tail calls, and FP/SIMD banks are covered.
- [x] AMD64 target, allocation, emission, WAST, and WASI tests pass.
- [x] No target-specific call ordering logic is duplicated from AArch64.
