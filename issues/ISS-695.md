# ISS-695: Preserve vector values in data-segment array operations

## Description
A valid v128 array.new_data module returns1 in Wasmtime49 after wasm-tools
validation. On ac02661, Wasmoon JIT traps unreachable and the interpreter raises
TypeMismatch. The JIT type cache omits vector byte width, native decoding only
returns one64-bit word, and interpreter byte sizing/decoding omit vectors.

## Design
Add the existing16-byte value representation to data-segment sizing and decoding
in both engines. Preserve source/destination bounds, dropped-segment and null
trap ordering, canonical/legacy layouts, allocation admission and high-word bits.
Keep any later bulk-copy performance change independently reviewable.
