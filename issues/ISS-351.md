# ISS-351: Parse public interface owner references in the component audit

## Description
The Component Model interface-isolation audit scans fixed alias substrings and
two package directories. An implementation owner imported under another alias
or exposed from another adapter package can bypass the gate, while an unrelated
owner whose alias merely starts with a forbidden spelling can be rejected.
Consequently the gate does not analyze the owner of types in generated public
signatures.

## Design
Parse generated `.mbti` import entries into alias-to-owner mappings, then
resolve aliases referenced by the public interface declarations. Compare full
package owners with configured, segment-aware implementation owner roots.
Scan generated package interfaces for new implementation-boundary exposure,
with a small explicit allowlist for reviewed low-level native and WASI seams.

## Acceptance Criteria
- [x] An aliased nested implementation owner in the stable interface is
  rejected.
- [x] A similarly prefixed but unrelated owner is accepted.
- [x] Merely importing an implementation owner without exposing it is accepted.
- [x] A generic adapter exposing an implementation owner from another package
  is rejected.
- [x] The current generated interfaces, Python suite, and security audit pass.

## Close Notes

Replaced fixed alias substring checks with generated-interface owner analysis.
The audit parses the import table, resolves aliases used outside that table,
and compares complete owners with implementation roots at package-segment
boundaries. It fails closed on unresolved public aliases.

The adapter gate now discovers every generated interface under the configured
scan root and rejects unreviewed implementation-owner exposure. Only the
existing native session and WASI host low-level interfaces are explicitly
reviewed in the manifest.

Verification passed with the four focused regression cases, 57/57 Python
tests, the live component security audit, Python bytecode compilation,
`moon check --target native`, and `git diff --check`.
