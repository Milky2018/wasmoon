## Description
Shared memory64/custom-page backing can move on growth. Interpreter and JIT duplicate unsynchronized growth, and JIT memory-zero bounds may read stale context lengths after another owner grows the descriptor. Reserve stable shared backing, serialize descriptor growth, and load shared bounds from the authoritative descriptor.

## Acceptance Criteria
- [x] Shared backing remains stable across growth, including custom logical pages and memory64.
- [x] Concurrent growth returns distinct previous sizes and preserves zero initialization.
- [x] Both engines observe growth by an independent native worker.
- [x] Native, sanitizer and external regressions pass without changing upstream inputs.

## Close Notes
- Shared memory64 and custom-page memories reserve their maximum backing range; growth changes accessibility without moving addresses. Logical page lengths remain exact even when smaller than an OS page.
- Both growth entry points now use one descriptor implementation and serialize shared growth. Shared JIT bounds and bulk operations read the descriptor length; guard metadata is atomic.
- Independent native growth regression covers interpreter/JIT, memory32/memory64 and standard/custom pages (eight combinations). Summed old sizes detect lost growth; a final worker-only growth exposes stale JIT bounds. Restoring only the context-length fast path fails with an out-of-bounds trap; the corrected implementation passes normally and under ASan.
- The external `memory-combos.wast` exposed signed truncation of the declared maximum `0xffffffff`; the allocation FFI now widens explicit u32 maxima separately from the absent-maximum sentinel. Both engines pass the unmodified script again.
- Advanced the codegen revision to `direct-vcode-2` so persistent caches cannot reuse pre-atomic/pre-shared-growth machine code. Updated the cache regression to reject the previous revision.
- Final native suite: 2,370 passed. Warning-73, formatting, interfaces and module boundaries passed. Core WAST: 258 files / 62,563 assertions per engine; P1 explicit-rights and all four component suites passed. ASan passed all growth combinations.
- Full misc (`tmp/iss496-verified-misc/summary.json`): 558 pass, 68 script-only, 112 fail, 10 unsupported, 16 deferred; every verdict matches ISS-495. This sweep precedes only the cache revision metadata change, which has its own passing native cache regressions.
