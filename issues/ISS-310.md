## Description
Green component tests do not prove native async execution because the current
adapter may silently route suspendable functions to the interpreter.

## Design
Record typed execution evidence and make the Preview 3 JIT matrix require
native callback and native stackful cases. Keep the interpreter matrix as a
separate semantic oracle. Do not use string stage names or output parsing.

## Acceptance Criteria
- [x] JIT conformance fails when required calls fall back to the interpreter.
- [x] Stable 0.2, async 0.3, and future-gated suites pass in both modes.
- [x] Preview 3 CLI workloads exercise clocks, stdio, filesystem, and sockets.
- [x] The exact official snapshot commit is recorded in evidence.
