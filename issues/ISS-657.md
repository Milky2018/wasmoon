## Description
Decode the standard optional function-name subsection, preserve it in binary
roundtrips, and prefer debug names for JIT diagnostics.

## Acceptance Criteria
- [x] Decode names with imported function index offsets and unknown subsections.
- [x] Ignore malformed nonsemantic payloads without suppressing resource limits.
- [x] Encode deterministic in-range names, including long Unicode strings.
- [x] Use debug names, then export names, then stable index fallbacks.
- [x] Preserve semantic validation and the existing text renderer contract.
