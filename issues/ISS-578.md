## Description
Public native array APIs must validate their extents. The JIT retains obsolete Preview 1 guest entry points despite routing both engines through the portable host. Partial allocation failures can leave invalid preopen state. Native stubs are excluded from the existing sanitizer instrumentation.

## Design
Keep public API compatibility through checked MoonBit wrappers over private externs. Remove bypassed guest implementations and their registries/bridges while preserving context APIs. Make context initialization failure-safe. Separate native host responsibilities with explicit private interfaces, without splitting shared JIT ABI state mechanically. Extend declarative native validation rather than intercepting compiler commands.

## Acceptance Criteria
- [x] Invalid buffer extents and undersized outputs are rejected before native calls, with public API regressions.
- [x] Obsolete WASI guest implementations and bridge declarations are removed.
- [x] Partial preopen allocation failure leaves safely destructible state.
- [x] Handwritten native code has explicit warning and sanitizer coverage with a native positive control.
- [ ] Strict native checks, full tests, package installation, and cross-platform CI validate the changes.
