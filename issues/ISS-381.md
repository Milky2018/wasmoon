# ISS-381: Make e-graph rebuild incremental and retire the fixpoint trap API

## Description
`EGraph::rebuild` (`modules/milkir/egraph/egraph.mbt:803`) restores
invariants by reconstructing the hashcons, opcode index, use-def edges,
type map, and remat set **from scratch for the whole graph**, looping the
full pass until congruence produces no new unions. Three compounding costs:

1. Every rebuild is O(total nodes) times its fixpoint rounds; egg-style
   incremental repair (a worklist of classes dirtied by unions) exists
   precisely to avoid this.
2. Node deduplication in both `merge` and `rebuild` is a linear scan
   (`for existing in nodes { if existing == canonical_node ... }`), i.e.
   O(|class|²) per class, even though `ENode` derives `Hash`. Today this is
   masked by `eclass_enode_limit = 5` — a throttle covering for a data
   structure choice.
3. `EGraph::rewrite_to_fixpoint` (`egraph.mbt:648`) is a `pub` API whose
   budget is `2 × (classes + nodes)` iterations with a full rebuild after
   every changed iteration — quadratic and worse. Nothing calls it; its own
   doc comment says to prefer `saturate_indexed(ruleset, 1)`. It exists
   only to invite misuse.

The production path (`EGraphBuilder::optimize`, single saturation pass) is
currently acceptable because it triggers at most one rebuild per function;
this issue is about removing the trap and the masked quadratic before
anything raises the iteration count.

## Design
- Replace full-graph rebuild with worklist repair keyed by the classes
  touched since the last rebuild (egg's algorithm), or at minimum bound the
  rebuild to dirtied classes plus their parents via the use-def index.
- Use a hash-based set for intra-class node deduplication.
- Delete `rewrite_to_fixpoint` (no callers) or demote it to a test-only
  helper with an explicit small budget.

## Acceptance Criteria
- [ ] Rebuild work is proportional to touched classes, demonstrated by a
      counter or benchmark on a graph where one merge occurs in a large
      e-graph.
- [ ] Node dedup no longer performs linear scans.
- [ ] `rewrite_to_fixpoint` is gone from the public interface (`.mbti`
      diff) or clearly test-scoped.
- [ ] Full e-graph and optimizer suites plus the JIT/interp comparison
      corpus stay green.
