## Description
The interpreter and MilkIR frontend normalize atomic subopcodes for dispatch, but select RMW operations and widths using the original subopcode. Existing small-value tests miss incorrect updates and truncation.

- [x] Verify all RMW operations and widths, including successful and unsuccessful compare-exchange, against Wasmtime.
- [x] Both engines produce the expected old value and full memory contents.
- [x] Native checks and existing external passing cases remain green.
