# ISS-206: Establish the complete WASIp1 rights model and lookup boundary

## Metadata

- Status: closed

- Assignee: codex

- Updated: 2026-07-20
- External ref: none

## Description
Wasmoon stores descriptor rights but has no common operation boundary that checks them. Its rights constants also stop at bit 28, omitting Preview1 `SOCK_ACCEPT`, and `path_open` silently masks unknown bits instead of rejecting malformed rights.

## Design
Define the complete Preview1 rights bitset and add small backend-local helpers that validate a descriptor and require base rights before a host operation. Keep the interpreter and JIT descriptor stores authoritative; do not introduce a third shadow table or a flat schema that cannot express contextual rules.

## Acceptance Criteria
- [x] Interpreter and JIT define Preview1 rights bits 0 through 29, including `SOCK_ACCEPT`.
- [x] Unknown rights bits are rejected rather than silently discarded.
- [x] Interpreter and JIT expose one internal base-rights check at their descriptor lookup boundary.
- [x] Focused tests cover valid bit 29, unknown bits, missing descriptors, and missing rights.
- [x] Targeted MoonBit and native JIT tests pass.
