# ISS-486: Enforce stream handle ownership without numeric guessing

## Description
The stream.read adapter searches all component instances for a readable endpoint with the same numeric handle when the current instance has no such endpoint, then transfers that endpoint implicitly. Numeric handles are local to their owning component; this workaround can bypass canonical ownership transfer. Reproduce with an integer passed between components, remove guessing, and fix any real transfer path that depended on it.

## Acceptance Criteria
- [ ] An independent cross-component invalid-handle regression traps in Wasmoon and Wasmtime.
- [ ] Stream lookup uses the current instance only; legitimate transfers use the canonical ownership path.
- [ ] Existing component and misc corpora pass without new skips or fixture changes.
