## Description
`modules/wasmoon/runtime/store.mbt` initializes a `MarkSweepHeap` inside `Store::with_c_heap` with a `Keep for fallback` comment. The comment is ambiguous because it can imply an interpreter fallback path in JIT mode. The actual structure has both a MoonBit heap field and an optional C heap; the comment should describe state ownership precisely.

## Design
Reword the comment only. Prefer wording such as `used when C heap is disabled` or `kept for interpreter-owned GC operations`, depending on the surrounding code. Do not change heap initialization or GC behavior.

## Acceptance Criteria
- [ ] `Store::with_c_heap` no longer contains the ambiguous `Keep for fallback` wording.
- [ ] The replacement comment accurately describes why the `heap` field still exists when `c_heap` is enabled.
- [ ] No behavior changes are included.
- [ ] `git diff --check` passes.
