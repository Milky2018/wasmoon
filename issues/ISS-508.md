## Description
WastContext owns a Store, WASI context and compiled modules but run_wast_commands does not close them. Investigate ownership of replaced and unnamed JIT modules and pending calls before implementing ordered cleanup.

## Acceptance Criteria
- [ ] Prove native ownership is released after repeated successful and failing scripts.
- [ ] Retain compiled code until all imported calls and continuations have ended; cancel pending work before releasing native owners.
