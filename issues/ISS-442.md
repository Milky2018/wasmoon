## Description

Semantic MachV accessors such as `Function::blocks`, `block_instructions`,
`instruction_operands`, and `instruction_results` return copied arrays or newly
constructed handles. Target analysis repeatedly calls these accessors while
making several whole-function passes. AArch64 then walks the function again to
create target blocks and again in CFG order to lower instructions.

The final ISS-441 captures put AEGIS-128L target lowering at an 18,887 us
median: 5,529 us for AArch64 analysis and 12,506 us for target VCode
construction. The cost scales almost perfectly with surviving IR instruction
count, which points to repeated traversal and materialization rather than fixed
ISA setup.

## Design

Add a narrow indexed traversal surface to semantic MachV: stable instruction
slots, counts, and checked `*_at` queries that do not copy collections.
Preserve the snapshot semantics of existing public APIs for external callers.

Refactor both target selectors to create blocks and collect raw definitions,
uses, constants, and stable instruction slots in one canonical scan. Later
selection steps should iterate those dense indexed facts when their data
dependencies require ordering, instead of rescanning semantic MachV through
snapshot APIs. Target VCode remains the register-allocation and emission IR,
but its construction must consume the same indexed selection plan rather than
rediscovering the function shape.

Do not remove semantic MachV or fuse product-owned Wasmoon policy into a target
module as part of this issue.

## Acceptance Criteria
- [ ] Production AArch64 and x64 target lowering does not allocate copied block, instruction, operand, or result arrays merely to traverse semantic MachV.
- [ ] The public snapshot APIs retain their current ownership and validation behavior.
- [ ] Target analysis performs one canonical IR fact-collection scan; dependent selection passes use indexed facts rather than repeated snapshot traversal.
- [ ] Target VCode, relocation records, metadata, and generated code are unchanged for AEGIS-128L and focused target-lowering fixtures.
- [ ] Across at least seven cache-isolated AEGIS-128L captures, median target-lowering time falls by at least 20 percent from the 18,887 us ISS-441 baseline without shifting equivalent work into another stage.
- [ ] AArch64, x64, MachV, strict allocation-validation, formatting, warning-73, generated-interface, and module-boundary gates pass.
