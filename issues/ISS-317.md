# ISS-317: Accept native fiber hostcall frames

## Metadata

## Description
The JIT hostcall bridge validates argument and result slots only against the
module's ordinary Wasm stack. Stackful Component Async calls execute on a
guarded native fiber stack, so valid generated hostcalls are rejected as
invalid pointers and become an `unreachable` trap.

## Design
When a module has stack bounds configured, accept hostcall slots from either
that ordinary Wasm stack or the currently active native fiber's usable stack.
Keep overflow-safe bounds checks and continue rejecting every other pointer.

## Acceptance Criteria
- [x] Generated hostcalls on an active native fiber pass slot validation.
- [x] Slots outside both valid stack regions still trap.
- [x] Ordinary JIT hostcalls and native continuation tests remain passing.
- [x] The official async JIT suite no longer fails at the first fiber hostcall.
