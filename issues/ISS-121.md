## Description
Introduce the first complete safe loop-unrolling slice for canonical single-body I32 loops with an exactly known small trip count. Unsupported loop shapes must remain unchanged.

## Design
Add a private loop-unroll module that separates analysis from mutation. Recognize a unique preheader, header, body, latch, and exit; prove an I32 induction variable's initial value, bound, step, predicate, and trip count; clone instructions with fresh value and instruction IDs; and fully unroll only within a strict code-growth budget.

## Acceptance Criteria
- [ ] Canonical pure I32 loops with trip counts from zero through the configured bound are analyzed exactly.
- [ ] Full unrolling uses fresh value and instruction IDs and rewrites dependent operands.
- [ ] Reversed predicates, dynamic bounds, multi-latch loops, early exits, and unsafe arithmetic are skipped without mutation.
- [ ] Transformed functions pass the strengthened verifier.
- [ ] Focused analysis and transformation tests pass on native and wasm-gc.
