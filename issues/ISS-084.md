# ISS-084: Introduce generic context-slot metadata for lowering and emission

## Description
`machv/abi.EmbeddingContextLayout` currently exposes concrete runtime fields. Reusable modules need a generic way to name context-derived offsets and their invariants without knowing whether a slot is a Wasm function table, table base, globals pointer, or GC state.

## Design
Add generic context-slot metadata in `machv/abi`, including slot id, offset, mutability/invariance facts, and optional cache role. Keep old fields only temporarily while migrating dependent code. Wasmoon JIT should build the slot metadata from its concrete `VMContextLayout`.

## Acceptance Criteria
- [x] A reusable context-slot representation exists in `machv/abi`.
- [x] `wasmoon_jit` can translate `VMContextLayout` into the generic slot metadata.
- [x] New APIs make no mention of Wasm, Wasmoon, function table, table0, globals, memory directory, debug current function, or GC cursor/limit.
- [x] `moon info` reflects the intended public API.
- [x] Native `moon check` passes.
