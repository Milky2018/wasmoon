# ISS-645: Avoid reverse lookup in the upstream HTTP test fixture

## Description
Each upstream WASI03 HTTP endpoint fixture calls HTTPServer.server_bind, which
resolves its numeric loopback address to fill server_name. On GitHub macOS
26.6.2 / Python 3.12.10, this lookup takes about 35 seconds per fresh process,
before Wasmoon starts. Twenty executions across two workers add about six
minutes to the suite.

## Design
Launch the pinned upstream runner through a small wrapper that changes only
its endpoint server's binding method. Preserve TCP binding, use numeric
server_name/server_port metadata, and leave upstream files, endpoint handlers,
requests, guest assertions and deadlines unchanged. Do not patch the global
HTTPServer class or the runtime resolver.
