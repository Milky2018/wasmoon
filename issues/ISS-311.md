## Description
Native continuation correctness depends on lifecycle edges that ordinary
conformance tests rarely exercise: cancellation while parked, re-entry,
resource borrows, code lifetime, stale reactor events, and repeated stack
allocation.

## Design
Add deterministic stress and sanitizer coverage for task trees, callback and
stackful continuations, host operation cancellation, parked GC roots, and
logical resource cleanup.

## Acceptance Criteria
- [x] Cancellation at every lifecycle phase is covered.
- [x] Re-entry and instance poisoning remain enforced.
- [x] No fiber, registration, executable mapping, future, stream, or resource handle leaks.
- [x] Large interleaving tests pass repeatedly under sanitizers.
