# ISS-232: Move the standard Wasm encoder into wasm_core

## Description

The standard WebAssembly binary encoder is currently implemented and exported by `Milky2018/wasmoon_jit/cwasm`, even though it consumes only the reusable `wasm_core/types` model. This makes component parsing, tests, and `wat2wasm` depend on a native product artifact package for a target-portable specification operation.

## Design

Move the implementation mechanically into the new reusable package `Milky2018/wasm_core/encoder`. Migrate every caller directly and remove the forwarding API and now-unused `wasm_core/types` dependency from the artifact package. Do not change encoder behavior or retain an alias under `cwasm`.

## Acceptance Criteria
- [x] `Milky2018/wasm_core/encoder.encode` owns the standard module encoder.
- [x] Component text parsing, tests, and `wat2wasm` import the reusable encoder directly.
- [x] `Milky2018/wasmoon_jit/cwasm` exposes no Wasm encoder API or dependency.
- [x] Existing encoder consumers and full warning-73 checks pass without snapshot changes.
