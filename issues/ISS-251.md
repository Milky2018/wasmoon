## Description

The cutover manifest runs bare `git diff --check` in a clean checkout, which checks only uncommitted changes and therefore cannot reject whitespace errors already present in the pull-request commit range.

## Design

Pass the event base and head commits into the target jobs and run `git diff --check BASE HEAD`, with a safe `HEAD^` fallback for manual runs. Lock the exact committed-range command in unit tests.

## Acceptance Criteria
- [x] Pull requests check the complete base-to-head committed range.
- [x] Push and workflow-dispatch events use a valid deterministic fallback.
- [x] A temporary Git fixture with committed whitespace damage makes the gate fail.
- [x] The command remains a required manifest entry.
