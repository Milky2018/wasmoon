## Description

Physical-register occupancy is represented as `Array[Array[Int]]`. Every
bundle probe independently queries each segment, conflict owners are deduped
with a linear `contains`, and allocation or eviction shifts array contents.

## Design

Introduce one package-private physical-register range index with logarithmic
updates and ordered traversal. Probe an ordered bundle and the occupied ranges
with one merged traversal, deduping conflict bundles without a linear scan.
Keep fixed-register reservations in the same conflict model where practical.

## Acceptance Criteria
- [ ] `occupied : Array[Array[Int]]` is gone from production allocation.
- [ ] One register probe traverses the bundle ranges and occupied ranges
      together rather than querying every segment independently.
- [ ] Insert and removal do not shift all following occupied ranges.
- [ ] Directed overlap, allocation, eviction, and differential tests pass.
- [ ] Native warning check passes and compile-time evidence is recorded.
