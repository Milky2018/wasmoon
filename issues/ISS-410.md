## Description

Physical-register occupancy is represented as `Array[Array[Int]]`. Every
bundle probe independently queries each segment, conflict owners are deduped
with a linear `contains`, and allocation or eviction shifts array contents.

## Design

Introduce one package-private physical-register range index with logarithmic
updates and ordered traversal. Probe an ordered bundle and the occupied ranges
with one merged traversal, deduping conflict bundles without a linear scan.
Keep fixed-register reservations in the same conflict model where practical.

## Acceptance Criteria
- [x] `occupied : Array[Array[Int]]` is gone from production allocation.
- [x] One register probe traverses the bundle ranges and occupied ranges
      together rather than querying every segment independently.
- [x] Insert and removal do not shift all following occupied ranges.
- [x] Directed overlap, allocation, eviction, and differential tests pass.
- [x] Native warning check passes and compile-time evidence is recorded.

## Close Notes

- Replaced sorted occupancy arrays with one intrusive treap node per live-range
  segment. Insertions and removals rotate indices in flat arrays and allocate
  no tree nodes.
- Register probing now merges the ordered bundle segments with one ordered
  occupancy cursor. A generation-mark array deduplicates conflicting bundles.
- `moon check modules/regalloc --target native --warn-list +73` passed.
- `moon test modules/regalloc --target native --warn-list +73` passed: 82/82.
- On the 12,993-instruction synthetic spilling workload, seven measured runs
  reduced median regalloc time from 33,859 us to 32,693 us (-3.4%). Median
  module compilation fell from 242,031 us to 239,163 us; generated code stayed
  byte-for-byte equal in size at 78,372 bytes.
