# ISS-502: Parse numeric memory indices independently of following instructions

## Metadata
- Type: bug
- Status: closed

## Description
Numeric non-lane memargs were recognized only before offset/align or a closing parenthesis, rejecting valid linear instructions such as i32.load 1 followed by another instruction. A lone SIMD lane index before a closing parenthesis was conversely consumed as a memory index.

## Close Notes
- Numeric ordinary memory indices no longer depend on the following token. SIMD memargs treat a single numeric immediate as the required lane index, including before a closing parenthesis; an additional numeric immediate identifies the memory.
- The regression checks both memory indices and lane indices. wasm-tools 1.254.0 parses and validates the fixture; the native parser regression and full native/core WAST suites pass.
