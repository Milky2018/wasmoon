# ISS-449: Lower verified MilkIR without owned semantic MachV

## Metadata
- Type: task
- Status: closed

## Description

The production compiler materializes a complete target-neutral semantic MachV
function after MilkIR optimization and then immediately traverses it again to
build target VCode. AEGIS-128L spends a 12,658 us median in this first lowering
before the 10,631 us target lowering. Prior work removed redundant verifiers but
left the owned intermediate representation and its value, block, CFG, GC-root,
and cleanup storage intact.

## Design

Replace the owned production intermediate with a verified selection input: a
narrow read-only view over verified MilkIR plus target-neutral call, GC, trap,
and environment semantics. Targets consume that interface directly when
constructing VCode. Keep semantic MachV as an explicit public compiler IR for
external clients and white-box diagnostics, but do not route ordinary Wasmoon
compilation through an owned copy.

The interface must hide MilkIR internals from target packages and preserve the
existing reusable-compiler module boundary. Product-owned runtime address and
ABI elaboration remain in `wasmoon_jit`.

## Acceptance Criteria
- [x] Ordinary Wasmoon JIT compilation does not allocate an owned semantic MachV function before target VCode construction.
- [x] AArch64 and x64 consume one target-neutral verified selection interface without importing Wasmoon-owned packages.
- [x] Calls, traps, GC roots, stack maps, block parameters, environment fields, and runtime ABI elaboration remain behaviorally identical.
- [x] Standalone semantic MachV construction, verification, diagnostics, and external transformations remain available and strict.
- [x] Seven cache-isolated AEGIS-128L runs materially reduce the 12,658 us semantic-lowering median without displacing equivalent work into target lowering.
- [x] Native, strict allocation-validation, target, semantic lowering, formatting, warning-73, generated-interface, and module-boundary gates pass.

## Close Notes

Production Wasmoon compilation now lowers verified MilkIR directly into an
immutable semantic selection plan, including target-neutral runtime ABI and GC
root-scope elaboration, while public semantic `Function` construction remains
available for diagnostics and transformations. Dense verifier tables removed
the remaining validation bottleneck. Verified with `moon info`, `moon fmt`,
warning-73 native check, 2,686 native tests under
`MACHV_REGALLOC_VALIDATION=1`, focused MilkIR/MachV/target tests, the reusable
module-boundary audit, and two seven-run cache-isolated AEGIS captures.
