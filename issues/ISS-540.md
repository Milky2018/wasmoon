## Description
The Linux ASan/UBSan gate with the system allocator passes functional assertions
but LeakSanitizer reports 115877 bytes in 6045 allocations at process exit.
Allocation stacks involve component runtime state. This is distinct from the
resolved ASan fiber/alternate-stack integration failure on macOS. Do not disable
leak detection to make the gate pass.

## Acceptance Criteria
- [x] Isolate the leaking public lifecycle scenarios and identify ownership roots.
- [x] Repair the responsible lifetime boundary without clearing borrowed state.
- [ ] Linux sanitizer gate passes including leak detection and the deliberate-error probe.
- [ ] Native and external cross-platform gates remain green.

## Notes
- Linux run 35059262668 supplied the initial leak report. A macOS system-allocator uninstrumented control for the yielding-call test reported no leaks; this is not equivalent to Linux LeakSanitizer evidence.

- Isolated run 35059821146 identified nine component lifecycle cases. Current MoonBit core retains backing slots after Array.clear to preserve ArrayView semantics; the older local toolchain clears slots. Terminal cleanup now calls shrink_to_fit after clearing owned arrays, releasing retained closures and Store references without modifying borrowed module arrays.
