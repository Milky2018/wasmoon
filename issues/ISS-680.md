## Description
The algorithm corpus repeatedly calls a portable 64x64-to-128 multiplication
helper. Its four 32-bit limb products remain in native code even though MilkIR
already represents unsigned high multiplication. Improve the exact arithmetic
idiom without recognizing function names or changing observable memory effects.

## Design
Use bounded, constant-depth matching of the complete unsigned 32-bit limb
and carry equations. Emit existing low/high multiplication primitives;
ordinary DCE removes dead intermediate arithmetic. Reject different masks,
shifts, signed limbs and mismatched source identities. Preserve call/trap
frames, stores, source metadata and all effects. Invalidate older code caches.
Retain the change only after measured execution gains and compilation controls.
