## Description
The stable facade and low-level native session entry independently clamp the
same optimization level to the supported range.

## Design
Treat the low-level session entry as the single normalization boundary. The
stable engine configuration captures and forwards the caller-provided value
without duplicating policy.

## Acceptance Criteria
- [x] Only the low-level native session entry clamps optimization levels.
- [x] Stable engine construction forwards the requested level unchanged.
- [x] Existing native component behavior and tests pass.

## Close Notes

Removed optimization-level normalization from the stable engine factory. It
now captures the caller's requested level unchanged; the low-level native
session entry remains the sole clamp and therefore the sole policy owner.

Native facade black-box tests, full native tests, and the Component 0.2/0.3 JIT
matrices pass.
