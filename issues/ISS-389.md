# ISS-389: `wasmoon/sanitizer_testsuite` is named after a gate that no longer exists

## Description
`modules/wasmoon/sanitizer_testsuite` exists only because ISS-368 pulled
`jit_resumable_lifecycle_test.mbt` and `component_runtime_facade_test.mbt`
out of the 17k-line `wasmoon/testsuite` package: a sanitizer-covered test
inside a large package dragged that package's whole compile into the gate's
budget.

The gate is gone, so the reason for the split is gone. The two test files
are still run — `moon test` covers every package — but the package name now
points at something that does not exist, which is exactly the kind of stale
name that misleads a later reader.

## Design
Either fold the two files back into `wasmoon/testsuite` and delete the
package, or rename the package to something that describes what the tests
actually cover (JIT continuation lifecycle and the component runtime
facade). The rename is the smaller diff; the fold-back restores the layout
that existed before ISS-368.

Not urgent and not bundled with the gate removal: it is a naming decision,
not part of deleting the gate, and the fold-back moves large files that
would conflict with anything else in flight.

## Acceptance Criteria
- [ ] No package is named after the removed sanitizer gate.
- [ ] Both test files still run under `moon test` with unchanged results.
