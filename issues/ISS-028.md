## Description
The reusable entry, hostcall, and interpcall trampolines replaced legacy emitter fallbacks, but the current implementation intentionally rejects incomplete ABI cases. The remaining gaps include V128 lane packing, stack-passed arguments, overflow result areas, and nontrivial AArch64 immediate/offset encodings.

## Design
Extend trampoline generation in `wasmoon_jit` using reusable ABI helpers and target emitters. Keep unsupported cases explicit until implemented, and remove each `TODO(ISS-026)` only when the corresponding ABI path is covered by tests.

## Acceptance Criteria
- [x] Entry trampolines support register-carried scalar and V128 argument/result forms needed by current Wasmoon exports.
- [x] Hostcall and interpcall trampolines support stack-passed arguments and overflow result areas.
- [x] AArch64 trampoline loads/stores and stack adjustments handle general offsets/immediates correctly.
- [x] Equivalent x64 V128 register behavior is covered.
- [x] Focused tests cover the formerly unsupported V128 signatures and private AArch64 offset/immediate helpers.
- [x] `moon test modules/wasmoon_jit --target native --warn-list +73 --diagnostic-limit=200` passes.
