## Description

A nested synchronous canon lower and lift with full-width integer
arguments and results performs general component value conversion on
both sides of a representation-preserving boundary.

## Design

Recognize full-width signed and unsigned scalar signatures with direct
Core arguments, no callback, suspension, canonical memory, realloc,
or post-return. Keep owned argument and result snapshots. Use the
ordinary synchronous task and guarded Core invocation lifecycle.
Keep the general conversion route for unsupported shapes and
unexpected results from a custom Core engine.

## Acceptance Criteria

- [x] Preserve signed and unsigned overflow, void and trap behavior in
  the native and interpreter paths.
- [x] Match five cold pairs on the unchanged 200,000-call component
  input with serial Wasmtime as the compatible reference.
- [ ] Verify the final platform run.
