# ISS-437: Carry verified compiler states through the serial JIT pipeline

## Description

The production JIT pipeline repeatedly verifies objects whose invariants were
already established by the immediately preceding stage. Semantic lowering,
mandatory MachV cleanup, target lowering, and target compilation each expose
safe public entry points, but their aggregate composition loses the proof that
the object has not been mutated between calls. The same path also runs
reference-root dataflow for functions that cannot contain GC references.

## Design

Introduce opaque, module-owned verified states or private trusted composition
functions. Public standalone entry points continue to validate their inputs;
only a lexical aggregate pipeline may consume established validation evidence.
Add a cheap type summary so semantic lowering can skip GC-root dataflow when a
function contains no reference-typed values. Do not add a process-wide switch
or weaken validation for external embedders.

## Acceptance Criteria
- [x] The aggregate MilkIR-to-target pipeline validates each invariant once.
- [x] Public standalone lowering and compile APIs still reject malformed input.
- [x] Functions without reference-typed values skip GC-root dataflow without changing safepoint metadata.
- [x] AArch64 and x64 use the same ownership protocol.
- [x] AEGIS-128L detailed metrics show the semantic/target-stage effect across at least seven cold captures.
- [x] Strict native tests pass with and without `MACHV_REGALLOC_VALIDATION=1`.

## Notes

- 2026-08-28: Current AEGIS-128L medians are 23,631 us for semantic lowering
  and 30,317 us for target lowering. Static tracing found repeated verification
  at semantic lowering, MachV cleanup, target lowering, and target compilation.

- 2026-08-28: Semantic MachV now retains whether its canonical storage passed
  verification. Target selection consumes that proof with a full-validation
  fallback, and produces an opaque target-owned `SelectedFunction` consumed by
  compilation. Public `lower`, `select`, and `compile` entries retain their
  validating behavior. Both targets use the same protocol. Semantic lowering
  also skips GC-root dataflow when its type scan finds no reference carrier.

- 2026-08-28: Seven final cold AEGIS captures put semantic lowering at 20,576
  us and target lowering at 21,933 us, down from 23,631 us and 30,317 us. Native
  tests pass 2,671/2,671 both normally and with
  `MACHV_REGALLOC_VALIDATION=1`; all 258 WAST files pass in interpreter and JIT
  mode, and all three Component Model suites pass.

## Close Notes

Closed after both target pipelines carried verified state without weakening
their standalone APIs, and the measured serial cold path and strict test gates
confirmed the intended effect.
