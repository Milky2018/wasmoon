## Close Notes

Both unmodified custom-page max-size scripts now pass in interpreter and JIT (`tmp/iss499-custom-pages`, four passes). Memory allocation and import compatibility preserve Int64 page limits; Store rejects failed native allocations. Memory growth and its native ABI now preserve Int64 page counts and results, with explicit overflow checks. The single-byte memory32 limit is 0xfffffffe, matching pinned Wasmtime `Memory::allow_growth_to`. Wide page-count regressions also pass the pinned oracle with `-O memory-reservation=8589934592`; the default 4 GiB shared-memory reservation legitimately rejects growth above its capacity. Initial native regression: 2379 passed. Final ABI-version and external gates pending.

Final validation: core WAST 258 files / 62563 assertions per engine, local runtime scripts, all component suites in both engines, macOS P1 116 pass / 2 intentional not-applicable, and all four high-memory custom-page executions pass (`/tmp/iss499-gate-results.json`). Both large page-count regressions pass ASan (`/tmp/iss499-asan.log`). JIT ABI is now 6 and codegen revision direct-vcode-3 to reject incompatible cached artifacts. Linux P1 JIT failures remain separately tracked under ISS-503; Linux validation of this milestone will run with that follow-up.
