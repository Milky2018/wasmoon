## Description
After the struct-view improvement, a fresh sample still identifies ref.test and
its object-kind/local-type helpers. ARM64 disassembly calls both helpers before
checking whether the requested type is concrete. Independent counters observe
244,433,867 concrete canonical checks at regex n2100: neither query is consumed.

## Design
Select concrete canonical checks before querying kind/local type. Preserve the
legacy local-type fallback. Abstract tests query only kind; retain every tag,
nullability, abstract predicate and registered nominal subtype relation. Do not
add caches or remove bounds checks based on unproved registry invariants.

- [x] Attribute calls and verify redundant queries in generated host machine code.
- [x] Preserve canonical, legacy, abstract and nullable reference behavior.
- [x] Establish repeated invocation/compile/RSS comparisons with controls.
- [ ] Pass native/wasm, strict, integration and fresh sanitizer gates.
- [ ] Pass exact-head platform CI with clean artifact provenance.
