# ISS-521: Preserve native exception reference identity and payload ownership

## Metadata
- Type: bug
- Status: closed

- Created: 2026-09-10
- Updated: 2026-09-10

## Description
Native catch_ref and catch_all_ref currently manufacture references from tag indices. Native throw_ref ignores the reference and reuses transient exception state. A saved exception carrying 11, followed by another carrying 22, rethrows with payload 0 in JIT; the interpreter and pinned Wasmtime return 11. Implement stable exception ownership before adding native continuation exception injection.

## Acceptance Criteria
- [x] Saved exceptions retain their identity and payload after subsequent throws and handler exits.
- [x] Null throw_ref traps; imported tags and cross-call references preserve Store identity.
- [x] Exception payload GC roots survive collection and are released before Store heap destruction.
- [x] Native regressions, independent controls and existing external exception suites pass.

## Close Notes
- Replaced tag-index placeholders with non-null arena references. Rethrowing restores the referenced immutable tag and payload instead of transient handler state; null references trap explicitly.
- Native instances share a Store-owned exception arena. Handler exit and subsequent throws do not destroy saved objects. Store retirement unregisters payload roots before destroying the native heap. Tag layouts keep scalar and SIMD words out of retained GC roots.
- Interpreter/native arguments, results, globals and GC fields translate exception identities consistently, including imported tags whose local index differs from the Store address.
- Added independent WAST controls for saved scalar/SIMD payloads, catch_ref/catch_all_ref, null references and imported tags. Pinned Wasmtime and both Wasmoon engines pass all six assertions without changing upstream fixtures.
- Validation: 2443 native tests passed; 57 exception-related tests passed under ASan (leak detection disabled); official exception suite, all 12 local runtime scripts and ten relevant misc executions passed. Module-boundary audit and generated-interface/format/native-check gates passed.
