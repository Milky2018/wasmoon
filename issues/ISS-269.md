## Description
The exact official Component Model snapshot at
`d6b48f2f28880fbf3cbc3777fba7ac31084c7540` contains 24 files that require the
Component Model async proposal included in WASI 0.3 but no later gated
proposal. Wasmoon passes 8 files strictly. The remaining 16 files expose 77
command failures in async
lift/lower validation, stream and future ownership, cancellation, reentrancy,
waitable sets, resource transfer, and the component WAST harness.

The exact current counts are recorded in this issue. The dedicated strict CI
lane executes all files without an expected-failure exemption.

## Design
Resolve the 0.3 async validator and runtime semantics against the pinned
official tests. Keep feature-version classification independent from
additional async built-ins, the stackful async ABI, and component threading.
Do not move failing 0.3 tests into the future-gated suite.

## Acceptance Criteria
- [x] All 24 `async-0.3` files pass.
- [x] Async ABI validation rejects invalid sync function contracts.
- [x] Streams, futures, cancellation, transfer, and reentrancy match the
      official observable behavior.
- [x] Focused regressions and all component snapshot/quality gates pass.
