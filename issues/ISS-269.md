## Description
The exact official Component Model snapshot at
`d6b48f2f28880fbf3cbc3777fba7ac31084c7540` contains 24 files that require the
WASI 0.3 🔀 async feature but no later gated feature. Wasmoon passes 8 files
strictly. The remaining 16 files expose 77 command failures in async
lift/lower validation, stream and future ownership, cancellation, reentrancy,
waitable sets, resource transfer, and the component WAST harness.

The exact current counts are recorded in this issue. The dedicated strict CI
lane executes all files without an expected-failure exemption.

## Design
Resolve the 0.3 async validator and runtime semantics against the pinned
official tests. Keep feature-version classification independent from future
🚝, 🚟, and 🧵 behavior. Do not move failing 0.3 tests into the future-gated
suite.

## Acceptance Criteria
- [ ] All 24 `async-0.3` files pass.
- [ ] Async ABI validation rejects invalid sync function contracts.
- [ ] Streams, futures, cancellation, transfer, and reentrancy match the
      official observable behavior.
- [ ] Focused regressions and all component snapshot/quality gates pass.
