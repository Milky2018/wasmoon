## Description

AEGIS-128L spends 34,729 us in MilkIR optimization, including 20,797 us in
egraph rewriting and 5,030 us in global GVN. The optimizer time has a 0.991
correlation with surviving instruction count. ISS-438 already demonstrated the
relevant direction: replacing maps keyed by dense eclass IDs with indexed
arrays reduced egraph time by 22.2 percent without changing rewrite policy.

The remaining gap to Cranelift's optimizer is likely in hot node, edge, use,
and temporary-worklist representation rather than excessive convergence or a
single runaway rule.

## Design

Use ISS-441 attribution plus allocation/drop counters to identify the remaining
reference-counted records created per eclass, enode, parent edge, use, and
extraction step. Move only proven dense immutable facts to indexed storage or
carefully validated value representation, and reuse temporary worklists where
ownership permits.

Retain the current egraph rewrite policy, global GVN semantics, bounded memory
analysis, optimization level, and extraction result. Do not lower budgets or
disable a pass to satisfy the compile-time target.

## Acceptance Criteria
- [x] A source-grounded allocation/drop attribution identifies the hot optimizer records before their representation changes.
- [x] Dense hot facts and reusable temporary collections no longer incur avoidable map, object, or reference-count traffic.
- [x] Egraph rewrites, GVN decisions, optimized MilkIR, and generated AEGIS-128L code remain unchanged.
- [x] Across at least seven cache-isolated AEGIS-128L captures, aggregate MilkIR optimization improves materially without moving time into lowering or regalloc.
- [x] Function 56 remains at the 16,036-byte code-size control, and no optimization budget or memory-analysis coverage is reduced.
- [x] MilkIR optimizer tests, formatting, warning-73 checking, and generated interfaces pass.

## Notes
- 2026-08-28: This is deliberately lower priority than target-lowering and allocator representation work. The optimizer is about 21.5 percent of total compilation time, while lowering plus regalloc is about 65.9 percent.
- 2026-08-29: Tagged counters on an AEGIS cold compile observed 29,131 canonicalization calls, of which 24,741 (84.9 percent) returned the same canonical children and order. The old path still allocated a children array and `ENode` for every call and used payload-bearing constant options for presence tests.
- 2026-08-29: Extraction visited 29,402 nodes and replaced a best-table entry 11,080 times. Each old replacement rebuilt an `ExtractCost`, tuple, and option entry. Rebuild repaired only 1,278 classes, so replacing its work sets with persistent epoch state was rejected as complexity aimed at the smaller source of traffic.
- 2026-08-29: Canonicalization now copies children only after finding a stale id and returns the existing node on the 84.9-percent identity path. Constant presence is read directly from the canonical class. Extraction stores costs and depths in parallel dense scalar arrays and uses the optional node as the presence bit. Saturation scans the at-most-four admitted class nodes for duplicate opcode tags instead of allocating one tag array per class.
- 2026-08-29: Seven cache-isolated AEGIS runs at `7e609f01` measured medians of 29,454 us optimizer / 17,690 us egraph / 100,638 us module compile. Seven final runs measured 27,788 us / 16,106 us / 99,114 us: optimizer improved 5.7 percent and egraph improved 9.0 percent. Lowering was 12,730 -> 12,658 us, target lowering 10,790 -> 10,631 us, and regalloc 32,558 -> 32,513 us, so the gain was not shifted downstream.
- 2026-08-29: Per-function pass decisions, instruction counts, egraph class/node/rule counts, GVN work and budget results, spills, reloads, and code sizes matched the baseline. Total code remained 59,428 bytes and function 56 remained 16,036 bytes. No rewrite, extraction, GVN, or memory-analysis budget changed.
- 2026-08-29: `moon info`, `moon fmt`, warning-73 native checking, 186 egraph tests, 191 MilkIR tests, 2,685 native tests, and the same 2,685 native tests with `MACHV_REGALLOC_VALIDATION=1` passed.

## Close Notes
Closed after removing the three measured sources of short-lived egraph objects while preserving the optimizer decision signature and generated code controls. Cache-isolated AEGIS medians show a 9.0-percent egraph improvement and a 5.7-percent aggregate MilkIR optimizer improvement without downstream displacement.
