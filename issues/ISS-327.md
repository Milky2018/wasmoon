# ISS-327: Consolidate native platform CI with a matrix

## Description
The Linux AMD64 and macOS ARM64 jobs in `.github/workflows/check.yml` duplicate
almost every step. Changes to source checks, test suites, component conformance,
or sanitizer coverage must currently be applied twice and can silently drift.

## Design
Use one matrix job whose entries carry only genuine platform differences:
runner image, display name, native-test arguments, and ASan leak policy. Keep
Linux system dependency installation conditional. Preserve two independent
platform check names and keep sanitizer execution inside each matrix leg.

## Acceptance Criteria
- [x] The workflow defines the common native pipeline exactly once.
- [x] Linux AMD64 and macOS ARM64 remain independent matrix legs.
- [x] Linux-only dependency installation and platform-specific sanitizer policy
      remain explicit.
- [x] Existing source, native, WAST, WASI, Component Model, and sanitizer gates
      remain in both legs.
- [x] Workflow structure tests and repository quality checks pass.
