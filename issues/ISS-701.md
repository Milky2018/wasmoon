# ISS-701: Preserve semantic pointer carrier types at CFG edges

## Metadata
- Type: bug
- Status: in_progress

- Created: 2026-10-25
- Updated: 2026-10-25
- External ref: none

## Description
Both direct target selectors fold explicit I64/Ptr64 bitcasts into raw-word
aliases. The source value keeps its semantic type, while its target definition
keeps the original type. Strict CFG-edge validation consequently rejects legal
converted values with EdgeClassMismatch when passed to typed block parameters.
An isolated struct-view experiment exposed this independently of its rejected
performance specialization.

## Design
Materialize a typed Move only when an explicit untraced carrier alias reaches a
CFG edge with a different underlying target type. Keep body aliases free and
leave the session-wide value mapping unchanged: an edge-local copy need not
dominate uses in another branch. Query owned value types through CheckedBuilder;
do not expose mutable storage or relax edge, ownership, register or GC checks.
GcRef64 is never converted by this rule. Unconverted invalid source arguments
must still fail the existing strict validator.
