## Description
`TypeCheckIndirect(Int)` is a Wasm `call_indirect` exact type-check operation
encoded as a MachV instruction. It carries Wasm type-index semantics and emits a
specific compare-and-trap sequence.

## Design
Move exact indirect type-check lowering out of MachV instruction core. The
Wasm-facing lowering path should emit generic compare and conditional-trap
instructions that preserve the current trap behavior.

Do not change subtype-enabled indirect calls in this issue; they are handled by
ISS-071.

## Acceptance Criteria
- [ ] `TypeCheckIndirect(Int)` is removed from MachV instruction core.
- [ ] Exact indirect type checks lower to generic compare and trap instructions.
- [ ] The trap condition and trap code behavior match the existing emitter behavior.
- [ ] Relevant `call_indirect` exact-check WAST tests pass.
