## Description
Migrate MilkIR builders and Wasm frontend producers to normalized vector operations, then derive verifier contracts, printing, and effect summaries from the operation families instead of exhaustive copied constructor lists.

## Design
Migrate one semantic family at a time and remove its old constructors immediately. Vector memory effects must remain explicit. The printer must retain the existing textual MilkIR spelling, and verifier tests must cover supported and rejected parameter combinations.

## Acceptance Criteria
- [x] All MilkIR and Wasm frontend producers emit normalized vector operations.
- [x] Verifier contracts are organized by semantic family and reject unsupported combinations.
- [x] Printer output remains stable for existing vector operations.
- [x] Opcode effect summaries no longer enumerate every pure vector operation.
- [x] Relevant MilkIR and frontend tests pass.
