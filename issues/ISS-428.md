# ISS-428: Keep bounded memory GVN in large functions

## Description
MilkIR GVN disables all memory analysis whenever a function's total instruction
count exceeds its work budget. Consequently, memory expressions that occur
entirely within the first 300 visited instructions lose otherwise provable
reuse merely because unrelated instructions follow them.

## Design
Preserve bounded compilation work. Collect pointer-base facts only for the
dominator-order instruction prefix that GVN can visit. Small functions retain
the complete cross-CFG last-store analysis. Large functions start each
non-entry block with an independent unknown memory version, allowing safe
within-block memory reuse without assuming facts from unanalyzed predecessors.
Unknown pointer bases remain conservatively aliasing.

## Acceptance Criteria
- [ ] A large function reuses a provably identical memory value within the first 300 visited instructions.
- [ ] GVN does not inspect or optimize instructions beyond its work budget.
- [ ] Large-function partial memory analysis does not reuse values across unknown block-entry memory state.
- [ ] Existing full cross-CFG memory GVN remains unchanged for functions within budget.
- [ ] Focused MilkIR tests and the strict native test suite pass.
- [ ] Formatting, interfaces, native checks, and module-boundary audit pass.
