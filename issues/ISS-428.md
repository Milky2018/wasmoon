# ISS-428: Keep bounded memory GVN in large functions

## Description
MilkIR GVN disables all memory analysis whenever a function's total instruction
count exceeds its work budget. Consequently, memory expressions that occur
entirely within the first 300 visited instructions lose otherwise provable
reuse merely because unrelated instructions follow them.

## Design
Preserve bounded compilation work. Collect pointer-base facts only for the
dominator-order instruction prefix that GVN can visit. Small functions retain
the complete cross-CFG last-store analysis. Large functions start each
non-entry block with an independent unknown memory version, allowing safe
within-block memory reuse without assuming facts from unanalyzed predecessors.
Unknown pointer bases remain conservatively aliasing.

## Acceptance Criteria
- [x] A large function reuses a provably identical memory value within the first 300 visited instructions.
- [x] GVN does not inspect or optimize instructions beyond its work budget.
- [x] Large-function partial memory analysis does not reuse values across unknown block-entry memory state.
- [x] Existing full cross-CFG memory GVN remains unchanged for functions within budget.
- [x] Focused MilkIR tests and the strict native test suite pass.
- [x] Formatting, interfaces, native checks, and module-boundary audit pass.

## Close Notes
- 2026-08-13: Replaced the whole-function memory-analysis switch with a bounded pointer-analysis prefix that follows GVN's dominator preorder and contains at most the work budget's instructions. Large functions retain conservative within-block store-to-load forwarding while unknown block-entry memory state prevents unsupported cross-block reuse; functions within budget keep complete cross-CFG analysis. Added whitebox coverage for prefix forwarding, the fixed 300-instruction work count, conservative large-function block entries, and unchanged small-function cross-block forwarding. Verification passed all 189 MilkIR tests, `moon fmt`, `moon info`, native check with warning 73, `MACHV_REGALLOC_VALIDATION=1 moon test --target native --warn-list +73` (2621/2621), and the module-boundary audit.
