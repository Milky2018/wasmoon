# ISS-335: Preserve the named fiber advance invalid-state result

## Description
The C fiber protocol names advance result `-4` as
`WASMOON_FIBER_ADVANCE_INVALID_STATE`, but the MoonBit decoder classifies it as
an unknown `FiberAdvanceNativeFailure(-4)`. The public `InvalidState(Int)` error
therefore cannot represent this named protocol outcome.

## Design
Add a dedicated internal decoded advance variant for `-4`. When it is returned
after a stack switch, read the fiber's raw state code and convert the operation
to `FiberInvalidState(code)`, preserving the existing meaning of the public
`InvalidState(Int)` payload. Keep genuinely unknown advance codes mapped to
`NativeFailure`.

## Acceptance Criteria
- [x] Advance status `-4` decodes to a named invalid-state result.
- [x] The public operation path converts that result to `InvalidState(Int)`.
- [x] Unknown advance codes remain distinguishable as `NativeFailure`.
- [x] Fiber protocol, native fiber, and native project tests pass.
