# ISS-672: Preserve recursive groups when preparing the CLI GC context

## Metadata

- Status: closed

## Description
CLI invocation canonicalized `Store.current_types()` without its recursive
partition. The pinned parse_double module produced 159 unresolved references
and entered the pairwise fallback intended for unvalidated type graphs.
Omitting groups also changes isorecursive equivalence, so this is a metadata
correctness defect as well as an avoidable loading cost.

## Design
Snapshot type definitions and their recursive partition together through
`Store.current_type_graph()`. Use both for CLI canonicalization and reuse the
same definitions for GC setup. Keep the fallback for genuinely unvalidated
inputs; do not cache arbitrary public type resolvers or weaken equivalence.

  This is loading evidence, not an invocation or compiler-target claim.
