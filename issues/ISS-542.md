## Description
Remove resume-action context self-cycles, register suspended interpreter cleanup with the Store, and expand leak detection for terminal and abandoned execution.

## Notes

- Initial macOS system-allocator reproduction reported 158 leaked allocations / 6992 bytes when a suspended host call was abandoned after Store close; explicit cancellation reported zero.
- Resume actions now receive their ExecContext explicitly. Parked continuations register cleanup with their Store; consumption detaches registration before running guest/host work, and terminal handles release their captured state. Atomic waits and pending async host tasks have explicit cancellation hooks. Consumed or cancelled interpreter handles report ContinuationAlreadyConsumed on reuse, replacing the incidental Unreachable trap.

- Local validation passes 2497/2497 native tests and the expanded ASan/UBSan closure. Rebuilding the original macOS system-allocator reproducer against the fix changes the abandoned-after-close case from 158 allocations / 6992 bytes to zero reported leaks. Linux and full platform validation remain required.

- Linux run 35064367739 passes all 37 sanitizer fixtures without leaks. Its macOS native job exposed a scheduling assumption in the new async-host test before Store close: a one-millisecond delay did not guarantee host startup. Replaced timer-based coordination with explicit start/pending semaphores; the cancellation and cleanup assertions remain unchanged.

## Close Notes

- Final combined acceptance: https://github.com/Milky2018/wasmoon/actions/runs/35065396974 on 440c4d9a. Linux AMD64, macOS ARM64, Windows AMD64 Clang and MSVC, and Linux ASan/UBSan all passed. Native tests pass 2497/2497; the instrumented closure passes 37/37 with leak detection enabled and the deliberate ASan error detected.
- The expanded audit covered transaction callback capture, interpreter host suspension, explicit cancellation, repeated suspension and consumed handles, close during a host callback, atomic wait ownership, async host cancellation and cleanup reentry, plus the existing component and JIT lifecycle fixtures. No additional leak was reported in these scenarios. This is bounded coverage, not a claim that every project path or native stub has been proven leak-free.
- Resume actions do not capture their owning context. Parked execution remains explicitly Store-owned and embeddings must close their Store. The API lifetime contract is recorded in docs/native_call_export_api.md.
