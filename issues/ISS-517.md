## Description
Represent continuation types and references in the portable core type graph. Parse, encode and render all pinned typed-continuation operators and handler tables. Validate their stack effects, referenced function/tag types and subtype relations. Add a real stack-switching feature profile while retaining existing default core validation behavior.

## Acceptance Criteria
- [x] Pinned continuation syntax roundtrips through WAT and binary encodings verified by independent tooling.
- [x] Positive and negative operator/type/handler controls match the pinned validator.
- [x] WAST configuration enables the actual stack-switching validation profile; existing core and native suites remain green.

## Close Notes
- Implemented the continuation type hierarchy, recursive type handling, seven operators, handler tables, binary codecs, canonical text rendering, and a real `--stack-switching` validator profile.
- Fixed pre-existing heap-immediate encoding and text-only block signature loss exposed by continuation roundtrips. The encoder now materializes block signatures without mutating the source module and preserves recursive groups.
- All 49 standalone modules from the pinned continuation corpus passed text/binary roundtrips and both validator entry points. Every emitted binary independently passed `wasm-tools validate --features all` (`/tmp/iss517-independent-encoding.json`). Portable core package tests: 388 passed.
- Native regression suite: 2440 passed. Complete official core, local runtime, component and explicit-rights P1 gates passed (`/tmp/iss518-gate-results.json`).
- The pinned source was built for x64 macOS to establish a runnable continuation oracle. It passed 38 of 46 related scripts; eight `switch` scripts hit the pinned backend's platform restriction, not a guest assertion failure (`/tmp/iss517-x64-upstream-oracle.json`).
