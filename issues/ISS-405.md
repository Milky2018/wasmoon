# ISS-405: Rebuild cheap values once per using block after GVN

## Description

This is the change that fixes the doubling measured in ISS-403.

Elaboration currently reuses any dominating definition of an e-class for
free. For a constant used across many blocks, that single definition is
live for the whole function, so the register allocator gives it a stack
slot and reloads it at every use. In the measured fixture 64.5% of the
emitted bytes are spill and reload traffic and the marginal cost per wasm
op doubles from 16 to 32 bytes.

## Design

Add one linear MilkIR pass after GVN and final CFG cleanup. Record candidate
definitions in dense value-indexed arrays, rebuild each candidate at most once
per using block, and rewrite ordinary and terminator operands. Use generation
stamps for block-local replacements so the pass does not clear a value-sized
array for every block. Run DCE afterward.

Do not modify e-graph elaboration or regalloc. Do not recurse or use distance,
pressure, or clone-count heuristics.

## Acceptance Criteria
- [ ] A constant used in several blocks is rebuilt in each using block
      rather than reused from a dominating definition.
- [ ] Repeated uses within one block still share one definition.
- [ ] The 256-distinct-address fixture holds at 16 B/op at 400 and 800
      ops, with no cliff between 280 and 300.
- [ ] Spill and reload traffic drops well below the measured 64.5% share
      on the 20,000-op fixture.
- [ ] A regression test pins the marginal byte cost. It must be cheap:
      the 400-op case is a few hundred milliseconds, unlike the megabyte
      fixture rejected on cost in ISS-402.
- [ ] Workspace tests and the WAST corpus pass in both modes.

## Notes
- 2026-08-07: The fixture is `scripts/gen_wide_branch_wat.py`, which
  cycles through 256 distinct addresses. A variant with every address
  distinct already holds at 16 B/op through 800 ops and is the control.
- 2026-08-12: Current elaboration still treats any dominating
  `class_to_value` entry as free and has no `(block, key)` rebuild cache. The
  existing remat rules affect extraction cost only; they do not cut the
  cross-block live range described here.

- 2026-08-12: Moved the design after global GVN. The previous elaboration
  placement ran too early to repair the transformation that creates the long
  range.
- 2026-08-12: Implemented the linear late pass and wired it into the final O2
  cleanup. Focused MilkIR tests cover once-per-block cloning, repeated uses,
  terminator uses, and DCE of the original definition. End-to-end code-size
  evidence remains before closure.
