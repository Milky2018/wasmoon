## Description
A valid2048-object initializer produces25.6MB of machine code and47.4MB of
artifact data. Fresh profiles show2,089,994 reloads and4.54s in register allocation.
Root definitions already live in registered function shadow slots, but ordinary
call metadata transports the same roots into target KeepAlive instructions.

## Design
After complete function-mask publication, omit duplicate SSA root transport only
for ordinary calls covered by that registered frame. Preserve call-site and
argument metadata, logical liveness, strict slot admission, returns-twice rejection,
caller-scope fallback, tails and noreturn handling. Native GC, parked execution
and rollback already enumerate the frame independently. Advance codegen22 and
reject cached21 artifacts; the format and native ABI remain unchanged.
