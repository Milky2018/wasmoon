## Description
Move the repository toward a MoonBit workspace where all first-stage modules live under `modules/`, including the final `wasmoon` package. This creates the physical layout that later extraction tasks depend on.

## Design
Introduce `moon.work` and place module roots under `modules/`. Keep changes mechanical at first: do not change compiler abstractions in this issue. The target module names are `wasm_core`, `milkir`, `machv`, `regalloc`, `machv_regalloc`, `machv_emit`, `x64_target`, `aarch64_target`, `wasmoon_jit`, and `wasmoon`.

## Acceptance Criteria
- [ ] A MoonBit workspace exists with all first-stage module roots under `modules/`.
- [ ] Existing package imports are updated enough for `moon check` to discover the workspace.
- [ ] Root-level package/module metadata no longer implies a single monolithic Wasmoon module.
- [ ] `moon check` passes or any remaining failures are captured in follow-up issues.
