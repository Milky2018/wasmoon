# ISS-154: Return typed Wasm dialect lowering errors

## Description
`wasm_isa_lower` decodes extension operations with `decode_or_abort`. Unknown or malformed public `ExtOp` values can therefore terminate the process instead of returning a validation error at the Wasm adapter seam.

## Design
Validate all Wasm extension operations before machine lowering, return a typed Wasm lowering error from the public lowering interface, and remove the public aborting decoder. The private lowering callback may rely on the validated invariant but must not expose an aborting entry point.

## Acceptance Criteria
- [ ] Unknown and malformed Wasm extension operations return typed errors from the public lowering interface.
- [ ] Removed legacy memory and table opcode names return typed errors rather than aborting.
- [ ] `decode_or_abort` is no longer public.
- [ ] Valid frontend-produced Wasm MilkIR continues to lower unchanged.
- [ ] Generated interfaces, relevant tests, full native tests, warning checks, and module-boundary audit pass.
