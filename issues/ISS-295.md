## Description
Current official suites contain boundary cases but do not provide a dedicated,
repeatable workload for large valid components and repeated facade invocation.

## Design
Generate large components instead of committing opaque binaries. Exercise many
core functions, lifted functions, exports, nested instance paths, wide type
shapes, and repeated calls. Apply explicit generation, parsing, validation,
invocation, wall-time, and artifact-size limits and emit a report for trend
analysis.

## Acceptance Criteria
- [x] The stress corpus covers width, nesting, export count, code size, and
      repeated invocation.
- [x] Boundary-valid cases succeed and deliberate over-limit cases fail
      structurally rather than aborting.
- [x] Every workload records generation parameters, artifact size, phase
      timings, peak RSS where available, and final status.
- [x] A bounded smoke configuration runs on pull requests.
- [x] A larger scheduled/manual configuration uploads its report and generated
      reproducers.
