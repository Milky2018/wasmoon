## Description
Convert one independently owned resource from an external pointer to a MoonBit-managed owner for review. Scope is the DWARF builder only.

## Design
Allocate the complete builder as a MoonBit external object with a finalizer; expose it as an opaque DWARFBuilder type. No separate pointer shell or custom reference count. All FFI operations borrow it. Explicit destroy and the finalizer share idempotent cleanup, unregister debugger metadata, release its buffer and clear the weak active-builder pointer. Closed aliases cannot mutate or resolve addresses. Registration is idempotent and unregister permits registration again.

## Acceptance Criteria
- [x] Capturing closures keep builders alive after the creating scope returns; dropping the last owner invokes cleanup without explicit destroy.
- [x] Repeated close, unregister/register, and post-close aliases are safe; closing an inactive builder preserves the active one.
- [x] Strict MoonBit/C checks, native tests and ASan/UBSan pass.
- [x] Other resource ownership protocols remain unchanged.

## Notes
The debugger registry and active-builder pointer borrow the builder; they do not own a permanent RC reference. Cleanup unlinks those references before the runtime frees the managed allocation. Callers retain the owner for the period in which symbolication is required.

## Close Notes
DWARFBuilder now directly owns one MoonBit external-object allocation containing its complete native state. All operations borrow the managed object. Explicit close and the finalizer share cleanup, including invalidating the active-builder pointer; no other resource owner was migrated.

Verified with strict native MoonBit checks, 35 warning-clean C translation units, all 2565 native tests, and 47 ASan/UBSan tests plus instrumentation controls. The closure-lifetime regression observes the C weak pointer after normal last-reference release without explicit destroy or forced collection. Alias-close and unregister/register regressions pass. Cross-platform CI is dispatched separately after push; these results are local macOS arm64 validation.
