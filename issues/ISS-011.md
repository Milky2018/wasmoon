## Description
Create `modules/wasmoon_jit` for Wasmoon-specific JIT integration, native glue, runtime symbol resolution, executable memory, host calls, VMContext access, traps, helper bindings, and `.cwasm` artifacts.

## Design
Consume MilkIR/MachV/machv_emit outputs through clean interfaces. Resolve generic relocations to Wasmoon runtime helpers and `jit_ffi` symbols inside `wasmoon_jit`. Keep `.cwasm` as a Wasmoon-owned artifact that may wrap machine-code bytes, function indices, imports, trap/debug mappings, and runtime metadata.

## Acceptance Criteria
- [ ] `wasmoon_jit` owns `jit_ffi`, native C/assembly glue, executable memory, runtime helper resolution, and hostcall integration.
- [ ] `.cwasm` reading/writing remains in `wasmoon_jit` rather than `machv_emit`.
- [ ] `machv_emit` no longer imports Wasmoon runtime or JIT FFI code.
- [ ] Existing JIT correctness tests pass or have follow-up issues for unsupported cases.
