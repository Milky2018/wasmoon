## Description
Move the reusable optimization pipeline now under `modules/wasmoon/ir/opt*.mbt` and `modules/wasmoon/ir/egraph` onto MilkIR, without baking WebAssembly semantics into generic optimization passes.

## Design
Separate generic algebraic, CFG, CSE/GVN, rematerialization, and loop optimizations from Wasm-specific legality conditions. Keep optimization APIs usable by non-Wasmoon frontends. If a rule depends on WebAssembly numeric, reference, trap, or runtime behavior, isolate that condition behind metadata or a Wasm-specific rule set.

## Acceptance Criteria
- [ ] MilkIR exposes an optimization driver or pass API with ported tests from the old IR optimization suite.
- [ ] Generic optimization passes do not import `wasm_core` or Wasmoon runtime/JIT packages.
- [ ] WebAssembly-specific rewrite legality is isolated in frontend/runtime-specific adapters or explicitly documented follow-up issues.
- [ ] Old IR optimization tests are ported, replaced, or tracked as follow-up issues.
- [ ] `moon test --target native --warn-list +73 --diagnostic-limit=200` passes for affected packages.
