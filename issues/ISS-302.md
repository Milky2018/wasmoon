## Description
The Wasmoon-owned async runtime needs real macOS readiness and timer delivery
without polling loops or threads.

## Design
Implement an internal native adapter using kqueue for descriptor readiness,
timers, and an explicit wakeup source. Keep all platform handles behind the
reactor seam and make registration cancellation idempotent.

## Acceptance Criteria
- [x] Read, write, timer, wake, cancel, and stale-event behavior is tested on macOS.
- [x] No busy polling is used.
- [x] Dropped registrations cannot deliver events to reused operation IDs.
- [x] Native sanitizer coverage passes.

## Close Notes
- Added a Wasmoon-owned native reactor adapter backed by one-shot kqueue
  descriptor filters, `EVFILT_TIMER`, and `EVFILT_USER`.
- Kept descriptors, filters, and monotonic kernel tokens behind opaque
  registrations while delivering readiness through `wasmoon_async.Waker`.
- Made cancellation idempotent and removed tokens before cancelling runtime
  operations so queued stale events cannot wake reused operations.
- Verified all four native adapter tests with normal and ASan/UBSan builds and
  compiled the C adapter with `-Wall -Wextra -Werror`.
