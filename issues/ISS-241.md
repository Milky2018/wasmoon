## Description

`explore --stage regalloc` currently prints a placeholder instead of the selected Target VCode and its allocation. The final architecture needs stable read-only views of semantic MachV, target-selected VCode, allocated VCode, the unlinked code object, and machine bytes for both native targets.

## Design

Add a Wasmoon-owned diagnostic facade that runs the same target-owned lowering, allocation, frame, and emission checkpoints as production and returns rendered ordinary-data views. Keep concrete target instruction and construction types behind the facade. Migrate CLI and HTML explore output to the real views and test complete snapshots for x64 and AArch64.

## Acceptance Criteria
- [x] A single diagnostic facade exposes semantic MachV, selected Target VCode, allocated VCode, unlinked code-object metadata, and machine bytes.
- [x] Both AArch64 and x64 diagnostics execute their real target-owned verified pipelines.
- [x] CLI and HTML `explore` stages render real data and no placeholder text remains.
- [x] Whole-view snapshots cover both targets and malformed input remains a structured pipeline failure.
- [x] Strict checks and relevant native tests pass.
