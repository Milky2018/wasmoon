## Description
Extract target-independent register allocation into `modules/regalloc`. This module is the pure algorithm library and must not depend on concrete MachV instruction data structures.

## Design
Define an abstract program view for virtual-register definitions, uses, CFG, constraints, clobbers, live ranges, spill requirements, and allocation results. Move algorithmic pieces from the current `vcode/regalloc` implementation while keeping MachV-specific projection and rewriting out of this module.

## Acceptance Criteria
- [x] `regalloc` exposes an abstract allocator input and allocation result model.
- [x] `regalloc` does not import `machv` concrete instruction definitions.
- [x] Existing allocation tests are ported or replaced with tests over the abstract program model.
- [x] Known incomplete allocator features include scoped `TODO(regalloc)` comments.
