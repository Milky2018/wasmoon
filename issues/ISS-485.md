## Description
The runner treats quoted text as a parse failure, accepts parse failures for assert_invalid, and accepts arbitrary instantiation failures for assert_unlinkable. Audit these decisions against the pinned WAST adapter before changing them. The first quoted-text control behaves identically in Wasmtime; no divergence has yet been established.

- [x] Fix any confirmed divergence and verify the affected external inputs on both engines.

## Close Notes

- Pinned 668016 controls confirm two phase divergences: valid quoted text in assert_invalid and invalid inline/binary modules in assert_unlinkable pass Wasmoon incorrectly but fail the oracle. The former added a second module wrapper; the latter caught parse/validation errors together with instantiation failures.
- Empty diagnostic controls distinguish phase behavior from diagnostic wording. Quoted valid text in assert_malformed is still accepted by both adapters when no diagnostic substring is required; do not reinterpret that as a phase divergence. Start traps satisfy assert_unlinkable in the pinned adapter and remain accepted.
- A positive quoted module executes in the pinned adapter, including a child thread after an initial root module. Preserve the exact concatenated text in ordinary and threaded execution. The native regression failed before the fix (`/tmp/iss485-red-phase.log`, one failed test).

- The first full sweep exposed valid implicit quoted modules in comments.wast and annotations.wast. Added an explicit `implicit_module` parsing option that detects an existing module form using lexer tokens (including skipped annotations/comments), wraps only field fragments, and protects the closing token from trailing line comments. Ordinary parser callers retain their default strict module form.
- The corrected positive fixture passes pinned Wasmtime; 27 independent phase controls cover expected acceptance and rejection across the oracle and both engines. Exact validation diagnostic wording remains outside this phase audit.

- Final native: 2431 passed. Official core returns to 258 files and 62563 assertions per engine; all 11 local runtime scripts pass in both engines. Component and explicit-rights P1 lanes pass (116 passes, two intentional not-applicable executions). Full misc remains 602 pass, 72 script-only, 90 typed-continuation failures, zero unsupported/timeout/deferred/harness errors (`tmp/iss485-final-all-misc/summary.json`). No upstream fixture or expected result was changed.
