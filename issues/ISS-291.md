## Description
Malformed component binaries and generated valid component programs are not
currently exercised through a reproducible fuzz campaign.

## Design
Mutate pinned valid component seeds for parser and validator robustness, and
generate bounded arithmetic components for end-to-end invocation. Every case
has a stable seed, timeout, outcome classification, and retained failure
artifact. A campaign that generates or executes no cases is a hard failure.

## Acceptance Criteria
- [x] Byte mutations cover truncation, bit flips, insertions, deletions, and
      section-length corruption.
- [x] Valid generated components reach parse, validation, instantiation, and
      invocation.
- [x] Crashes, signals, aborts, and timeouts fail the campaign.
- [x] Reports record tool versions, seed, counts, and failure artifacts.
- [x] Unit tests prove zero-case and timeout paths fail.
