## Description
Four upstream command guests (http-fields, http-request, http-response, http-request-options) import wasi:http/types@0.3.0. The HTTP host implements these resources, but the command CLI installs only the command world, causing UnknownImport. This is a composition/CLI coverage gap, not a missing import in the standard command world.

## Acceptance Criteria
- [x] Provide an explicit command execution path for requested HTTP imports with coherent resource ownership and async driving.
- [x] Run the four unchanged upstream guests on both engines.
- [x] Preserve denied-by-default network authority.

`component --run --http` composes types and client imports with the command world. All four upstream guests now execute on both engines (two pass, two retain exact WIT differences, ISS-571).
